# 02-创意引擎 · 技能

> 想法特殊的核心来源。高概念生成、跨界碰撞、反套路反转、what if引擎。

## 何时调用
- 用户说"帮我想个点子/想法/概念"
- 用户需要故事灵感
- 用户觉得自己的想法太普通，想要更特别的
- 用户说"如果...会怎样"类型的问题

## 输入要求
- 题材/类型方向（可选，不指定则随机生成）
- 想要的数量（默认3个）
- 可选：喜欢的元素、不想要的方向、参考作品

## 输出格式
- 每个概念包含：一句话高概念、核心冲突、独特卖点、故事潜力分析
- 标注哪个概念最有潜力，为什么
- 给出深化建议

## 核心方法论

### 方法一：高概念生成器
高概念 = 熟悉的元素 + 意想不到的组合 + 明确的冲突

公式：`[主角] 在 [不寻常的设定] 中，必须 [核心目标]，但 [核心障碍]`

生成步骤：
1. 选一个主角类型（失忆的侦探/退休的杀手/穿越的程序员/会说话的猫...）
2. 选一个不寻常的设定（时间循环/记忆可以买卖/死人会发短信/全世界都失忆了...）
3. 选一个核心目标（找到真相/拯救某人/改变过去/活下去...）
4. 选一个核心障碍（时间限制/身份暴露/内部背叛/规则限制...）
5. 组合成一句话，然后问"这会引发什么有趣的故事？"

### 方法二：跨界碰撞器
把两个不相关的元素强行结合，产生化学反应。

元素库分类：
- **职业**：医生、律师、厨师、宇航员、小偷、考古学家、电竞选手...
- **设定**：末世、赛博朋克、中世纪、太空站、海底城市、时间循环...
- **类型**：悬疑、爱情、喜剧、恐怖、冒险、政治、家庭...
- **核心冲突**：复仇、救赎、寻找、生存、背叛、成长、抉择...

碰撞公式：`[职业] + [设定] + [类型] + [核心冲突]`

示例：
- 厨师 + 末世 + 悬疑 + 复仇 → 末世里唯一会做正宗中餐的厨师，用厨艺破案并复仇
- 考古学家 + 时间循环 + 恐怖 + 生存 → 考古学家在古墓中陷入时间循环，每次循环都发现队友的新秘密
- 电竞选手 + 赛博朋克 + 政治 + 背叛 → 电竞选手发现比赛背后是政治阴谋，队友是卧底

### 方法三：反套路反转器
输入一个常见套路，输出3种颠覆性反转。

常见套路列表：
- 主角是天选之子
- 反派想毁灭世界
- 青梅竹马最终在一起
- 师父是好人
- 穿越者用现代知识碾压古代
- 失忆的主角其实是好人
- 最后一分钟救援成功

反转方法：
1. **身份反转**：你以为的A其实是B（天选之子其实是反派的棋子）
2. **动机反转**：你以为他想做X，其实想做Y（反派不是毁灭世界，而是拯救世界的极端方式）
3. **结果反转**：你以为会成功，其实失败了，而且失败才是正确的
4. **视角反转**：从另一个角色的角度看，主角才是反派
5. **规则反转**：故事建立的规则在关键时刻被推翻，但有铺垫

### 方法四：What If 引擎
通过连续追问"如果...会怎样"，深挖设定的独特性。

使用方法：
1. 从一个基础设定开始
2. 连续问5层"如果...会怎样"
3. 每一层都比上一层更深入、更具体
4. 最终找到这个设定最独特、最有故事潜力的点

示例：
- 基础：如果记忆可以买卖
- What if 1：如果穷人靠卖记忆为生？→ 产生"记忆矿工"阶层
- What if 2：如果记忆买卖导致身份混乱？→ 有人买了太多别人的记忆，分不清自己是谁
- What if 3：如果有人专门收集名人的记忆？→ 出现"记忆收藏家"，黑市交易
- What if 4：如果记忆可以被篡改？→ 政治势力用篡改记忆控制民众
- What if 5：如果主角是记忆警察，但自己的记忆也被篡改过？→ 核心冲突和故事

## 输出模板

### 概念卡片
```
概念 #1
一句话高概念：[主角]在[设定]中必须[目标]，但[障碍]
核心冲突：
独特卖点（为什么这个故事特别）：
可能的开篇：
主要人物雏形：
故事潜力分析：
适合的类型/字数：
```

## 调用示例
**用户**：帮我想3个科幻短篇的点子，要特别一点的
**技能输出**：
1. 概念#1：记忆删除师 — 专门帮人删除痛苦记忆的技师，发现一位客户的记忆里藏着自己失踪妻子的线索
2. 概念#2：倒数人生 — 每个人出生时手腕上有倒计时显示死亡时间，主角发现自己的倒计时在加速，而唯一能减缓的方法是...
3. 概念#3：语言瘟疫 — 一种通过语言传播的瘟疫，说特定词汇就会被感染，主角是语言学家，必须在失声前找到解药
...（每个概念附详细分析）
最推荐概念#2，因为它有天然的悬念和情感张力，适合短篇的紧凑结构。

## 想法解析与展开引擎（v1.1 新增）

> 不管用户扔过来什么——一句话灵感、一个画面、一个怪念头、一个情绪、甚至一个词——都能接住、解析、补全、展开成3个完整的故事方向。

### 可接收的任何想法类型

| 输入类型 | 示例 | 解析重点 |
|---------|------|---------|
| **一句话灵感** | "外卖员穿越到古代" | 核心冲突是什么？穿越者的优势/劣势是什么？ |
| **一个画面** | "雨夜里穿红裙子的女人站在桥上" | 这个画面里藏着什么故事？她为什么在这？接下来会发生什么？ |
| **一个人物** | "一个怕血的医生" | 这个矛盾怎么来的？他怎么工作？这个缺陷会带来什么冲突？ |
| **一个设定** | "这个世界说谎会下雨" | 这个规则怎么影响社会？人们怎么适应？谁在利用规则？ |
| **一个情绪** | "孤独但又很自由的感觉" | 什么人会有这种感觉？什么场景能传递这种情绪？什么故事能承载它？ |
| **一个反常识念头** | "英雄其实是反派的爸爸" | 这个关系怎么藏？什么时候揭露？揭露后双方怎么反应？ |
| **一个主题** | "记忆和遗忘" | 谁在遗忘？遗忘了什么？遗忘是好事还是坏事？有人想记住吗？ |
| **一个词** | "灯塔""旧照片""回声" | 这个词能联想到什么？什么人会和它有关？它藏着什么秘密？ |
| **一个类型混合** | "科幻+乡村爱情" | 两个类型的核心元素怎么融合？冲突点在哪？创新点在哪？ |
| **一个"我也说不清"** | "就是有种感觉，说不上来" | 用提问+给选项的方式帮用户澄清，给3个最接近的方向 |

### 想法解析四步法

**第一步：提取核心**
- 这个想法最核心的元素是什么？（人物/设定/冲突/情绪/画面/主题）
- 这个想法的"种子"是什么？（去掉所有修饰后最本质的那个点）
- 用户为什么会想到这个？（背后可能的情感动机）

**第二步：补全维度**
- 想法给了什么？缺什么？
- 自动补全缺失维度：
  - 给了人物 → 补冲突（这个人的矛盾是什么？他想要什么但得不到？）+ 补世界（他活在什么样的世界里？）
  - 给了设定 → 补人物（谁在这个设定里最痛苦/最得利？）+ 补冲突（这个设定会引发什么矛盾？）
  - 给了画面 → 补前因（画面之前发生了什么？）+ 补后果（接下来会发生什么？）+ 补人物（画面里的人是谁？）
  - 给了情绪 → 补人物（什么人会有这种情绪？）+ 补场景（什么场景能传递这种情绪？）+ 补故事（什么故事能承载这种情绪？）
  - 给了一个词 → 联想3个完全不同的故事方向

**第三步：生成3个差异化方向**
- 每个方向必须在**核心冲突+情感基调+结尾感觉**三个维度上都不同
- 每个方向必须包含：
  - 创新点（哪里不是套路）
  - 情感内核（这个故事真正在讲什么）
  - 一句话核心
  - 开场画面（直接写100字，不是描述）
- 三个方向的差异必须大到用户能明显感觉到"这是三个完全不同的故事"

**第四步：用户选择后深化**
- 用户选一个 → 进入人物塑造/结构设计阶段
- 用户说"都不对" → 问"是人物不对、冲突不对、还是感觉不对？"，针对性调整后再给2个
- 用户说"我想把A的人物和B的设定结合" → 直接混合，生成新方向
- 用户说"再给我几个" → 用创新五法生成完全不同的3个，不重复之前的方向

### 想法展开质量标准

- 不管输入多简单，输出的3个方向必须每个都能支撑起一个完整的故事
- 每个方向必须有至少1个创新点
- 每个方向的开场画面必须具体、有画面感、能让人想继续看
- 禁止给"半成品方向"（只有点子没有故事），每个方向必须有完整的核心冲突+人物+世界+结尾感觉
- 如果用户的想法本身有逻辑问题（比如"一个不会游泳的人当游泳教练"但没有合理原因），先指出来，再给修正后的方向

## 创意质量自检（v1.1 新增）

每个创意方向生成后必须检查，不通过的方向直接淘汰，不展示给用户。

### 检查项

**1. 创新点检查**
- [ ] 这个方向的核心创新点是什么？
- [ ] 这个创新点在同类作品里常见吗？（常见就淘汰或重新生成）
- [ ] 是真创新还是伪创新？（换皮不换骨是伪创新，必须改核心设定）

**2. 独特性检查**
- [ ] 用一句话概括核心设定，是否和已知作品高度相似？
- [ ] 有没有明显的差异化元素？
- [ ] 读者看到这个设定会觉得"有点意思"还是"又是这个"？

**3. 可写性检查**
- [ ] 这个创意能支撑起完整的故事吗？（还是只是个点子，展开后就空了？）
- [ ] 有明确的核心冲突吗？
- [ ] 有足够的情节空间吗？（能撑起目标字数/时长吗？）

**4. 情感内核检查**
- [ ] 这个创意背后有情感内核吗？（还是只是炫技？）
- [ ] 读者会关心这个故事里的人吗？
- [ ] 这个故事能让人产生某种强烈的情感反应吗？

**5. 逻辑自洽检查**
- [ ] 核心设定有内部逻辑吗？（不是"因为作者需要所以这样"）
- [ ] 设定会引发什么连锁反应？这些反应都考虑到了吗？
- [ ] 有没有明显的逻辑漏洞？

### 淘汰规则

- 创新点检查不通过 → 重新生成，不用展示
- 独特性检查不通过 → 加入差异化元素后重新生成，或直接淘汰
- 可写性检查不通过 → 补充核心冲突和情节空间，或淘汰
- 情感内核检查不通过 → 给创意加情感内核，或淘汰
- 逻辑自洽检查不通过 → 修正设定使其自洽，或淘汰

**只有5项全部通过的方向，才能展示给用户。**
