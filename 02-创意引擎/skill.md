# 02-创意引擎 · 技能

> 想法特殊的核心来源。高概念生成、跨界碰撞、反套路反转、what if引擎。

## 何时调用
- 用户说"帮我想个点子/想法/概念"
- 用户需要故事灵感
- 用户觉得自己的想法太普通，想要更特别的
- 用户说"如果...会怎样"类型的问题

## 输入要求
- 题材/类型方向（可选，不指定则随机生成）
- 想要的数量（默认3个）
- 可选：喜欢的元素、不想要的方向、参考作品

## 输出格式
- 每个概念包含：一句话高概念、核心冲突、独特卖点、故事潜力分析
- 标注哪个概念最有潜力，为什么
- 给出深化建议

## 核心方法论

### 方法一：高概念生成器
高概念 = 熟悉的元素 + 意想不到的组合 + 明确的冲突

公式：`[主角] 在 [不寻常的设定] 中，必须 [核心目标]，但 [核心障碍]`

生成步骤：
1. 选一个主角类型（失忆的侦探/退休的杀手/穿越的程序员/会说话的猫...）
2. 选一个不寻常的设定（时间循环/记忆可以买卖/死人会发短信/全世界都失忆了...）
3. 选一个核心目标（找到真相/拯救某人/改变过去/活下去...）
4. 选一个核心障碍（时间限制/身份暴露/内部背叛/规则限制...）
5. 组合成一句话，然后问"这会引发什么有趣的故事？"

### 方法二：跨界碰撞器
把两个不相关的元素强行结合，产生化学反应。

元素库分类：
- **职业**：医生、律师、厨师、宇航员、小偷、考古学家、电竞选手...
- **设定**：末世、赛博朋克、中世纪、太空站、海底城市、时间循环...
- **类型**：悬疑、爱情、喜剧、恐怖、冒险、政治、家庭...
- **核心冲突**：复仇、救赎、寻找、生存、背叛、成长、抉择...

碰撞公式：`[职业] + [设定] + [类型] + [核心冲突]`

示例：
- 厨师 + 末世 + 悬疑 + 复仇 → 末世里唯一会做正宗中餐的厨师，用厨艺破案并复仇
- 考古学家 + 时间循环 + 恐怖 + 生存 → 考古学家在古墓中陷入时间循环，每次循环都发现队友的新秘密
- 电竞选手 + 赛博朋克 + 政治 + 背叛 → 电竞选手发现比赛背后是政治阴谋，队友是卧底

### 方法三：反套路反转器
输入一个常见套路，输出3种颠覆性反转。

常见套路列表：
- 主角是天选之子
- 反派想毁灭世界
- 青梅竹马最终在一起
- 师父是好人
- 穿越者用现代知识碾压古代
- 失忆的主角其实是好人
- 最后一分钟救援成功

反转方法：
1. **身份反转**：你以为的A其实是B（天选之子其实是反派的棋子）
2. **动机反转**：你以为他想做X，其实想做Y（反派不是毁灭世界，而是拯救世界的极端方式）
3. **结果反转**：你以为会成功，其实失败了，而且失败才是正确的
4. **视角反转**：从另一个角色的角度看，主角才是反派
5. **规则反转**：故事建立的规则在关键时刻被推翻，但有铺垫

### 方法四：What If 引擎
通过连续追问"如果...会怎样"，深挖设定的独特性。

使用方法：
1. 从一个基础设定开始
2. 连续问5层"如果...会怎样"
3. 每一层都比上一层更深入、更具体
4. 最终找到这个设定最独特、最有故事潜力的点

示例：
- 基础：如果记忆可以买卖
- What if 1：如果穷人靠卖记忆为生？→ 产生"记忆矿工"阶层
- What if 2：如果记忆买卖导致身份混乱？→ 有人买了太多别人的记忆，分不清自己是谁
- What if 3：如果有人专门收集名人的记忆？→ 出现"记忆收藏家"，黑市交易
- What if 4：如果记忆可以被篡改？→ 政治势力用篡改记忆控制民众
- What if 5：如果主角是记忆警察，但自己的记忆也被篡改过？→ 核心冲突和故事

## 输出模板

### 概念卡片
```
概念 #1
一句话高概念：[主角]在[设定]中必须[目标]，但[障碍]
核心冲突：
独特卖点（为什么这个故事特别）：
可能的开篇：
主要人物雏形：
故事潜力分析：
适合的类型/字数：
```

## 调用示例
**用户**：帮我想3个科幻短篇的点子，要特别一点的
**技能输出**：
1. 概念#1：记忆删除师 — 专门帮人删除痛苦记忆的技师，发现一位客户的记忆里藏着自己失踪妻子的线索
2. 概念#2：倒数人生 — 每个人出生时手腕上有倒计时显示死亡时间，主角发现自己的倒计时在加速，而唯一能减缓的方法是...
3. 概念#3：语言瘟疫 — 一种通过语言传播的瘟疫，说特定词汇就会被感染，主角是语言学家，必须在失声前找到解药
...（每个概念附详细分析）
最推荐概念#2，因为它有天然的悬念和情感张力，适合短篇的紧凑结构。
