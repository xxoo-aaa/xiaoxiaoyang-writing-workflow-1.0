# 32-商业广告创意剧本

> 商业广告不是"介绍产品"，是"在30秒内让观众记住你、相信你、想要你"。好的广告创意，不是"我的产品有多好"，而是"我的产品能让你的生活变得多好"。本模块不写分镜脚本，只提供创意思路和剧本——从Brief解读，到概念开发，到15个行业的创意库，帮你快速产出能打的广告剧本。

---

## 一、商业广告的本质

### 广告不是什么

- ❌ 不是产品说明书（不要罗列参数）
- ❌ 不是自嗨（不要只说"我们很厉害"）
- ❌ 不是硬塞（不要强行植入产品）
- ❌ 不是所有人都喜欢（广告是做给目标受众看的，不是做给所有人看的）

### 广告是什么

- ✅ 是"在正确的时间，对正确的人，说正确的话"
- ✅ 是"用一个故事/一个场景/一个情绪，让观众记住产品"
- ✅ 是"把产品的功能，翻译成用户的利益"
- ✅ 是"在30秒内，完成'注意→兴趣→欲望→行动'的闭环"

### 广告的AIDA模型

| 阶段 | 英文 | 目标 | 手法 |
|------|------|------|------|
| **注意** | Attention | 抓住观众注意力 | 强钩子、反差、悬念、情绪冲击 |
| **兴趣** | Interest | 让观众感兴趣 | 问题呈现、场景共鸣、好奇心 |
| **欲望** | Desire | 让观众想要产品 | 效果展示、利益点、情感连接 |
| **行动** | Action | 引导观众行动 | 明确的CTA（Call to Action） |

## 二、Brief解读五步法

拿到一个广告需求（Brief），不要急着写，先解读。

### 第一步：产品是什么

**关键问题**：
- 产品的核心功能是什么？
- 和竞品相比，最大的差异点是什么？
- 产品解决了用户的什么问题？
- 产品的使用场景是什么？

**输出**：一句话说清产品——"这是一个____，它能帮用户____。"

### 第二步：给谁看

**关键问题**：
- 目标受众是谁？（年龄、性别、职业、收入、生活方式）
- 他们的痛点是什么？
- 他们的渴望是什么？
- 他们平时看什么内容？用什么平台？

**输出**：用户画像——"一个____岁的____，他/她正在为____烦恼，他/她想要____。"

### 第三步：要达到什么效果

**关键问题**：
- 广告的目标是什么？（品牌曝光？产品销售？活动推广？）
- 希望观众看完后做什么？（记住品牌？购买产品？参与活动？）
- 成功的标准是什么？（播放量？转化率？品牌认知度？）

**输出**：广告目标——"让____（受众）在____（场景）下，____（行动）。"

### 第四步：有什么限制

**关键问题**：
- 预算多少？（决定制作规模和创意形式）
- 时长多少？（15秒/30秒/60秒/更长）
- 投放平台？（抖音/电视/朋友圈/YouTube）
- 品牌调性？（高端/亲民/搞笑/感动）
- 必须包含的元素？（Logo、Slogan、特定信息）
- 不能碰的红线？（审查、竞品对比、敏感话题）

**输出**：限制清单——"时长____秒，投放____，必须包含____，不能____。"

### 第五步：找洞察

**关键问题**：
- 用户在使用这类产品时，有什么"未被说出的需求"？
- 有什么"反常识"的角度？
- 有什么"情感共鸣点"？
- 产品和用户之间，有什么"意想不到的连接"？

**输出**：核心洞察——"用户真正想要的不是____，而是____。"

**洞察示例**：
- 不是"用户想买一杯咖啡"，而是"用户想要一个能停下来喘口气的瞬间"
- 不是"用户想买一辆车"，而是"用户想要一种掌控感和自由感"
- 不是"用户想买护肤品"，而是"用户想要被看见、被欣赏"

## 三、创意概念开发五法

### 方法一：反差法

**操作**：把两个看似不相关的东西放在一起，制造反差感。

**示例**：
- 高端护肤品 + 工地场景（"再粗糙的环境，也要精致的脸"）
- 昂贵的红酒 + 便利店场景（"好东西，不需要特殊场合"）
- 运动品牌 + 办公室场景（"办公室也是你的运动场"）

### 方法二：共情法

**操作**：找到目标受众的共同痛点/情感，用真实的场景引发共鸣。

**示例**：
- 外卖平台 + 加班到深夜的年轻人（"再晚，也有热饭等你"）
- 保险 + 初为人父的年轻人（"有了想保护的人，就有了软肋和铠甲"）
- 学习APP + 焦虑的中年人（"人生最坏的结果，不过是大器晚成"）

### 方法三：悬念法

**操作**：开头制造悬念，让观众想知道"接下来会怎样"。

**示例**：
- 开头：一个人在空无一人的街道上狂奔（他在跑什么？）→ 揭示：他在赶最后一班地铁，因为用了XX导航，刚好赶上
- 开头：一个女人对着镜子哭（她为什么哭？）→ 揭示：她用了XX护肤品，皮肤好到感动哭了
- 开头：一群人在办公室里尖叫（发生了什么？）→ 揭示：老板宣布今天提前下班，因为用了XX办公软件，效率翻倍

### 方法四：反转法

**操作**：让观众以为是A，结果是B，制造意外和惊喜。

**示例**：
- 以为是爱情片（男女主浪漫相遇）→ 反转：其实是男主用了XX香水，女主被吸引
- 以为是励志片（主角努力奋斗）→ 反转：其实是主角用了XX学习APP，效率翻倍
- 以为是恐怖片（黑暗中传来声音）→ 反转：其实是XX智能音箱在播放音乐

### 方法五：夸张法

**操作**：把产品的效果夸张到极致，让观众印象深刻。

**示例**：
- 洗衣液：衣服脏到能长出植物 → 用了XX洗衣液，焕然一新
- 充电宝：手机没电到关机 → 用了XX充电宝，瞬间满电，继续玩三天三夜
- 减肥产品：胖到门都出不去 → 用了XX产品，瘦到能穿进十年前的牛仔裤

## 四、广告剧本结构

### 标准结构（30秒广告）

| 时间 | 内容 | 功能 |
|------|------|------|
| **0-3秒** | 强钩子（反差/悬念/情绪冲击） | 抓住注意力 |
| **3-10秒** | 问题呈现（用户痛点/场景共鸣） | 引发兴趣 |
| **10-20秒** | 产品介入 + 效果展示 | 激发欲望 |
| **20-25秒** | 情感升华/利益强化 | 加深印象 |
| **25-30秒** | 品牌露出 + CTA（行动号召） | 引导行动 |

### 剧本格式（不用分镜，只写画面描述和台词）

```
【场景】一句话描述场景
【人物】主要人物
【台词/旁白】人物说的话或旁白
【动作】关键动作（简单描述，不写分镜）
```

### 剧本示例（30秒）

```
【场景】深夜的办公室，一个年轻人对着电脑发呆，屏幕上是写不完的PPT。
【人物】小李（28岁，疲惫）

小李（叹气）：这什么时候是个头啊……

【动作】手机响了，是外卖APP的推送。他看了一眼，点了一份热汤面。

【场景】15分钟后，外卖送到。小李打开盖子，热气扑面而来。

小李（吃了一口，眼睛亮了）：……还挺好吃的。

【旁白】再晚的夜，也有热饭等你。XX外卖，30分钟必达。

【动作】小李放下筷子，看着电脑，眼神重新有了力量。

小李（自言自语）：吃完这碗，再战三百回合！

【画面】品牌Logo + Slogan + APP下载二维码
```

## 五、15个行业创意库

### 行业一：快消品（食品/饮料/日化）

**核心卖点**：日常、高频、性价比、情感陪伴

**创意方向1：日常仪式感**
- 思路：把普通的快消品，变成生活中的"小确幸"
- 剧本示例（咖啡）：
```
【场景】早上7点，闹钟响了。一个年轻人赖在床上，不想起。
【旁白】每天早上，都有一个理由让你起床。
【动作】他闻到了咖啡的香味，睁开眼睛，看到桌上有一杯刚冲好的咖啡。
【旁白】XX咖啡，给你一个起床的理由。
【人物】他拿起咖啡，喝了一口，笑了。
【人物】新的一天，开始了。
```

**创意方向2：反差幽默**
- 思路：用夸张/反差的方式展示产品效果
- 剧本示例（洗衣液）：
```
【场景】一个孩子穿着白衣服在泥地里打滚，妈妈在旁边看着，表情淡定。
【人物】朋友：你不心疼吗？
【人物】妈妈（微笑）：心疼什么？
【动作】妈妈把脏衣服扔进洗衣机，倒了XX洗衣液。
【场景】衣服洗出来，洁白如新。
【人物】妈妈：有XX，随便造。
```

**创意方向3：情感陪伴**
- 思路：把产品和情感记忆连接
- 剧本示例（方便面）：
```
【场景】大学宿舍，一个男生在泡方便面。
【旁白】大学四年，吃了多少碗XX面？
【蒙太奇】考试前吃、失恋后吃、熬夜打游戏吃、毕业前最后一晚一起吃。
【场景】多年后，他在超市看到XX面，拿了一包。
【人物】（吃了一口）：还是这个味道。
【旁白】XX面，陪你走过那些年。
```

### 行业二：3C数码（手机/电脑/耳机）

**核心卖点**：科技感、性能、体验、生活方式

**创意方向1：场景化展示**
- 思路：不罗列参数，用场景展示产品如何融入生活
- 剧本示例（降噪耳机）：
```
【场景】嘈杂的地铁里，一个女生戴上耳机，瞬间安静了。
【旁白】世界很吵，但你可以选择安静。
【蒙太奇】飞机上、办公室、咖啡厅、街头——她戴上耳机，就进入了自己的世界。
【场景】她摘下耳机，朋友问她：你刚才在听什么？
【人物】她（微笑）：听我自己。
【旁白】XX降噪耳机，把世界调成静音。
```

**创意方向2：功能戏剧化**
- 思路：把一个功能点用戏剧化的方式展示
- 剧本示例（手机拍照）：
```
【场景】一个摄影师在拍夜景，试了很多次都不满意。
【人物】（叹气）：这光太暗了……
【动作】他拿出XX手机，随手一拍。
【场景】照片出来，清晰明亮，色彩惊艳。
【人物】（震惊）：这……是手机拍的？
【旁白】XX手机，暗夜也能拍出大片。
```

**创意方向3：情感连接**
- 思路：科技产品连接人与人的情感
- 剧本示例（平板电脑）：
```
【场景】一个小女孩在用平板视频通话，对面是外地工作的爸爸。
【人物】爸爸：宝贝，今天在学校怎么样？
【人物】小女孩：爸爸你看！（她把平板转向窗外，烟花正在绽放）
【人物】爸爸（眼眶红了）：……真美。
【人物】小女孩：爸爸，明年我们一起看好不好？
【旁白】XX平板，让距离不再是距离。
```

### 行业三：汽车

**核心卖点**：自由、掌控、安全、身份、家庭

**创意方向1：自由与远方**
- 思路：汽车代表自由和探索
- 剧本示例：
```
【场景】一个男人在办公室里，看着窗外，眼神疲惫。
【旁白】你有多久没有出发了？
【动作】他下班，坐进车里，发动引擎。
【蒙太奇】车行驶在城市道路、高速公路、山间小路、海边公路。
【场景】他停在海边，下车，看着大海，深吸一口气。
【人物】（微笑）：这才是生活。
【旁白】XX汽车，带你去任何你想去的地方。
```

**创意方向2：家庭与安全**
- 思路：汽车是家庭的移动空间，安全是核心
- 剧本示例：
```
【场景】一个爸爸在开车，后座上是妻子和孩子。孩子在安全座椅上睡着了。
【旁白】每一次出发，都是为了平安到达。
【动作】突然，前方有车急刹。爸爸还没反应过来，车已经自动刹停了。
【场景】妻子惊醒，看了一眼没事，又安心地靠回座椅。
【旁白】XX汽车，主动安全系统，比你更快一步。
【人物】爸爸（看着后视镜里的孩子，微笑）：有你们在，我必须更小心。
```

**创意方向3：身份与品味**
- 思路：高端汽车代表身份和品味
- 剧本示例：
```
【场景】一个商务场合，所有人都在寒暄。一个男人从容地走进来，气场十足。
【旁白】真正的高级，不需要大声说。
【动作】他坐下，从容地和客户交谈，每一个细节都恰到好处。
【场景】会议结束，他走出大楼，司机把车开过来——一辆XX豪华轿车。
【旁白】XX汽车，懂你的从容。
```

### 行业四：服饰/时尚

**核心卖点**：风格、自信、品质、自我表达

**创意方向1：自我表达**
- 思路：衣服是穿在身上的态度
- 剧本示例：
```
【场景】一个女生在镜子前试衣服，换了很多套都不满意。
【旁白】你穿的不是衣服，是你自己。
【动作】她换上一件XX品牌的外套，看了一眼镜子，眼睛亮了。
【场景】她走出门，走在街上，自信满满。路人纷纷侧目。
【人物】（对镜头微笑）：今天，我就是主角。
【旁白】XX服饰，穿出你的态度。
```

**创意方向2：场景化穿搭**
- 思路：不同场景，不同穿搭
- 剧本示例（运动品牌）：
```
【蒙太奇】
- 早上：她穿着XX运动服在公园跑步
- 上午：她穿着XX休闲装在咖啡馆工作
- 下午：她穿着XX瑜伽服在健身房
- 晚上：她穿着XX连衣裙和朋友聚会
【旁白】从晨跑到夜生活，XX陪你切换每一个角色。
【人物】（对镜头）：我不止一面。
```

**创意方向3：品质与工艺**
- 思路：强调材质、工艺、细节
- 剧本示例（高端男装）：
```
【场景】一个老裁缝在手工缝制一件西装，一针一线，极其专注。
【旁白】好的衣服，是有温度的。
【蒙太奇】面料的选择、剪裁的精准、缝制的细致、纽扣的打磨。
【场景】一个男人穿上这件西装，站在镜子前，整个人的气质都不一样了。
【人物】（整理领口，微笑）：嗯，就是它了。
【旁白】XX男装，匠心缝制，为你而生。
```

### 行业五：金融（银行/保险/理财）

**核心卖点**：安全、信任、专业、未来保障

**创意方向1：情感与责任**
- 思路：金融产品背后是对家人的责任和爱
- 剧本示例（保险）：
```
【场景】一个年轻的爸爸抱着刚出生的宝宝，眼神温柔。
【旁白】从你出生的那一刻起，我就想为你挡住一切风雨。
【蒙太奇】孩子学走路、上幼儿园、上小学、上中学——爸爸一直在身边。
【场景】孩子要去外地上大学了，爸爸送他到车站。
【人物】爸爸：去吧，爸爸永远是你最坚强的后盾。
【旁白】XX保险，为爱守护，让爱不留遗憾。
```

**创意方向2：反焦虑**
- 思路：用轻松的方式化解金融焦虑
- 剧本示例（理财APP）：
```
【场景】一个年轻人看着银行卡余额，愁眉苦脸。
【人物】：钱怎么又没了……
【动作】他打开XX理财APP，跟着上面的建议，开始小额理财。
【蒙太奇】一个月后、三个月后、一年后——余额慢慢变多。
【场景】一年后，他看着余额，笑了。
【人物】：原来存钱也没那么难嘛。
【旁白】XX理财，让每一分钱都为你工作。
```

**创意方向3：专业与信任**
- 思路：展示专业能力，建立信任
- 剧本示例（银行）：
```
【场景】一个小企业主在办公室里发愁，资金周转困难。
【人物】：这可怎么办……
【动作】他来到XX银行，客户经理耐心地听他的情况，给他制定了贷款方案。
【场景】三个月后，他的企业渡过了难关，订单越来越多。
【人物】（握着客户经理的手）：谢谢你，当时要是没有你们……
【人物】客户经理（微笑）：这是我们应该做的。XX银行，和中小企业一起成长。
```

### 行业六：医疗/健康

**核心卖点**：专业、关怀、效果、安心

**创意方向1：关怀与温度**
- 思路：医疗不只是治病，更是关怀
- 剧本示例（体检中心）：
```

- 下午：她在健身房练瑜伽
- 晚上：她穿着运动外套和朋友聚会
【旁白】运动不是任务，是生活的一部分。
【人物】（对镜头微笑）：动起来，每一天都精彩。
【旁白】XX运动，穿出你的运动态度。
```

### 行业十五：公益

**核心卖点**：社会价值、情感共鸣、行动号召

**创意方向1：情感冲击**
- 思路：用真实的故事和情感冲击，引发关注
- 剧本示例（环保）：
```
【场景】一只海龟在海里游，被一个塑料袋缠住了脖子，痛苦地挣扎。
【旁白】你随手扔掉的一个塑料袋，可能是它的夺命绳。
【蒙太奇】海洋里的垃圾、被污染的海滩、受伤的海洋生物。
【场景】一个小女孩在海滩上捡垃圾，一个接一个。
【人物】：我能做的不多，但我想做点什么。
【旁白】保护环境，从少用一个塑料袋开始。
```

**创意方向2：反常识**
- 思路：用反常识的角度，引发思考
- 剧本示例（关爱老人）：
```
【场景】一个老人独自坐在家里，看着全家福，自言自语。
【人物】老人：今天是我的生日……他们应该会来吧……
【场景】门铃响了，老人兴奋地去开门——是快递员，送的是他自己买的药。
【旁白】你有多久没回家看父母了？他们等的，从来不是礼物。
【场景】老人看着空荡荡的房间，叹了口气。
【旁白】常回家看看，别让爱等待。
```

**创意方向3：希望与行动**
- 思路：不只展示问题，更给出希望和行动方案
- 剧本示例（乡村教育）：
```
【场景】一个乡村教室，孩子们在简陋的教室里上课，眼神里满是对知识的渴望。
【旁白】他们和城里的孩子一样聪明，只是缺少机会。
【蒙太奇】志愿者来支教、捐赠图书、修建新教室、孩子们在新教室里开心地学习。
【场景】一个小女孩拿着新书，笑得很灿烂。
【人物】：我长大了想当老师，回来教更多的小朋友。
【旁白】XX公益，给每个孩子一个改变命运的机会。你的每一份捐赠，都在改变一个孩子的人生。
```

## 六、国内/海外广告差异

### 国内广告特点

- **节奏快**：信息密度大，30秒内塞很多内容
- **直接**：直接说卖点、优惠、CTA
- **情感牌**：家庭、亲情、奋斗、逆袭等情感主题受欢迎
- **明星代言**：明星代言效果好
- **平台特色**：抖音/快手等短视频平台，广告要符合平台调性（搞笑、反转、种草）
- **审查严格**：医疗、金融、教育等行业审查严格，不能用绝对化用语

### 海外广告特点

- **节奏稍慢**：更注重故事性和情感铺垫
- **含蓄**：不直接说卖点，用故事让观众自己感受
- **幽默和反讽**：幽默广告受欢迎，尤其是超级碗广告
- **价值观表达**：品牌常表达社会价值观（多元、环保、平权等）
- **平台特色**：YouTube前贴片广告，前5秒必须抓住人；Instagram/TikTok重视视觉和创意
- **法规不同**：各国广告法规不同，需要注意

### 跨文化广告建议

1. **情感是普适的**：爱、家庭、奋斗、自由——这些情感跨文化通用
2. **文化特定元素要谨慎**：幽默、梗、符号可能在不同文化中有不同含义
3. **本地化是关键**：同一个产品，在不同市场要用不同的创意角度
4. **避免刻板印象**：不要用种族、性别、宗教的刻板印象
5. **遵守当地法规**：每个国家的广告法规不同，发布前要确认

## 七、常见问题及解法

| 问题 | 表现 | 解法 |
|------|------|------|
| **广告没人看** | 播放量低，完播率低 | 前3秒必须有强钩子；用反差/悬念/情绪冲击；符合平台调性 |
| **看了记不住** | 观众看完不知道在说什么 | 核心卖点只说一个；重复品牌名和Slogan；结尾有记忆点 |
| **记住了但不买** | 品牌认知有了，但转化率低 | CTA要明确；给出购买理由（优惠/限时/稀缺）；降低购买门槛 |
| **太像广告** | 观众一看就划走 | 用故事/场景/情感包装，不要直接卖货；先给价值，再提产品 |
| **产品植入太硬** | 产品出现得很突兀 | 让产品自然融入场景；产品是解决问题的关键，不是硬塞 |
| **创意太抽象** | 观众看不懂想表达什么 | 创意要服务于卖点；再创意也要让观众一眼看懂产品利益 |
| **卖点太多** | 广告里说了五六个卖点，观众一个都记不住 | 一个广告只说一个核心卖点；其他卖点可以放在其他广告里 |
| **目标受众不明确** | 想让所有人都喜欢，结果谁都不喜欢 | 明确目标受众，说他们想听的话，用他们的语言 |
| **违反审查** | 广告被下架/罚款 | 发布前检查审查红线；不用绝对化用语；敏感行业提前确认 |
| **预算有限** | 没钱做大制作 | 好创意不等于大制作；用创意和情感取胜，小成本也能出好广告 |

## 八、正反示例对比

### 示例：同一产品的两种广告

**产品**：一款续航超长的蓝牙耳机

❌ **差的广告（说明书式）**：
```
【旁白】XX蓝牙耳机，采用最新蓝牙5.3技术，续航长达48小时，IPX7防水，主动降噪，音质卓越，佩戴舒适。现在购买，立减100元！
【画面】产品特写 + 参数列表 + 购买链接
```
（问题：罗列参数，没有场景和情感，观众记不住，不想买。）

✅ **好的广告（故事式）**：
```
【场景】一个年轻人在长途火车上，戴上XX耳机，开始听歌。
【旁白】从北京到上海，5个小时。
【蒙太奇】他听着歌，看窗外的风景，看书，打盹——耳机一直有电。
【场景】到了上海，他下火车，朋友来接他。
【人物】朋友：你这耳机听了一路？还有电？
【人物】他（看了一眼耳机）：还有80%呢。
【人物】朋友（震惊）：什么耳机这么顶？
【旁白】XX蓝牙耳机，48小时超长续航，从白天听到黑夜。
【画面】品牌Logo + 购买链接
```
（好的原因：用场景展示续航，不罗列参数；有故事和人物；产品自然融入；结尾有记忆点和CTA。）

## 十、商业广告创意剧本质量自检清单

完成广告剧本后，用以下清单自检：

### Brief解读
- [ ] 产品核心功能明确吗？
- [ ] 目标受众清晰吗？
- [ ] 广告目标明确吗？（品牌/销售/活动）
- [ ] 限制条件都考虑了吗？（时长、平台、预算、审查）
- [ ] 找到核心洞察了吗？

### 创意
- [ ] 前3秒有强钩子吗？（反差/悬念/情绪冲击）
- [ ] 创意和产品有关联吗？（不是为了创意而创意）
- [ ] 核心卖点只说一个吗？（不罗列参数）
- [ ] 产品植入自然吗？（不生硬）
- [ ] 有记忆点吗？（观众看完能记住什么）

### 剧本
- [ ] 结构完整吗？（注意→兴趣→欲望→行动）
- [ ] 场景具体吗？（不是抽象描述）
- [ ] 人物有特点吗？（不是工具人）
- [ ] 台词精炼吗？（没有废话）
- [ ] CTA明确吗？（观众知道看完要做什么）

### 效果
- [ ] 目标受众会有共鸣吗？
- [ ] 观众看完能记住品牌吗？
- [ ] 观众看完有购买欲望吗？
- [ ] 符合品牌调性吗？
- [ ] 符合平台调性吗？

### 合规
- [ ] 没有违反广告法吗？（不用绝对化用语）
- [ ] 没有敏感内容吗？（政治、宗教、种族等）
- [ ] 数据/效果描述真实吗？（不虚假宣传）
- [ ] 行业特殊规定遵守了吗？（医疗、金融、教育等）

**任何一项不通过，回到对应部分修改，修改后重新自检。**

---

> **商业广告创意剧本的终极目标**：让观众在30秒内，从"这是什么"到"我想要"。好的广告不是"打扰观众"，是"给观众价值"——要么让他笑，要么让他哭，要么让他觉得"这说的就是我"。当观众看完你的广告，主动搜索你的产品，甚至转发给朋友——你的广告就成功了。
