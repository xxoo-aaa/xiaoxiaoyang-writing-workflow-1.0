# 21-研究与考据 · 技能

> 特定题材的资料研究：研究方法、资料整理、考据技巧、如何把研究自然融入故事。让特定题材写得真实可信。

## 何时调用
- 用户写特定题材需要做研究（医疗/法律/历史/科技/职业...）
- 用户需要考据历史/文化/制度的准确性
- 用户需要整理研究资料
- 用户说"需要查资料/考据/怎么写得真实"

## 输入要求
- 研究主题（具体的题材/领域/时代）
- 故事需求（研究这些资料是为了写什么场景/人物）
- 可选：已有的资料、参考来源

## 输出格式
- 研究计划（需要研究哪些方面、优先级、来源建议）
- 核心研究发现（最重要的3-5个发现）
- 详细研究笔记
- 资料整理和分类
- 如何在故事中使用这些资料的建议
- 需要注意的准确性问题
- 参考来源列表

## 核心方法论

### 研究方法

**研究前的准备**：
1. **明确研究目的**：你研究这些资料是为了写什么？（某个场景？某个人物？某个设定？）
2. **列出研究问题**：把你需要知道的东西列成具体的问题，不要泛泛地"了解一下"
3. **确定研究深度**：你需要多深入？（表面了解/中等深度/专业深度）
4. **设定时间限制**：研究是为了写作，不要陷入研究而不写作（研究地狱）

**研究的信息来源**（按可信度排序）：
1. **专业书籍/学术论文**：最可靠，但可能枯燥
2. **权威机构网站**：政府、医院、大学、专业协会的官方网站
3. **纪录片/专题片**：直观，有画面感，适合研究环境和生活
4. **人物访谈**：如果能找到相关职业的人访谈，是最有价值的
5. **行业论坛/社区**：从业者的真实讨论，有很多"内行才知道"的细节
6. **新闻报道/深度报道**：真实案例，有故事性
7. **百科/科普文章**：入门级了解，但需要交叉验证
8. **小说/影视**：可以参考，但不能作为唯一来源（可能有艺术加工和错误）

**研究技巧**：
1. **从宏观到微观**：先了解整体框架，再深入具体细节
2. **关键词搜索**：用专业术语搜索，比用日常语言搜索结果更专业
3. **交叉验证**：重要信息至少从2-3个来源确认
4. **记录来源**：每个重要信息都记录来源，方便后续查证
5. **关注"反常识"的细节**：最有价值的研究发现往往是和大众认知不同的细节
6. **关注"日常"的细节**：专业人士的日常习惯、术语、工作流程，这些是让故事真实的关键

### 常见题材研究要点

**医疗题材**：
- 医院的组织结构和流程（挂号/门诊/住院/手术/急诊）
- 医生的工作状态（值班/手术/病历/医患沟通）
- 医学术语和简称（不要用错，也不要过度使用）
- 疾病的症状、诊断、治疗过程（要准确）
- 医疗设备和操作（不要写出常识性错误）
- 医院的等级和分工（三甲/社区医院/专科医院）
- 医生的晋升路径和职业压力
- 医患关系和医疗纠纷
- 注意：不要让医生做护士的工作，不要混淆科室

**法律题材**：
- 法律体系（大陆法系/英美法系，中国的公检法体系）
- 诉讼流程（立案/侦查/起诉/审判/上诉）
- 律师的工作（接案/调查/阅卷/开庭/辩护）
- 法律术语（准确使用，不要望文生义）
- 证据规则（什么能作为证据，怎么取证）
- 不同类型案件的特点（刑事/民事/行政/商事）
- 律师的职业伦理和灰色地带
- 法庭的程序和礼仪
- 注意：不要把英美法系的制度套到中国，不要让律师做警察的工作

**历史题材**：
- 时代背景（政治/经济/文化/社会结构）
- 官职制度和等级（不要用错朝代的官职）
- 服饰/建筑/饮食/生活用品（符合时代）
- 语言和称谓（不要用现代词汇，不要用错称谓）
- 交通和通讯（古代的旅行速度、信息传递方式）
- 货币和经济（物价、收入、消费水平）
- 风俗习惯和礼仪（婚丧嫁娶、节日、社交礼仪）
- 重大历史事件和人物（不要改变重大史实）
- 注意：细节要准确，但不要为了考据而牺牲故事性

**科技/科幻题材**：
- 现有科技的水平和限制（不要写出超越当前物理定律的"硬科幻"错误）
- 科技发展的趋势和可能性（近未来设定要合理）
- 科技对社会/生活/人际关系的影响
- 专业领域的术语和工作方式（AI/生物/航天/量子...）
- 科技的伦理和社会问题
- 注意：硬科幻要遵守物理定律，软科幻可以更自由但也要有内在逻辑

**职业题材**（通用）：
- 该职业的日常工作内容和流程
- 职业术语和行话（适当使用，增加真实感）
- 职业的晋升路径和职业发展
- 职业的收入水平和社会地位
- 职业的压力和风险
- 职业的人际关系（同事/上下级/客户）
- 职业的职业道德和灰色地带
- 从业者的真实生活状态（不是影视剧中的理想化形象）
- 最好能找到从业者访谈或行业论坛，了解"内行才知道"的细节

### 资料整理

**研究笔记模板**：
```
研究主题：
关联项目/场景：
研究日期：
研究问题：[我 originally 想知道什么]

核心发现（最重要的3-5个）：
1. ...
2. ...
3. ...

详细笔记：
【分类1】
  - 要点：...
  - 细节：...
  - 来源：...
【分类2】
  - ...

可用场景：
- 场景1：可以用...细节
- 场景2：可以用...设定

需要注意（容易出错的地方）：
- ...
- ...

参考来源：
1. [书名/网站/纪录片] - 可信度评估
2. ...
```

**资料分类方法**：
- 按项目分类：每个写作项目一个文件夹
- 按主题分类：医疗/法律/历史/科技/职业...
- 按可信度分类：权威来源/一般来源/待验证
- 按使用状态分类：已使用/待使用/参考

### 如何把研究融入故事

**核心原则**：研究是为了故事服务，不是为了展示研究。不要让故事变成百科全书。

**融入技巧**：

1. **通过行动展示，不是通过说明**
   - ❌ "医院的三级查房制度是..."
   - ✅ 展示主任带着主治和住院医查房的场景，通过他们的对话和行动展示制度

2. **通过人物的日常展示**
   - 让专业人士做他们日常会做的事（写病历/整理证据/做实验）
   - 通过这些日常行动自然展示专业知识
   - 读者不需要知道所有细节，只需要感受到"这个人很专业"

3. **通过冲突和问题展示**
   - 让角色遇到一个专业问题，通过解决问题展示专业知识
   - 比如医生遇到疑难病例，律师遇到棘手案件
   - 解决问题的过程就是展示专业知识的过程

4. **通过术语和行话（适度）**
   - 适当使用专业术语，增加真实感
   - 但不要过度使用，让读者看不懂
   - 术语的意思可以通过上下文自然理解，不需要解释
   - 注意：术语要用对，不要望文生义

5. **通过细节展示**
   - 专业人士的小习惯、小细节（医生洗手的方式/律师整理文件的习惯）
   - 工作环境的细节（办公室的布置/工具的摆放）
   - 这些细节比大段说明更有真实感

6. **只展示和故事相关的部分**
   - 不要把你研究的所有东西都写进去
   - 只写和当前场景/人物/冲突相关的部分
   - 其他研究成果可以作为背景知识，让你写的时候更有底气，但不需要全部展示

7. **让角色解释给"外行"听**
   - 如果有一个外行角色（新手/客户/患者），可以让专业角色向他解释
   - 这样自然地传递信息，不会像在上课
   - 但不要让解释太长，点到为止

**常见问题**：
- ❌ 研究地狱：一直在研究，迟迟不开始写作
  - 解决：设定研究时间限制，研究到"足够写"就开始写，边写边查
- ❌ 信息倾倒：把研究成果大段写进故事，变成百科全书
  - 解决：通过行动/冲突/细节展示，只写和故事相关的部分
- ❌ 常识错误：研究了但还是写错了关键信息
  - 解决：重要信息交叉验证，写完后找专业人士审读（如果可能）
- ❌ 过度专业：写得太专业，普通读者看不懂
  - 解决：术语通过上下文理解，必要时用外行角色的视角解释

### 考据技巧

**考据的核心**：准确、有来源、可验证。

**考据步骤**：
1. **确定考据点**：哪些信息需要准确？（官职/年代/服饰/制度/事件...）
2. **查找权威来源**：优先使用学术著作、原始史料、权威机构
3. **交叉验证**：至少2-3个来源确认
4. **记录来源**：每个考据点记录来源，方便后续查证
5. **标注不确定**：如果有争议或不确定，标注出来，写作时回避或模糊处理

**常见考据错误**：
- 张冠李戴：把A朝代的东西用到B朝代
- 时空错乱：让人物使用当时还没有的东西
- 称谓错误：用错官职/辈分/尊称
- 制度错误：混淆不同时代的制度
- 数值错误：物价/年龄/时间计算错误

**考据和故事性的平衡**：
- 重大史实不能错（会被读者骂）
- 次要细节可以适当艺术加工（为了故事性）
- 如果不确定，可以模糊处理（不写具体年代/官职，用泛指）
- 考据是为了让故事更真实，不是为了炫耀知识

## 调用示例
**用户**：我要写一个古代背景的小说，主角是个仵作（古代法医），需要研究什么？
**技能输出**：
仵作题材研究计划：

一、需要研究的核心方面（按优先级）：

1. **仵作的职业定位和工作内容**（最高优先级）
   - 仵作在古代的社会地位（通常是贱籍，被人看不起）
   - 仵作的具体工作（验尸/验伤/现场勘查/出具报告）
   - 仵作的工作流程（接到报案→现场勘查→验尸→撰写验状→上报）
   - 仵作和官府的关系（隶属于哪个部门，受谁管辖）
   - 仵作的收入和生活状态
   - 来源：《洗冤集录》（宋慈，古代法医学专著）、古代司法制度研究、历史论文

2. **古代验尸技术和方法**（高优先级）
   - 古代的验尸方法（看/闻/问/切，用醋/酒/皂角等）
   - 如何判断死因（钝器伤/锐器伤/中毒/缢死/溺死/烧死...）
   - 如何判断死亡时间（根据尸斑/尸僵/胃内容物）
   - 古代的法医知识水平（能做到什么，不能做到什么）
   - 常见的验尸错误和舞弊（受贿/伪造/误判）
   - 来源：《洗冤集录》、古代法医学史、现代法医对古代方法的分析

3. **古代司法制度和流程**（中优先级）
   - 案件的处理流程（报案→受理→勘查→审讯→判决→上报）
   - 各级官府的司法权限（县/府/省/中央）
   - 仵作在司法流程中的位置和作用
   - 古代的证据规则和审判方式
   - 死刑案件的复核制度
   - 来源：中国法制史、历代刑法志、古代案例集

4. **时代背景和社会环境**（中优先级）
   - 你设定的具体朝代（宋/明/清？不同朝代仵作制度不同）
   - 该朝代的社会结构、等级制度
   - 仵作作为贱籍的生活状态和社会歧视
   - 当时的城市/乡村环境
   - 当时的医疗水平（和仵作的工作相关）
   - 来源：该朝代的社会史、生活史研究

5. **专业术语和行话**（低优先级但重要）
   - 仵作/法医的专业术语（尸斑/尸僵/八字不交/白练...）
   - 古代司法术语（供状/诉状/验状/五听...）
   - 古代的官职和称谓
   - 注意：术语要用对，不要用现代法医术语套到古代
   - 来源：《洗冤集录》原文、古代司法文献、专业词典

二、核心研究发现（仵作题材最有价值的几个点）：

1. **仵作的社会地位极低**：通常属于贱籍，子孙不能参加科举，被人看不起。这是很好的人物冲突来源——有能力但被社会歧视。
2. **《洗冤集录》是真实存在的**：宋代宋慈所著，是世界上最早的法医学专著。可以让主角学习/参考这本书，增加真实感。
3. **古代验尸有很多"土方法"但也有科学性**：用醋浇在尸骨上看伤痕、用红油伞遮尸骨看骨折、用糯米团验毒...这些方法既有时代特色，又有一定科学道理。
4. **仵作经常被贿赂和胁迫**：因为他们的验尸结果直接影响案件判决，所以经常被利益相关方贿赂或威胁。这是很好的剧情冲突来源。
5. **仵作和"推理"天然相关**：验尸就是从尸体上找线索、推理死因和过程，和侦探推理有异曲同工之妙。可以把仵作写成古代法医+侦探的结合。

三、如何在故事中使用这些研究：

1. **通过验尸场景展示专业**：设计几个详细的验尸场景，通过主角的操作和推理展示古代法医学知识。这是仵作题材最核心的看点。
2. **通过社会歧视展示人物冲突**：主角有能力但因为身份被歧视，他如何证明自己、如何面对偏见。这是人物弧线的核心。
3. **通过贿赂和胁迫展示道德困境**：主角在验尸时面临利益诱惑和生命威胁，他如何选择。这是道德冲突的来源。
4. **通过《洗冤集录》展示传承**：主角学习/参考/改进《洗冤集录》，可以和历史人物宋慈产生联系（如果是宋代背景）。
5. **通过案件展示时代背景**：每个案件都可以反映当时的社会问题（阶级压迫/性别歧视/司法腐败...），让故事有深度。

四、需要注意的准确性问题：

1. 不要让仵作做现代法医才能做的事（DNA/毒理分析/显微镜...）
2. 不要混淆朝代（宋代的仵作制度和明清不同）
3. 不要让仵作的社会地位太高（他们通常是贱籍，不是官员）
4. 验尸方法要符合当时的技术水平，不要穿越
5. 司法流程要符合当时的制度，不要用现代司法制度套古代

五、推荐参考来源：
1. 《洗冤集录》宋慈（必读，原文+白话译本）
2. 《中国古代法医学史》贾静涛
3. 《洗冤集录校译》
4. 古代司法制度相关论文
5. 宋代/明代社会生活史
6. 如果可能，找现代法医了解他们对古代方法的评价

六、研究时间建议：
- 第一阶段（1-2天）：读《洗冤集录》，了解仵作的基本工作和方法
- 第二阶段（2-3天）：研究古代司法制度和仵作的社会地位
- 第三阶段（1-2天）：研究具体朝代的社会背景和生活细节
- 边写边查：写作中遇到具体问题再深入研究，不要一开始就想研究完所有东西
