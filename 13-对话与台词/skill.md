# 13-对话与台词 · 技能

> 写好对话和台词：潜台词、人物语言差异化、冲突对话、信息型对话、情感对话、幽默对话。

## 何时调用
- 用户觉得对话写得干/不自然/没有张力
- 用户需要写特定类型的对话（争吵/告白/审讯/谈判）
- 用户需要让角色的语言更有辨识度
- 用户说"对话写不好/台词怎么写"

## 输入要求
- 场景和人物背景
- 对话的目标和冲突
- 可选：已有的对话草稿

## 输出格式
- 对话功能分析（这段对话在做什么）
- 潜台词设计（角色说的和想的不一样）
- 人物语言差异化建议
- 具体的对话改写
- 对话节奏和停顿设计
- 对话修订Checklist

## 核心方法论

### 对话的功能

好的对话不只是"角色在说话"，它同时在做以下至少一件事：

1. **推进情节**：通过对话揭示新信息、做出决定、引发行动
2. **展示人物**：通过说话方式展示性格、背景、情绪、价值观
3. **制造冲突**：通过对话中的分歧、误解、对抗制造张力
4. **传递信息**：通过对话让读者知道需要知道的事（但要自然）
5. **建立关系**：通过对话展示角色之间的关系和情感
6. **制造悬念**：通过对话中的暗示、回避、半真半假制造悬念
7. **表达主题**：通过对话中的观点碰撞体现主题

**检查**：如果一段对话删掉后，情节、人物、关系都没有变化，那这段对话就是多余的。

### 潜台词（Subtext）

**核心原则**：角色说的话和他们真正想的/感觉的不一样。最有张力的对话是"话里有话"。

**潜台词的类型**：
1. **回避型**：角色回避真正的问题，说别的事
   - 例：A问"你还爱我吗？"B说"今天晚饭吃什么？"
2. **反语型**：角色说的和想的相反
   - 例："你可真厉害啊"（其实是说"你搞砸了"）
3. **过度解释型**：角色急于解释，反而暴露了真实想法
   - 例："我没事，我真的没事，你别问了"（其实有事）
4. **转移型**：角色把话题转移到别人身上
   - 例：A问"你是不是隐瞒了什么？"B说"你呢？你就没有秘密吗？"
5. **沉默型**：角色不说话，用动作/表情代替
   - 例：A问"你还爱我吗？"B没有回答，只是转过身去

**潜台词设计步骤**：
1. 明确每个角色在这个场景中**真正想要什么**（深层目标）
2. 明确他们**害怕什么/不想暴露什么**
3. 设计他们**表面上说什么**（用来掩盖真实目标/恐惧的话）
4. 让读者通过上下文、动作、语气感受到他们没说出来的话

**潜台词和冲突的关系**：
- 当角色的真实目标和他们说的话矛盾时，就产生了张力
- 读者知道角色在回避/撒谎，会期待真相被揭开
- 潜台词在高潮处被打破（角色终于说出真心话），产生情感爆发

### 人物语言差异化

**每个角色说话都应该不一样**，读者光看对话就能分辨是谁在说话。

**语言差异化的维度**：
1. **用词**：正式/口语/文雅/粗俗/专业术语/方言/外来词
2. **句式**：长句/短句/完整句/碎片化/疑问句多/陈述句多
3. **语速**：快/慢/停顿多/一口气说完
4. **语气**：温柔/尖锐/幽默/严肃/讽刺/讨好/冷漠
5. **口头禅**：独特的用词/习惯用语/说话的开头结尾
6. **说话方式**：喜欢反问/喜欢比喻/喜欢引用/喜欢打断/喜欢附和
7. **教育和背景**：用词和语法反映教育水平、职业、地域、阶层

**设计人物语言的方法**：
1. 为每个主要角色写一段"语言画像"：他怎么说话？为什么？
2. 给每个角色1-2个独特的语言特征（不要太多，否则刻意）
3. 检查：遮住说话人名字，读者能分辨是谁在说话吗？
4. 注意：语言差异要自然，不能为了差异而差异，要符合人物背景

**语言差异化示例**：
- 退休教授：长句，用词精准，喜欢引用，说话慢条斯理
- 街头混混：短句，粗口，俚语，说话快，喜欢挑衅
- 程序员：逻辑化，用技术比喻，说话直接，不擅长寒暄
- 小女孩：简单句，好奇，重复，想象力丰富，说话跳脱
- 外交官：圆滑，模棱两可，从不直接说不，永远留有余地

### 冲突对话

**冲突对话的核心**：双方都有目标，且目标对立，对话就是博弈。

**冲突对话的类型**：
1. **争吵**：情绪爆发，双方都在攻击/防御
2. **谈判**：理性博弈，双方在争取最大利益
3. **审讯**：一方在获取信息，另一方在隐瞒
4. **对峙**：双方摊牌，真相即将揭开
5. **说服**：一方试图改变另一方的想法/决定

**冲突对话的节奏**：
- 开头：试探，双方都在观察对方
- 发展：冲突升级，话语越来越直接/尖锐
- 高潮：关键信息被揭示/最伤人的话被说出/做出决定
- 结尾：一方获胜/双方破裂/达成妥协/留下悬念

**冲突对话技巧**：
1. **打断**：情绪激动时互相打断，增加紧张感
2. **重复**：重复某个词/句子，强调情绪
3. **升级**：从讨论事情→攻击对方人格→翻旧账
4. **沉默**：在最紧张的时候沉默，比说话更有力量
5. **动作配合**：对话时的动作（摔门、转身、握拳、流泪）增强情绪
6. **潜台词**：冲突中双方都在隐瞒真实感受，话里有话

**争吵对话的常见问题**：
- ❌ 双方都在喊口号，没有具体内容
- ❌ 争吵的原因太 trivial（为了一点小事吵翻天，不符合人物）
- ❌ 争吵解决得太快（上一秒吵，下一秒和好）
- ❌ 只有一方在输出，另一方只是听着

### 信息型对话

**核心挑战**：通过对话传递读者需要知道的信息，但不能像"念说明书"。

**信息型对话的问题**：
- "说明式对话"：角色说他们已经知道的事，只是为了告诉读者
- 例："你知道的，自从三年前你妻子去世后，你就一直一个人住..."（对方当然知道）

**自然传递信息的方法**：
1. **一方不知道，另一方解释**：信息差是自然的（新手问老手，孩子问父母）
2. **争论中带出信息**：双方对某事有不同看法，争论中自然揭示背景
3. **质问中带出信息**：一方质问另一方，被质问者的回答揭示信息
4. **回忆/闪回中带出**：角色回忆过去，自然带出背景信息
5. **环境/道具辅助**：通过角色看到的东西（照片、文件、物品）引出信息
6. **误解中带出**：角色的误解被纠正，过程中揭示真相

**信息型对话的原则**：
- 信息应该是角色**当下需要**的，不是为了读者而说
- 传递信息时应该有**冲突或情感**，不是平铺直叙
- 不要一次倒太多信息，分批传递
- 重要信息应该在有张力的场景中揭示

### 情感对话

**情感对话的核心**：不是直接说"我爱你/我恨你/我很伤心"，而是通过具体的话语和细节让读者感受到。

**情感对话类型**：
1. **告白**：表达爱意/好感，关键是时机和方式
2. **决裂**：关系破裂，关键是积累的矛盾爆发
3. **和解**：关系修复，关键是真诚和让步
4. **告别**：离别/死亡，关键是不舍和遗憾
5. **安慰**：一方安慰另一方，关键是共情和陪伴

**情感对话技巧**：
1. **说不出口**：最强烈的情感往往是说不出口的，用停顿、回避、动作代替
2. **具体的细节**：不说"我会想你"，说"我会想你煮的咖啡，还有你总是把书放反的习惯"
3. **未完成的句子**：话说到一半停住，比说完更有力量
4. **重复**：重复某个词/句子，表达情绪的强烈
5. **对比**：平时话多的人突然沉默，平时坚强的人突然流泪
6. **时机**：情感对话应该在有足够铺垫的时候出现，不能突兀

### 幽默对话

**幽默的类型**：
1. **反差幽默**：预期和实际的反差（严肃的人说搞笑的话，危险的场景出现搞笑反应）
2. **机智对答**：快速、聪明的回应（banter）
3. **错位幽默**：角色在错误的场合说错误的话
4. **自嘲**：角色拿自己开玩笑
5. **重复幽默**：同一个梗在不同场景重复出现，每次略有变化
6. **冷幽默**：面无表情地说搞笑的话

**幽默对话的原则**：
- 幽默应该符合人物性格（不是所有人都会开玩笑）
- 幽默应该服务于人物和情节，不是为了搞笑而搞笑
- 在紧张/悲伤的场景中加入适当的幽默，可以调节节奏
- 不要用歧视性/冒犯性的幽默

### 对话修订Checklist

- [ ] 这段对话有明确的功能吗？（推进情节/展示人物/制造冲突/传递信息）
- [ ] 有潜台词吗？角色说的和想的一样吗？
- [ ] 每个角色的说话方式有区别吗？（遮住名字能分辨是谁吗？）
- [ ] 有没有"说明式对话"？（角色说他们已经知道的事）
- [ ] 对话自然吗？像真人会说的话吗？
- [ ] 对话有节奏吗？（长短句交替，有停顿和沉默）
- [ ] 有没有太多副词？（"他生气地说"→用对话本身展示愤怒）
- [ ] 对话标签（"他说"/"她问"）是否过多？可以用动作代替吗？
- [ ] 对话中的信息是分批传递的吗？（不是一次倒完）
- [ ] 情感对话有足够的铺垫吗？

## 调用示例
**用户**：帮我写一段男女主决裂的对话，他们在一起五年，男主隐瞒了自己的真实身份
**技能输出**：
场景设定：深夜，公寓，女主刚发现男主的真实身份（他是卧底警察，接近她是为了调查她父亲）
潜台词设计：
- 她真正想要的：确认他对她的感情有多少是真的
- 她害怕的：五年的感情全是假的
- 他真正想要的：让她相信他的感情是真的
- 他害怕的：失去她，以及任务失败

对话（带潜台词标注）：
她把文件放在桌上，手指在发抖，但声音很平。"这是什么？"
（她已经知道了，但想听他怎么说——这是最后一次机会）
他看了一眼文件，脸色变了。"你从哪找到的？"
（他没有否认，第一反应是来源——这比文件本身更让她心寒）
"所以是真的。"她退后一步，像是在看一个陌生人，"五年。你演了五年。"
"不是演。"他往前走了一步，声音里有她从没听过的急切，"接近你是任务，但后来..."
"后来什么？"她笑了，笑声很轻，却比哭更让人难受，"后来你假戏真做了？林深，你连自己都骗吧？"
（她用他的全名称呼他——这是她生气到极点的标志）
他张了张嘴，却没说出话。他的手抬了一下，想碰她，又放下了。
（动作代替语言——他的犹豫比任何解释都更说明问题）
"你知道最讽刺的是什么吗？"她拿起外套，走到门口，"我爸一直说你不对劲，我还跟他吵。结果他是对的。"
她停在门口，没有回头。"任务完成了，林警官。你可以回去交差了。"
门关上的声音很轻，却像是什么东西碎了。
他站在原地，看着桌上的文件，很久没有动。

对话要点：
1. 没有直接说"我恨你"/"你骗了我"，而是通过具体的话和动作展示
2. 潜台词丰富：她的平静比爆发更有力量，他的沉默比解释更诚实
3. 人物语言差异化：她平时温柔，生气时反而很平静；他平时冷静，此刻却语无伦次
4. 细节：用全名称呼、手抬了又放下、门关上的声音
5. 结尾用动作和环境收尾，不是对话
