# 20-素材与知识库 · 技能

> 长期积累写作素材：金句库、场景库、人物原型库、参考资料分类、研究笔记。越用越值钱的个人写作资产。

## 何时调用
- 用户需要整理/积累写作素材
- 用户需要查找/使用已积累的素材
- 用户需要建立个人素材库系统
- 用户说"素材怎么整理/金句库/灵感积累"

## 输入要求
- 素材类型（金句/场景/人物/参考资料/研究笔记）
- 可选：具体的素材内容、想要的分类方式

## 输出格式
- 素材库系统设计（分类结构、标签体系、检索方法）
- 各类素材的记录模板
- 素材整理和分类建议
- 素材使用方法（如何在写作中调用素材）
- 素材库定期维护建议

## 核心方法论

### 素材库系统设计

**核心原则**：素材不是收藏，而是使用。积累的目的是为了在写作时能快速找到并使用。

**素材库分类结构**：

```
素材库/
├── 金句库/
│   ├── 对话金句.md
│   ├── 叙述金句.md
│   ├── 哲理金句.md
│   └── 按主题分类/（爱情/死亡/自由/孤独...）
├── 场景库/
│   ├── 动作场景.md
│   ├── 情感场景.md
│   ├── 环境描写.md
│   └── 按氛围分类/（紧张/温馨/恐怖/悲伤...）
├── 人物原型库/
│   ├── 主角原型.md
│   ├── 反派原型.md
│   ├── 配角原型.md
│   └── 人物关系模板.md
├── 设定素材库/
│   ├── 世界观设定.md
│   ├── 职业/行业资料.md
│   ├── 历史/文化资料.md
│   └── 科技/魔法设定.md
├── 参考作品库/
│   ├── 书籍笔记.md
│   ├── 影视分析.md
│   ├── 经典结构拆解.md
│   └── 优秀片段收藏.md
└── 研究笔记/
    ├── 按项目分类/
    └── 按主题分类/
```

**标签体系**：
- 每个素材打3-5个标签，方便检索
- 标签维度：类型/主题/情感/适用场景/来源
- 示例：#对话 #紧张 #悬疑 #两人对峙 #来自《白夜行》

**检索方法**：
- 按分类浏览
- 按标签搜索
- 按关键词搜索
- 建立"素材索引表"，记录每个素材的位置和关键词

### 金句库

**金句的类型**：
1. **对话金句**：角色说的精彩台词（有潜台词、有力量、有记忆点）
2. **叙述金句**：精彩的描写/比喻/概括（有画面感、有哲理）
3. **哲理金句**：关于人生/人性/世界的深刻观察
4. **情感金句**：精准表达某种情感的句子
5. **结构金句**：精彩的开头/结尾/转折句

**金句记录模板**：
```
原文：[金句内容]
来源：[书名/电影/作者，或原创]
类型：对话/叙述/哲理/情感/结构
主题：[爱情/死亡/自由/孤独/复仇...]
情感：[悲伤/温暖/愤怒/恐惧...]
适用场景：[什么时候可以用/化用]
我的化用：[我可以怎么用在自己的故事里]
标签：#... #...
```

**金句使用原则**：
- 不要直接抄袭，要化用（学习结构和角度，用自己的语言表达）
- 金句是灵感来源，不是替代品
- 积累时就思考"我可以怎么用"，不要只收藏不使用
- 定期回顾金句库，把已经内化的标记出来

### 场景库

**场景素材的类型**：
1. **动作场景**：打斗、追逐、战斗、危机
2. **情感场景**：告白、决裂、重逢、告别、安慰
3. **环境描写**：城市、乡村、自然、室内、天气
4. **氛围场景**：紧张、温馨、恐怖、悲伤、悬疑
5. **对话场景**：争吵、谈判、审讯、闲聊、告白

**场景记录模板**：
```
场景描述：[场景的核心内容和氛围]
来源：[书名/电影/原创]
类型：动作/情感/环境/氛围/对话
氛围：[紧张/温馨/恐怖/悲伤...]
关键技巧：[这个场景用了什么写作技巧]
  - 节奏：...
  - 感官：...
  - 视角：...
  - 潜台词：...
可借鉴点：[我可以学习什么]
我的化用：[我可以怎么用在自己的故事里]
标签：#... #...
```

**场景拆解方法**：
- 分析场景的结构（目标/冲突/转折/结果）
- 分析场景的节奏（快慢、张弛）
- 分析场景的感官细节（用了哪些感官）
- 分析场景的对话（有没有潜台词、语言差异化）
- 分析场景的视角（用了什么视角，为什么）
- 总结可借鉴的技巧

### 人物原型库

**人物原型的类型**：
1. **主角原型**：各种类型的主角（英雄/反英雄/普通人/受害者/复仇者...）
2. **反派原型**：各种类型的对手（野心家/极端理想主义者/被伤害者/纯粹的恶...）
3. **配角原型**：导师/盟友/对手/催化剂/良心/喜剧调剂...
4. **人物关系模板**：各种有张力的人物关系（宿敌/师徒/错位身份/秘密关系/相爱相杀...）

**人物原型记录模板**：

```
可借鉴点：[我可以学习什么]

标签：#... #...
```

**人物关系模板记录**：

### 参考作品库

**参考作品的记录方式**：
1. **书籍笔记**：读完一本书后的笔记（核心创意、结构、人物、精彩片段、可借鉴点）
2. **影视分析**：看完一部电影/剧后的分析（结构、节奏、镜头、表演、可借鉴点）
3. **经典结构拆解**：把经典作品的结构拆解开，学习其结构设计
4. **优秀片段收藏**：收藏优秀的片段，标注好在哪里

**研究笔记的类型**：
1. **按项目分类**：每个写作项目的研究资料

### 素材库维护

**定期维护**：
- **每周**：整理本周积累的素材，分类、打标签、写化用思路
- **每月**：回顾本月素材，把已经内化的标记出来，删除无用的
- **每季度**：整理素材库结构，优化分类和标签
- **每项目结束**：把项目中的研究笔记和优秀片段归档到素材库

**素材使用流程**：
1. 写作前：浏览相关分类的素材，寻找灵感
2. 写作中：遇到需要的场景/人物/设定，搜索素材库
3. 写作后：把写作中产生的好想法/好片段归档到素材库
4. 修订时：用素材库中的优秀片段作为参考，提升质量

**素材库的核心价值**：
- 越用越值钱：积累越多，写作时可调用的资源越多
- 减少卡文：有素材库作为灵感来源，不容易写不下去
- 提升质量：有优秀作品作为参考，写作质量会逐步提升
- 个人风格：通过积累和化用，逐步形成自己的写作风格

## 调用示例
**用户**：我想建立一个金句库，怎么开始？
**技能输出**：
金句库建立指南：

1. **准备工具**：
   - 用一个文档/笔记软件（Notion/印象笔记/飞书文档/纯文本都可以）
   - 建立分类：对话金句、叙述金句、哲理金句、情感金句
   - 或者按主题分类：爱情、死亡、自由、孤独、复仇、成长...

2. **积累方法**：
   - 读书/看电影时，遇到让你心动的句子，立刻记下来
   - 不要只记句子，还要记：来源、类型、主题、你为什么喜欢
   - 最重要的：写一句"我的化用"——你可以怎么用在自己的故事里
   - 每天积累1-3句就够了，质量比数量重要

3. **记录模板**：
   ```
   原文："..."
   来源：《书名》作者
   类型：对话/叙述/哲理/情感
   主题：爱情/死亡/自由...
   为什么好：[这句话好在哪里]
   我的化用：[我可以怎么用]
   标签：#... #...
   ```

4. **使用方法**：
   - 写作前：浏览相关主题的金句，寻找灵感
   - 写作中：遇到需要表达某种情感/主题时，搜索金句库
   - 注意：不要直接抄袭，要化用——学习句子的结构、角度、节奏，用自己的语言和故事表达
   - 金句是灵感来源，不是替代品

5. **定期维护**：
   - 每周整理本周积累的金句
   - 每月回顾，把已经内化的标记出来
   - 每季度删除不再喜欢的金句，保持库的质量
   - 目标：积累100句高质量金句，你的写作会有明显提升

6. **起步建议**：
   - 先从你最喜欢的3本书/3部电影开始，每本提取5句你最喜欢的
   - 这样一开始就有15句，建立信心
   - 然后养成习惯，每天积累1句
   - 3个月后你会有90+句，这是一笔宝贵的写作资产

示例（帮你写3条作为起步）：
```
原文："世上只有一种英雄主义，就是在认清生活真相之后依然热爱生活。"
来源：《米开朗基罗传》罗曼·罗兰
类型：哲理
主题：英雄主义/生活/热爱
为什么好：用"只有一种"的绝对化表达，加上"认清真相"和"依然热爱"的对比，有力量感
我的化用：可以用在主角经历重大打击后重新站起来的场景，或者作为主题句
标签：#哲理 #英雄主义 #生活 #成长

原文："她一次也没有回头。"
来源：《白夜行》东野圭吾
类型：叙述/情感
主题：决绝/失去/爱情
为什么好：极其简洁，7个字，却有巨大的情感冲击力，留白让读者自己感受
我的化用：可以用在角色彻底放弃/决裂/离开的场景，用极简的动作表达强烈的情感
标签：#叙述 #情感 #决绝 #留白

原文："如果你要驯服一个人，就要冒着掉眼泪的危险。"
来源：《小王子》圣埃克苏佩里
类型：对话/哲理
主题：爱情/驯服/风险
为什么好：用"驯服"这个独特的词，加上"掉眼泪的危险"，把爱情的风险和美好结合在一起
我的化用：可以用在角色犹豫是否要投入一段感情/关系时，或者作为主题句
标签：#对话 #哲理 #爱情 #风险
```

从这3句开始，逐步建立你的金句库。记住：质量比数量重要，每句都要写"我的化用"，这样才是真正属于你的素材。
