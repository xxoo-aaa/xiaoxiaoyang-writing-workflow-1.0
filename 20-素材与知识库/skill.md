# 20-素材与知识库 · 技能

> 长期积累写作素材：金句库、场景库、人物原型库、参考资料分类、研究笔记。越用越值钱的个人写作资产。

## 何时调用
- 用户需要整理/积累写作素材
- 用户需要查找/使用已积累的素材
- 用户需要建立个人素材库系统
- 用户说"素材怎么整理/金句库/灵感积累"

## 输入要求
- 素材类型（金句/场景/人物/参考资料/研究笔记）
- 可选：具体的素材内容、想要的分类方式

## 输出格式
- 素材库系统设计（分类结构、标签体系、检索方法）
- 各类素材的记录模板
- 素材整理和分类建议
- 素材使用方法（如何在写作中调用素材）
- 素材库定期维护建议

## 核心方法论

### 素材库系统设计

**核心原则**：素材不是收藏，而是使用。积累的目的是为了在写作时能快速找到并使用。

**素材库分类结构**：

```
素材库/
├── 金句库/
│   ├── 对话金句.md
│   ├── 叙述金句.md
│   ├── 哲理金句.md
│   └── 按主题分类/（爱情/死亡/自由/孤独...）
├── 场景库/
│   ├── 动作场景.md
│   ├── 情感场景.md
│   ├── 环境描写.md
│   └── 按氛围分类/（紧张/温馨/恐怖/悲伤...）
├── 人物原型库/
│   ├── 主角原型.md
│   ├── 反派原型.md
│   ├── 配角原型.md
│   └── 人物关系模板.md
├── 设定素材库/
│   ├── 世界观设定.md
│   ├── 职业/行业资料.md
│   ├── 历史/文化资料.md
│   └── 科技/魔法设定.md
├── 参考作品库/
│   ├── 书籍笔记.md
│   ├── 影视分析.md
│   ├── 经典结构拆解.md
│   └── 优秀片段收藏.md
└── 研究笔记/
    ├── 按项目分类/
    └── 按主题分类/
```

**标签体系**：
- 每个素材打3-5个标签，方便检索
- 标签维度：类型/主题/情感/适用场景/来源
- 示例：#对话 #紧张 #悬疑 #两人对峙 #来自《白夜行》

**检索方法**：
- 按分类浏览
- 按标签搜索
- 按关键词搜索
- 建立"素材索引表"，记录每个素材的位置和关键词

### 金句库

**金句的类型**：
1. **对话金句**：角色说的精彩台词（有潜台词、有力量、有记忆点）
2. **叙述金句**：精彩的描写/比喻/概括（有画面感、有哲理）
3. **哲理金句**：关于人生/人性/世界的深刻观察
4. **情感金句**：精准表达某种情感的句子
5. **结构金句**：精彩的开头/结尾/转折句

**金句记录模板**：
```
原文：[金句内容]
来源：[书名/电影/作者，或原创]
类型：对话/叙述/哲理/情感/结构
主题：[爱情/死亡/自由/孤独/复仇...]
情感：[悲伤/温暖/愤怒/恐惧...]
适用场景：[什么时候可以用/化用]
我的化用：[我可以怎么用在自己的故事里]
标签：#... #...
```

**金句使用原则**：
- 不要直接抄袭，要化用（学习结构和角度，用自己的语言表达）
- 金句是灵感来源，不是替代品
- 积累时就思考"我可以怎么用"，不要只收藏不使用
- 定期回顾金句库，把已经内化的标记出来

### 场景库

**场景素材的类型**：
1. **动作场景**：打斗、追逐、战斗、危机
2. **情感场景**：告白、决裂、重逢、告别、安慰
3. **环境描写**：城市、乡村、自然、室内、天气
4. **氛围场景**：紧张、温馨、恐怖、悲伤、悬疑
5. **对话场景**：争吵、谈判、审讯、闲聊、告白

**场景记录模板**：
```
场景描述：[场景的核心内容和氛围]
来源：[书名/电影/原创]
类型：动作/情感/环境/氛围/对话
氛围：[紧张/温馨/恐怖/悲伤...]
关键技巧：[这个场景用了什么写作技巧]
  - 节奏：...
  - 感官：...
  - 视角：...
  - 潜台词：...
可借鉴点：[我可以学习什么]
我的化用：[我可以怎么用在自己的故事里]
标签：#... #...
```

**场景拆解方法**：
- 分析场景的结构（目标/冲突/转折/结果）
- 分析场景的节奏（快慢、张弛）
- 分析场景的感官细节（用了哪些感官）
- 分析场景的对话（有没有潜台词、语言差异化）
- 分析场景的视角（用了什么视角，为什么）
- 总结可借鉴的技巧

### 素材库维护

**定期维护**：
- **每周**：整理本周积累的素材，分类、打标签、写化用思路
- **每月**：回顾本月素材，把已经内化的标记出来，删除无用的
- **每季度**：整理素材库结构，优化分类和标签
- **每项目结束**：把项目中的研究笔记和优秀片段归档到素材库

**素材使用流程**：
1. 写作前：浏览相关分类的素材，寻找灵感
2. 写作中：遇到需要的场景/人物/设定，搜索素材库
3. 写作后：把写作中产生的好想法/好片段归档到素材库
4. 修订时：用素材库中的优秀片段作为参考，提升质量

**素材库的核心价值**：
- 越用越值钱：积累越多，写作时可调用的资源越多
- 减少卡文：有素材库作为灵感来源，不容易写不下去
- 提升质量：有优秀作品作为参考，写作质量会逐步提升
- 个人风格：通过积累和化用，逐步形成自己的写作风格

## 调用示例
**用户**：我想建立一个金句库，怎么开始？
**技能输出**：
金句库建立指南：

1. **准备工具**：
   - 用一个文档/笔记软件（Notion/印象笔记/飞书文档/纯文本都可以）
   - 建立分类：对话金句、叙述金句、哲理金句、情感金句
   - 或者按主题分类：爱情、死亡、自由、孤独、复仇、成长...

2. **积累方法**：
   - 读书/看电影时，遇到让你心动的句子，立刻记下来
   - 不要只记句子，还要记：来源、类型、主题、你为什么喜欢
   - 最重要的：写一句"我的化用"——你可以怎么用在自己的故事里
   - 每天积累1-3句就够了，质量比数量重要

3. **记录模板**：
   ```
   原文："..."
   来源：《书名》作者
   类型：对话/叙述/哲理/情感
   主题：爱情/死亡/自由...
   为什么好：[这句话好在哪里]
   我的化用：[我可以怎么用]
   标签：#... #...
   ```

4. **使用方法**：
   - 写作前：浏览相关主题的金句，寻找灵感
   - 写作中：遇到需要表达某种情感/主题时，搜索金句库
   - 注意：不要直接抄袭，要化用——学习句子的结构、角度、节奏，用自己的语言和故事表达
   - 金句是灵感来源，不是替代品

5. **定期维护**：
   - 每周整理本周积累的金句
   - 每月回顾，把已经内化的标记出来
   - 每季度删除不再喜欢的金句，保持库的质量
   - 目标：积累100句高质量金句，你的写作会有明显提升

6. **起步建议**：
   - 先从你最喜欢的3本书/3部电影开始，每本提取5句你最喜欢的
   - 这样一开始就有15句，建立信心
   - 然后养成习惯，每天积累1句
   - 3个月后你会有90+句，这是一笔宝贵的写作资产

示例（帮你写3条作为起步）：
```
原文："世上只有一种英雄主义，就是在认清生活真相之后依然热爱生活。"
来源：《米开朗基罗传》罗曼·罗兰
类型：哲理
主题：英雄主义/生活/热爱
为什么好：用"只有一种"的绝对化表达，加上"认清真相"和"依然热爱"的对比，有力量感
我的化用：可以用在主角经历重大打击后重新站起来的场景，或者作为主题句
标签：#哲理 #英雄主义 #生活 #成长

原文："她一次也没有回头。"
来源：《白夜行》东野圭吾
类型：叙述/情感
主题：决绝/失去/爱情
为什么好：极其简洁，7个字，却有巨大的情感冲击力，留白让读者自己感受
我的化用：可以用在角色彻底放弃/决裂/离开的场景，用极简的动作表达强烈的情感
标签：#叙述 #情感 #决绝 #留白

原文："如果你要驯服一个人，就要冒着掉眼泪的危险。"
来源：《小王子》圣埃克苏佩里
类型：对话/哲理
主题：爱情/驯服/风险
为什么好：用"驯服"这个独特的词，加上"掉眼泪的危险"，把爱情的风险和美好结合在一起
我的化用：可以用在角色犹豫是否要投入一段感情/关系时，或者作为主题句
标签：#对话 #哲理 #爱情 #风险
```

从这3句开始，逐步建立你的金句库。记住：质量比数量重要，每句都要写"我的化用"，这样才是真正属于你的素材。

## 正反示例对比

### 示例：素材积累的好与坏

❌ **差的素材积累**：
> 小明读了很多书，看到好句子就复制粘贴到一个叫"素材"的文档里。
> 一年后，他的素材文档有10万字，分类混乱，没有标签，没有来源，没有"我的化用"。
> 写作时，他想找一句关于"孤独"的金句，搜索了半天，找到20句，但不知道哪句好、怎么用。
> 最后，他要么直接抄一句（有抄袭风险），要么干脆不用（素材库白建了）。
>
> （问题：只收藏不整理，没有分类标签，没有"我的化用"，素材库变成了垃圾场，用的时候找不到、不会用。）

✅ **好的素材积累**：
> 小明读了很多书，看到好句子就立刻记录到金句库，格式统一：
> ```
> 原文："她一次也没有回头。"
> 来源：《白夜行》东野圭吾
> 类型：叙述/情感
> 主题：决绝/失去
> 为什么好：极简，7个字，巨大的情感冲击力，留白
> 我的化用：用在角色彻底放弃/离开的场景，用极简动作表达强烈情感
> 标签：#叙述 #情感 #决绝 #留白
> ```
> 他每周整理一次素材，分类清晰，标签统一。
> 写作时，他搜索"决绝"，立刻找到5句，每句都有"我的化用"提示。
> 他选择一句，学习它的"极简+留白"手法，用自己的语言写："他关上门，没有再看一眼。"
> 不是抄袭，是化用——学习了手法，表达了自己的故事。
>
> （好的原因：格式统一、分类清晰、有标签、有"我的化用"、定期维护，素材库是真正能用的工具，不是收藏夹。）

### 示例：场景拆解的好与坏

❌ **差的场景拆解**：
> 小明看了一部电影，觉得一个打斗场景很棒。
> 他在素材库里写："《XX电影》打斗场景，很棒。"
> 三个月后，他看到这条记录，完全不记得那个场景好在哪里、怎么用。
>
> （问题：只记录了"很棒"，没有拆解技巧，没有可借鉴点，没有"我的化用"，等于没记录。）

✅ **好的场景拆解**：
> 小明看了一部电影，觉得一个打斗场景很棒。
> 他在场景库里详细拆解：
> ```
> 场景描述：主角在狭窄走廊里和三个对手打斗，空间极其有限
> 来源：《XX电影》
> 类型：动作
> 氛围：紧张、窒息
> 关键技巧：
>   - 节奏：先慢（主角观察环境）→ 快（突然爆发）→ 慢（最后一击），张弛交替
>   - 空间：利用狭窄空间制造窒息感，主角利用环境（墙壁、管道）作为武器
>   - 感官：强调声音（骨头断裂声、呼吸声）和触觉（汗水、血迹），少用视觉全景
>   - 视角：近距离跟拍，让观众有代入感
> 可借鉴点：打斗场景不一定要大场面，小空间+近距离+声音设计可以更紧张
> 我的化用：写小说中的打斗场景时，用小空间+感官细节+节奏变化，而不是"他一拳打过去，对方倒下了"
> 标签：#动作 #紧张 #小空间 #节奏 #感官
> ```
> 三个月后，他写打斗场景时，搜索"动作"，找到这条拆解，立刻回忆起那个场景的技巧，用在自己的小说里。

## 常见问题及解法

| 问题 | 表现 | 解法 |
|------|------|------|
| **素材库越积越乱** | 收藏了很多，但分类混乱，找不到 | 建立统一的分类和标签体系；每周花15分钟整理新素材；不要追求完美分类，能找到就行 |
| **只收藏不使用** | 素材库很大，但写作时从来不用 | 每条素材都必须写"我的化用"；写作前先浏览相关素材；把素材使用纳入写作流程 |
| **不知道该积累什么** | 看到什么都想收藏，结果什么都没积累好 | 聚焦你正在写的项目和你最薄弱的写作环节；质量比数量重要，每天1-3条高质量素材就够了 |
| **素材重复** | 同一句金句/同一个场景收藏了好几次 | 定期去重；建立索引表，收藏前先搜索是否已有；相似的合并，保留最好的 |
| **直接抄袭** | 把素材库里的金句直接抄到自己的作品里 | 金句是灵感来源，不是替代品；学习结构和角度，用自己的语言表达；引用要注明来源 |
| **素材过时** | 几年前收藏的素材，现在看已经不喜欢了 | 定期清理，每季度删除不再喜欢的素材；素材库是活的，不是博物馆；保留你真正会用的 |
| **不知道怎么拆解** | 觉得一个场景很棒，但说不出好在哪里 | 用拆解清单逐项分析：结构/节奏/感官/视角/对话/潜台词；先模仿别人的拆解，慢慢就会了 |
| **素材太多记不住** | 素材库有几千条，但写作时想不起来用 | 不要追求记住所有素材；写作时主动搜索相关关键词；定期回顾，把最常用的标记为"精华" |
| **工具选择困难** | 不知道用什么工具建素材库 | 用你最习惯的工具就行——Notion/印象笔记/飞书文档/纯文本/Excel都可以；工具不重要，坚持使用才重要 |
| **积累了但写作没提升** | 素材库很大，但写作质量没变化 | 检查：你真的在用素材吗？你在化用还是只是收藏？素材要转化为技巧，不是囤积；每次写作后回顾，哪些素材用上了，哪些没用 |

## 素材与知识库质量自检清单

每月复盘素材库时，用以下清单自检：

### 素材库结构
- [ ] 分类结构清晰吗？（金句/场景/人物/设定/参考作品/研究笔记）
- [ ] 标签体系统一吗？（每条素材3-5个标签）
- [ ] 有检索方法吗？（分类浏览/标签搜索/关键词搜索）
- [ ] 有索引表吗？（重要素材的位置和关键词）

### 素材质量
- [ ] 每条素材都有来源吗？
- [ ] 每条素材都有"我的化用"吗？（最重要）
- [ ] 每条素材都有标签吗？
- [ ] 有重复的素材吗？（需要去重）
- [ ] 有已经过时/不再喜欢的素材吗？（需要清理）

### 素材使用
- [ ] 写作前会浏览相关素材吗？
- [ ] 写作中会主动搜索素材库吗？
- [ ] 写作后会把好想法归档到素材库吗？
- [ ] 修订时会用素材库参考吗？
- [ ] 上个月有多少条素材真正用上了？（使用率）

### 维护习惯
- [ ] 每周整理新素材吗？（分类、打标签、写化用）
- [ ] 每月回顾素材库吗？（标记精华、删除无用）
-  [ ] 每季度优化分类和标签吗？
- [ ] 项目结束后会把研究笔记归档吗？

### 核心价值
- [ ] 素材库帮你减少卡文了吗？
- [ ] 素材库帮你提升写作质量了吗？
- [ ] 素材库是"活的"（经常使用和更新）还是"死的"（只收藏不使用）？
- [ ] 你能在5分钟内找到需要的素材吗？

**任何一项不通过，下个月重点改进。记住：素材库的核心价值不是"大"，而是"能用"——一个100条高质量、每条都有"我的化用"的素材库，比一个10000条只收藏不整理的素材库有用得多。**

---

> **素材与知识库的终极目标**：让你不再"书到用时方恨少"，而是"需要的时候立刻能找到"。好的素材库不是收藏夹，是武器库——每一件武器都经过打磨（拆解技巧）、都有使用说明（我的化用）、都能在战斗中派上用场（写作时调用）。当你可以在写作时随手调用积累的素材，把别人的技巧变成自己的能力——你的素材库就成功了。
