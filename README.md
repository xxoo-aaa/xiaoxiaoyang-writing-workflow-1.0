# 小羊写作工作流 1.2

> 一个中心技能 + 32个次级技能的 AI 辅助写作系统。帮你更便捷地写出吸引人、想法特殊、内容丰富的小说、剧本、短剧和商业广告。

## 这是什么

这不是一个存放稿件的仓库，而是一个**写作工具箱和技能系统**。你从这里获取方法、模板、流程，用到你的实际写作项目中。

核心模式：**中心技能调用次级技能**。你用自然语言说出需求，中心技能理解后自动调用对应的专业技能来完成任务。

## 快速开始

### 方式一：直接说需求
不用记技能名，直接用自然语言描述你要做什么：

- "帮我想一个科幻短篇的点子"
- "帮我设计一个有魅力的反派"
- "这一章结尾不够抓人，帮我改改"
- "帮我把这篇小说改编成短剧"
- "帮我写一个护肤品的广告创意剧本"
- "启动一个长篇小说项目"
- "启动写作搭档，我只有个模糊想法"

中心技能会自动识别该调用哪个技能。

### 方式二：按文体走完整流程
- **短篇小说**：创意 → 选题 → 人物 → 大纲 → 场景 → 钩子 → 修订
- **长篇小说**：创意 → 类型 → 世界观 → 人物 → 大纲 → 冲突 → 主题 → 写作 → 修订
- **电影剧本**：创意 → 人物 → 大纲 → 剧本格式 → 台词 → 修订
- **短剧改编**：原著分析 → 分集大纲 → 钩子设计 → 台词 → 审核
- **商业广告**：Brief解读 → 受众洞察 → 创意概念 → 剧本创作 → 合规审核

详见 [00-快速启动/](00-快速启动/)

## 使用原则

1. **这是工具箱，不是稿件库** — 稿件存在你的项目里，这里只存方法和模板
2. **自然语言驱动** — 不用记技能名，直接说你要干什么
3. **增量式构建** — 不用一次想清楚所有事，先搭框架，逐步深化
4. **项目记忆** — 中心技能会记住你的项目上下文，不用每次重复输入
5. **模板拿来即用** — 从 templates/ 复制模板到你的项目中使用，不要直接改原模板
