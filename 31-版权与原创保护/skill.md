# 31-版权与原创保护

> 你的作品是你的心血，也是你的资产。版权保护不是"等被侵权了再想办法"，是"从创作第一天就开始保护"。本模块提供版权基础知识、原创自查方法、合同注意事项和维权路径——这些是一般性信息，不构成法律意见，具体法律问题请咨询专业律师。

---

## 一、版权基础知识

### 什么是版权

版权（著作权）是作者对其创作的文学、艺术和科学作品依法享有的专有权利。

**版权包括**：
- **人身权**：发表权、署名权、修改权、保护作品完整权（不可转让）
- **财产权**：复制权、发行权、出租权、展览权、表演权、放映权、广播权、信息网络传播权、摄制权、改编权、翻译权、汇编权等（可以转让或许可）

### 版权的取得

**自动取得原则**：作品创作完成之日起，作者自动享有版权，不需要登记或申请。

**但登记有好处**：
- 登记证书是权利的初步证明，维权时更方便
- 有些平台/出版社要求提供登记证书
- 交易/授权时更有说服力

### 版权保护期限

- **作者人身权**（署名权、修改权、保护作品完整权）：永久保护
- **作者财产权**：作者终生 + 死后50年（中国）；作者终生 + 死后70年（美国/欧盟等多数国家）
- **法人作品**：发表后50年

### 不受版权保护的内容

- 思想、概念、方法、制度（版权保护表达，不保护思想）
- 法律法规、官方文件
- 时事新闻
- 历法、通用数表、通用表格和公式
- 过于简短的标题、口号（可能受商标法保护，但不受版权法保护）

## 二、原创性自查

### 什么是原创

原创不是"完全不借鉴"，而是"用自己的方式表达"。借鉴是正常的，但抄袭是违法的。

**借鉴 vs 抄袭**：
- **借鉴**：受某作品启发，用自己的方式表达，加入自己的创新
- **抄袭**：直接复制他人的表达（文字、情节、人物设定等），没有自己的创新

### 原创自查五步法

#### 第一步：文字相似度自查

**操作**：检查你的文字是否和已有作品高度相似。

**方法**：
- 用查重工具（如知网、PaperPass、Grammarly的查重功能）检查文字重复率
- 网络文学可以用"百度搜索"搜索关键段落，看是否有重复
- 注意：通用表达、常用句式不算抄袭，但大段连续重复就是问题

**标准**：
- 连续超过100字和他人作品完全一致 → 高度疑似抄袭
- 核心情节、人物设定高度相似 → 可能构成"实质性相似"
- 通用设定（如"主角是孤儿""有一个神秘的导师"）不算抄袭

#### 第二步：情节/设定自查

**操作**：检查你的核心情节、人物设定、世界观是否和已有作品高度相似。

**方法**：
- 列出你的核心设定（主角身份、核心冲突、关键情节、世界观规则）
- 和同类型热门作品对比，看是否有"实质性相似"
- 注意：类型套路（如"升级流""重生复仇"）是公共素材，不算抄袭，但具体的情节组合和人物关系如果高度相似，可能有问题

**标准**：
- 核心设定完全一样（主角名字、身份、经历、关键情节都一样）→ 抄袭
- 类型套路相同但具体表达不同 → 正常借鉴
- 致敬/同人创作 → 需要明确标注，且不能用于商业用途（除非获得授权）

#### 第三步：素材来源自查

**操作**：检查你使用的素材（图片、音乐、引用文字等）是否有版权。

**方法**：
- 引用他人文字要注明出处，且引用比例不能过高
- 使用图片要确认版权（免费可商用的图库如Unsplash、Pexels；有版权的图片要获得授权）
- 音乐、视频素材同理
- 注意："网上找到的"不等于"可以随便用"

#### 第四步：AI生成内容自查

**操作**：如果你使用了AI辅助写作，检查AI生成的内容是否有版权风险。

**方法**：
- AI生成的内容可能和已有作品相似（AI是基于大量数据训练的）
- 重要内容要用查重工具检查
- 不要直接复制AI生成的大段文字，要进行修改和个性化
- 注意：目前AI生成内容的版权归属在各国法律中尚不明确，建议在作品中注明AI使用情况

#### 第五步：整体评估

**操作**：综合以上四步，评估作品的原创性。

**评估标准**：
- 文字重复率低于10% → 安全
- 核心设定有自己的创新 → 安全
- 素材都有授权或来自公共领域 → 安全
- AI生成内容经过充分修改 → 安全
- 如有任何一项不达标 → 修改后再发布

### 常见"灰色地带"

| 情况 | 是否侵权 | 建议 |
|------|---------|------|
| 写同人小说（基于已有作品的角色和世界观） | 可能侵犯原作者的改编权 | 非商业、明确标注"同人创作"通常可以；商业用途需要获得授权 |
| 借鉴类型套路（如"重生复仇""系统升级"） | 不侵权（套路是公共素材） | 但具体情节和人物要有自己的创新 |
| 致敬经典（引用经典作品的台词/情节） | 少量、明确的致敬通常可以 | 不要大段复制，要加入自己的创新 |
| 翻译国外作品并发布 | 侵犯翻译权 | 需要获得原作者或出版社的授权 |
| 用AI生成图片作为封面 | AI生成图片的版权尚不明确 | 建议使用有明确版权的图片，或自己设计 |
| 改编真实事件 | 不侵犯版权（事实不受保护） | 但要注意隐私权和名誉权，不要诽谤真实人物 |
| 书名和已有作品相同 | 书名通常不受版权保护 | 但可能构成不正当竞争，建议取独特的书名 |

## 三、合同注意事项

### 签约前必看的条款

#### 1. 版权归属

**关键问题**：作品的版权归谁？

- **作者保留版权**：最好的情况，你只是授权平台/出版社使用
- **平台/出版社拥有版权**：要谨慎，可能意味着你失去了对作品的控制权
- **共同拥有**：需要明确各自的权利范围

**建议**：尽量保留版权，只授权特定的权利（如信息网络传播权）。

#### 2. 授权范围

**关键问题**：你授权了哪些权利？授权范围有多大？

- **权利种类**：是只授权信息网络传播权，还是包括改编权、翻译权、影视化权等？
- **地域范围**：是只授权中国大陆，还是全球？
- **语言范围**：是只授权中文，还是包括所有语言？
- **平台范围**：是只授权某一个平台，还是包括其关联平台？

**建议**：授权范围越小越好，不要"全权利""全球""永久"授权。

#### 3. 授权期限

**关键问题**：授权多久？到期后版权归谁？

- **固定期限**：如3年、5年，到期后权利回归作者
- **永久授权**：要非常谨慎，可能意味着你永远失去了这些权利
- **作品保护期内**：有些合同写"版权保护期内"，相当于永久

**建议**：尽量签固定期限（3-5年），到期后可以续约或收回。

#### 4. 报酬与分成

**关键问题**：你能拿到多少钱？怎么算？什么时候付？

- **买断**：一次性拿到一笔钱，之后的收益和你无关
- **分成**：按收入的一定比例分成（如订阅收入的50%）
- **保底+分成**：先拿一笔保底金，之后再分成
- **付费时间**：月结？季结？有没有最低支付额？

**建议**：
- 分成比例要明确（是按总收入还是净收入？扣除哪些成本？）
- 要有知情权（平台要提供销售数据）
- 要有审计权（你可以查账）
- 注意"净收入"的定义（平台可能扣除很多成本后再分成）

#### 5. 违约责任

**关键问题**：如果一方违约，怎么办？

- 平台违约（如不按时付钱、擅自扩大授权范围）：你有什么救济？
- 你违约（如断更、一稿多投）：有什么惩罚？
- 违约金是否合理？

**建议**：违约责任要对等，不能只约束作者不约束平台。

#### 6. 解约条款

**关键问题**：什么情况下可以解约？解约后版权归谁？

- 作者解约权：什么情况下你可以解约？（如平台连续X个月不付钱）
- 平台解约权：什么情况下平台可以解约？
- 解约后的处理：未结算的报酬怎么付？作品怎么处理？

**建议**：确保你有合理的解约权，解约后版权能回归。

### 签约前的检查清单

- [ ] 版权归属明确吗？（尽量保留版权）
- [ ] 授权范围明确吗？（权利种类、地域、语言、平台）
- [ ] 授权期限合理吗？（尽量固定期限，不要永久）
- [ ] 报酬和分成明确吗？（比例、计算方式、支付时间）
- [ ] 有知情权和审计权吗？
- [ ] 违约责任对等吗？
- [ ] 解约条款合理吗？
- [ ] 有没有"霸王条款"？（如"所有权利归平台""永久授权""违约金过高"）
- [ ] 合同条款和平台宣传一致吗？
- [ ] 你理解合同的每一条吗？（不理解的要问，不要签看不懂的合同）

**重要提示**：签约前最好让专业律师看一下合同，尤其是大额合同或长期合同。

## 四、原创保护方法

### 方法一：创作过程存证

**操作**：在创作过程中保留证据，证明你是原创作者。

**方法**：
- **时间戳存证**：用可信时间戳服务（如联合信任时间戳服务中心）为作品草稿存证
- **区块链存证**：用区块链存证平台（如至信链、司法链）存证
- **邮件存证**：把作品草稿发给自己的邮箱，邮件的时间戳可以作为证据
- **云文档版本历史**：用有版本历史的云文档（如飞书、Google Docs），版本记录可以作为证据
- **本地文件保留**：保留创作过程中的各个版本草稿

### 方法二：版权登记

**操作**：作品完成后，到版权登记机构进行登记。

**方法**：
- **中国**：中国版权保护中心（http://www.ccopyright.com.cn），可以线上申请
- **美国**：U.S. Copyright Office（https://www.copyright.gov）
- **其他国家**：各国都有相应的版权登记机构

**好处**：
- 登记证书是权利的初步证明
- 维权时更方便
- 交易/授权时更有说服力

### 方法三：发布时的保护

**操作**：在发布作品时采取措施，防止被盗用。

**方法**：
- **加水印**：在图片/视频上加水印（文字作品不太适用）
- **分段发布**：不要一次性发布全部内容，分段发布，被盗用时可以及时发现
- **保留首发证据**：在平台发布时，平台的发布时间可以作为首发证据
- **声明版权**：在作品开头或结尾注明"版权所有，未经授权不得转载"

### 方法四：侵权监测

**操作**：定期监测是否有人盗用你的作品。

**方法**：
- **搜索引擎搜索**：定期用百度/Google搜索作品中的关键段落
- **平台监测**：在主要平台（如起点、番茄、Wattpad、Amazon）搜索你的作品名
- **第三方监测服务**：可以使用专业的版权监测服务
- **读者举报**：鼓励读者发现盗版后举报

### 方法五：维权路径

**操作**：发现侵权后，按以下步骤维权。

**步骤**：
1. **取证**：截图、录屏、公证，保存侵权证据
2. **通知平台**：向侵权平台发送侵权通知（DMCA Takedown Notice），要求下架
3. **发送律师函**：如果平台不处理或侵权严重，发送律师函
4. **行政投诉**：向版权局、文旅局等行政部门投诉
5. **诉讼**：如果以上都无效，向法院提起诉讼

**注意**：
- 维权要及时，不要等侵权扩散后再处理
- 证据要充分（侵权内容、侵权时间、侵权范围、你的权利证明）
- 可以寻求专业律师的帮助
- 有些平台有快速维权通道（如起点的盗版投诉通道）

## 五、AI写作的版权问题

### 当前状况

AI生成内容的版权归属在各国法律中尚不明确，是一个快速发展的领域。

**主要观点**：
- **中国**：目前倾向于认为AI生成内容不具有版权（因为不是人类创作），但如果人类进行了足够的创造性投入，可能享有版权
- **美国**：美国版权局目前不登记完全由AI生成的内容，但如果有足够的人类创造性贡献，可以登记
- **欧盟**：正在制定相关法规，倾向于要求AI生成内容标注来源

### 建议

1. **AI是工具，不是作者**：把AI当作辅助工具，最终的创作和决策由你做出
2. **充分修改**：不要直接复制AI生成的内容，要进行充分的修改和个性化
3. **保留创作过程**：保留你和AI的对话记录、修改过程，证明你的创造性投入
4. **标注AI使用**：在作品中注明是否使用了AI辅助（有些平台要求）
5. **关注法律变化**：AI版权法律在快速变化，定期关注最新动态

## 六、国内/海外版权差异

### 中国版权制度特点

- **版权自动取得**：创作完成即享有版权，登记是自愿的
- **保护期限**：作者终生 + 死后50年
- **行政保护强**：版权局、文旅局等行政部门可以进行行政处罚
- **平台责任**：平台有"通知-删除"义务，收到侵权通知后要及时处理
- **网络文学版权**：各大平台有比较完善的版权保护体系，但盗版仍然存在

### 美国版权制度特点

- **版权自动取得**：创作完成即享有版权，但登记是诉讼的前提
- **保护期限**：作者终生 + 死后70年
- **法定赔偿**：登记后可以主张法定赔偿（最高15万美元/作品），不需要证明实际损失
- **DMCA Takedown**：数字千年版权法，平台有"通知-删除"义务
- **诉讼成本高**：美国诉讼成本高，但赔偿额也高

### 海外维权建议

1. **在目标市场登记版权**：如果作品在海外发行，建议在目标国家登记版权
2. **了解目标市场的法律**：不同国家的版权法有差异
3. **使用国际版权条约**：中国和大多数国家都加入了《伯尔尼公约》，作品在成员国自动受保护
4. **寻求当地律师**：海外维权需要当地律师的帮助
5. **平台投诉**：Amazon、Wattpad等平台都有侵权投诉通道

## 七、常见问题及解法

| 问题 | 说明 | 解法 |
|------|------|------|
| **我的作品被抄袭了怎么办？** | 发现有人大段复制你的作品 | 取证→通知平台→律师函→行政投诉→诉讼 |
| **我可以写同人小说吗？** | 基于已有作品的角色和世界观创作 | 非商业、明确标注通常可以；商业用途需要获得原作者授权 |
| **我可以翻译国外作品吗？** | 把国外作品翻译成中文 | 需要获得原作者或出版社的翻译权授权，否则侵权 |
| **书名和别人一样怎么办？** | 书名通常不受版权保护 | 但可能构成不正当竞争，建议取独特书名 |
| **平台合同是霸王条款怎么办？** | 合同条款明显不公平 | 不要签；可以和平台协商；寻求律师帮助 |
| **我可以用网上的图片做封面吗？** | 网上的图片大多有版权 | 使用免费可商用图库（Unsplash、Pexels等），或获得授权，或自己设计 |
| **AI生成的内容有版权吗？** | 目前法律尚不明确 | 充分修改，保留创作过程，标注AI使用，关注法律变化 |
| **我的作品在多个平台发布算一稿多投吗？** | 同时在多个平台发布 | 看合同约定——如果合同有独家授权要求，就不能在其他平台发布 |
| **改编真实人物的故事侵权吗？** | 基于真实人物创作 | 事实不受版权保护，但要注意隐私权和名誉权，不要诽谤 |
| **版权到期后作品怎么办？** | 版权保护期过后进入公共领域 | 任何人都可以免费使用，但作者的署名权等人身权永久保护 |
| **我可以注册书名/角色名的商标吗？** | 书名/角色名可以注册为商标 | 如果作品有商业价值（如IP开发），可以考虑注册商标保护 |
| **合作创作的作品版权归谁？** | 多人合作创作 | 版权归合作作者共同所有，需要明确各自的份额和权利行使方式 |

## 八、正反示例对比

### 示例：合同条款的好与坏

❌ **差的合同条款**：
> 作者将作品的所有权利（包括但不限于信息网络传播权、复制权、发行权、改编权、翻译权、影视化权、游戏化权等）在全球范围内永久授权给平台，平台有权自行决定如何使用作品，无需另行通知作者。作品收益的分成比例由平台根据经营情况自行决定。

（问题：授权范围太大（所有权利、全球、永久）；分成比例不明确；平台权力过大；作者没有任何保障。）

✅ **好的合同条款**：
> 作者将作品的中文简体字信息网络传播权在中国大陆地区授权给平台，授权期限为3年，自作品上线之日起计算。平台按月向作者支付订阅收入的50%作为分成，每月15日前结算上月收益，并提供详细的销售数据。作者有权查阅平台的销售记录。任何一方违约，守约方有权解除合同并要求赔偿。合同到期后，所有授权权利回归作者。

（好的原因：授权范围明确（中文简体、信息网络传播权、中国大陆、3年）；分成比例和支付时间明确；作者有知情权和查账权；违约责任对等；到期后权利回归作者。）

## 十、版权与原创保护质量自检清单

发布作品或签约前，用以下清单自检：

### 原创性
- [ ] 文字重复率低于10%吗？
- [ ] 核心设定有自己的创新吗？（不是完全照搬他人）
- [ ] 使用的素材（图片、音乐、引用文字）都有版权或来自公共领域吗？
- [ ] AI生成内容经过充分修改了吗？
- [ ] 没有大段复制他人作品吗？

### 版权保护
- [ ] 保留了创作过程的证据吗？（草稿、版本历史、时间戳）
- [ ] 作品完成后进行版权登记了吗？（建议）
- [ ] 发布时注明了版权声明吗？
- [ ] 定期监测侵权了吗？

### 合同
- [ ] 版权归属明确吗？（尽量保留版权）
- [ ] 授权范围明确吗？（权利种类、地域、语言、平台）
- [ ] 授权期限合理吗？（不要永久授权）
- [ ] 报酬和分成明确吗？（比例、计算方式、支付时间）
- [ ] 有知情权和审计权吗？
- [ ] 违约责任对等吗？
- [ ] 解约条款合理吗？
- [ ] 没有"霸王条款"吗？
- [ ] 合同让专业律师看过了吗？（大额/长期合同建议）

### AI使用
- [ ] AI是辅助工具，最终创作由你完成吗？
- [ ] 保留了和AI的对话记录和修改过程吗？
- [ ] 作品中标注了AI使用情况吗？（如平台要求）
- [ ] 关注了AI版权法律的最新动态吗？

### 海外
- [ ] 了解目标市场的版权法吗？
- [ ] 在目标市场登记版权了吗？（如需要）
- [ ] 翻译权、海外发行权在合同中明确了吗？
- [ ] 知道海外维权的路径吗？

**任何一项不通过，在发布或签约前解决。**

---

> **版权与原创保护的终极目标**：让你的心血得到应有的尊重和回报。版权保护不是"和世界为敌"，是"为自己的创作负责"。当你从第一天就开始保护自己的作品，你才能在未来安心地创作、放心地授权、开心地收获。记住：你的作品有价值，而价值需要保护。
