# 16-吸引力工程 · 技能

> 工程化地设计吸引力：钩子、节奏、悬念、情感曲线、翻页欲。让人停不下来。

## 何时调用
- 用户觉得故事不够吸引人、读者会弃文
- 用户需要设计开篇钩子/章节结尾钩子
- 用户需要控制故事的节奏和张力
- 用户说"不够抓人/钩子怎么写/节奏怎么控制"

## 输入要求
- 故事类型和目标读者
- 故事大纲或具体场景
- 可选：觉得不吸引人的具体段落

## 输出格式
- 钩子设计方案（开篇钩子/章节结尾钩子/情节转折点）
- 节奏控制方案（紧张/舒缓的分布，张弛曲线）
- 悬念管理方案（伏笔追踪、信息差、读者预期管理）
- 情感曲线设计（泪点/爽点/燃点/虐点的位置和铺垫）
- 开篇诊断与修改建议
- 吸引力Checklist

## 核心方法论

### 钩子设计

**什么是钩子**：让读者产生"我想知道接下来会怎样"的冲动的任何设计

**钩子的类型**：

**1. 开篇钩子（前3页/前500字）**
- **悬念钩**：开头就抛出一个悬念/谜团（"她死的那天，我正在和她的情人吃饭"）
- **冲突钩**：开头就进入激烈冲突（打斗/争吵/危机）
- **反常识钩**：开头说一件违背常识的事，让读者好奇（"我丈夫死了三次"）
- **身份钩**：开头展示一个有特殊身份/处境的人（"我是一个职业骗子，专门骗骗子"）
- **危机钩**：开头就让角色处于危险中（"炸弹还有三分钟爆炸，而我被绑在椅子上"）
- **情感钩**：开头就有强烈的情感冲击（生离死别/背叛/重逢）
- **独特声音钩**：叙事者的声音非常有个性，让人想继续听下去

**开篇钩子的原则**：
- 前3行内就要有钩子（不要从"阳光明媚的早晨"开始）
- 钩子要和故事核心有关（不是为了钩而钩，和后面的故事脱节）
- 钩子要提出问题，让读者想知道答案
- 不要用虚假钩子（开头很刺激，后面和开头没关系）

**2. 章节结尾钩子（翻页钩）**
- **悬念钩**：章节结尾抛出一个新的悬念/谜团
- **危机钩**：角色在章节结尾遇到危险/危机
- **转折钩**：章节结尾发生一个意想不到的转折
- **揭示钩**：章节结尾揭示一个重要信息/真相
- **情感钩**：章节结尾有强烈的情感冲击
- **选择钩**：角色面临一个艰难的选择，读者想知道他选了什么
- **到来钩**：有人/有事即将到来，读者想知道是什么

**章节结尾钩子的原则**：
- 每章结尾都应该有钩子（至少是微妙的）
- 钩子的强度应该和故事的节奏匹配（紧张章节强钩子，舒缓章节弱钩子）
- 不要每章都是同一种钩子（交替使用不同类型）
- 钩子要在章节最后1-2段，不要太早

**3. 情节转折点钩子**
- 激励事件（打破日常）
- 第一幕转折点（进入新世界）
- 中点（故事方向改变）
- 最低点（一切似乎失去）
- 高潮前的最终选择
- 每个转折点都应该是一个大钩子，让读者想继续看

### 节奏控制

**节奏的本质**：不是"一直快"，而是"快慢交替，有张有弛，让读者在紧张和释放之间循环"

**节奏工具**：

1. **场景长度**
   - 紧张场景：短、快、句子短、段落短
   - 舒缓场景：长、慢、句子长、段落长
   - 交替使用，不要连续多个短场景（会疲劳）或连续多个长场景（会无聊）

2. **信息密度**
   - 关键场景：信息密集，每句话都有新信息
   - 过渡场景：信息稀疏，更多是氛围和情感
   - 在高密度场景后给读者喘息的空间

3. **时间处理**
   - 紧张时刻：拉伸时间（慢动作，详细描写每个瞬间）
   - 过渡时刻：压缩时间（"三天过去了"）
   - 在高潮前可以用倒计时增加紧张感

4. **视角切换**
   - 在紧张处切换视角，增加悬念（"A正在危险中，切到B在做什么"）
   - 注意切换的清晰度和节奏

5. **副线穿插**
   - 在主线紧张时插入副线，给读者喘息，同时增加对主线的期待
   - 副线本身也应该有张力，不是完全的放松

6. **悬念延迟**
   - 在高潮前插入短暂的平静/日常，增加紧张感（"暴风雨前的宁静"）
   - 读者知道大事即将发生，看着角色还在日常中，会更紧张

**节奏曲线（标准三幕）**：
- 第一幕：建立节奏，逐步加速（从日常到冲突）
- 第二幕前半：上升，有小高潮和喘息
- 中点：重大转折，节奏改变（通常加速）
- 第二幕后半：持续加速，压力越来越大，喘息空间越来越小
- 最低点：短暂的停滞/绝望（节奏最慢的时刻，但张力最大）
- 第三幕：全速冲向高潮（节奏最快）
- 高潮后：减速，余韵（节奏慢下来，给读者消化的时间）

**节奏检查**：
- [ ] 有没有连续3个以上的快节奏场景？（需要插入舒缓场景）
- [ ] 有没有连续3个以上的慢节奏场景？（需要加快节奏）
- [ ] 每个紧张场景后有喘息吗？
- [ ] 高潮前有"暴风雨前的宁静"吗？
- [ ] 场景长度和节奏匹配吗？
- [ ] 读者会不会在某个段落感到疲劳/无聊？

### 悬念管理

**悬念和钩子的区别**：钩子是瞬间的（让你想翻下一页），悬念是持续的（让你一直想知道真相）

**悬念的维持**：
1. **提出问题**：每个悬念都是一个问题（"凶手是谁？""他能活下来吗？""他们会在一起吗？"）
2. **延迟答案**：不要太快给出答案
3. **给出线索**：在延迟的过程中，逐步给出线索，让读者可以推理
4. **给出误导**：同时给出误导线索，让读者猜错方向
5. **提高stakes**：让悬念的后果越来越严重
6. **部分揭示**：每次揭示一部分，同时提出新问题
7. **最终揭示**：在高潮处揭示最终答案

**伏笔追踪表**：
| 伏笔 | 埋设位置 | 内容 | 计划回收位置 | 状态 |
|---|---|---|---|---|
| 神秘电话 | 第5章 | 搭档接了个神秘电话 | 第25章（高潮） | 已埋未收 |
| 消失的证据 | 第8章 | 关键证据不见了 | 第22章 | 已埋未收 |
| ... | ... | ... | ... | ... |

**读者预期管理**：
- **建立预期**：让读者形成某种预期（"他们会在一起"、"他会赢"）
- **打破预期**：在适当的时候打破预期（"他们分手了"、"他输了"）
- **超越预期**：最终给出比读者预期更好的结果（"虽然分手了，但他们都成长了，而且...")
- 注意：不要一直打破预期（读者会觉得被耍），也不要一直符合预期（读者会觉得无聊）

### 情感设计

**情感曲线**：好的故事让读者经历一系列情感变化，而不是一直是同一种情感

**常见情感点设计**：

1. **爽点**：读者感到痛快/满足的时刻
   - 设计：长期压抑后的爆发、反派被打脸、主角逆袭、真相大白
   - 铺垫：爽点之前必须有足够的压抑/委屈/期待
   - 注意：爽点不能太频繁（会麻木），也不能没有（会憋屈）

2. **泪点**：读者感到悲伤/感动的时刻
   - 设计：生离死别、牺牲、重逢、误解消除、角色的成长/救赎
   - 铺垫：泪点之前必须有足够的情感积累（读者关心这个角色/这段关系）
   - 注意：不要为了虐而虐（角色的苦难要有意义）

3. **燃点**：读者感到热血/振奋的时刻
   - 设计：主角站起来、团队合作、面对强敌不退缩、信念的力量
   - 铺垫：燃点之前必须有低谷/绝望（从绝望中站起来最燃）
   - 注意：燃点要有信念和情感支撑，不是单纯的打斗

4. **虐点**：读者感到心疼/压抑的时刻
   - 设计：误解、背叛、失去、求而不得、角色的痛苦
   - 铺垫：虐点之前必须有美好（曾经有多美好，失去时就有多虐）
   - 注意：虐点要有意义（推动角色成长/情节发展），不要为了虐而虐

5. **笑点**：读者感到轻松/愉快的时刻
   - 设计：角色的幽默、反差萌、机智对答、轻松的日常
   - 作用：在紧张/悲伤后调节情绪，让读者放松
   - 注意：幽默要符合人物性格，不要在严肃场景强行搞笑

**情感曲线设计原则**：
- 情感要有起伏，不要一直是同一种
- 每种情感点之前要有足够的铺垫
- 强烈的情感点之后要有缓冲（让读者消化）
- 情感点的强度应该逐步升级（后面的情感点比前面的更强）
- 高潮应该是情感最强烈的时刻

### 开篇诊断

**开篇（前500字/前3页）的检查清单**：

- [ ] 前3行内有钩子吗？（不是从天气/起床/赶路开始）
- [ ] 读者能快速知道主角是谁、他想要什么吗？
- [ ] 有冲突或张力吗？（不是平静的日常）
- [ ] 有独特性吗？（这个开头和其他故事有什么不同？）
- [ ] 读者会想知道"接下来会怎样"吗？
- [ ] 有没有大段的背景说明？（应该推后）
- [ ] 有没有介绍太多人物？（开篇只需要1-2个核心人物）
- [ ] 叙事声音有个性吗？
- [ ] 开篇和故事核心有关吗？（不是虚假钩子）

**常见开篇问题及修改**：
- ❌ "阳光明媚的早晨，XX起床了..." → ✅ 从冲突/悬念/独特场景开始
- ❌ 大段世界观介绍 → ✅ 先讲故事，世界观在需要时再揭示
- ❌ 介绍所有人物和关系 → ✅ 只介绍当前需要的，其他后面再说
- ❌ 平淡的日常，没有冲突 → ✅ 从日常中的异常/冲突开始
- ❌ 开头很刺激但和后面没关系 → ✅ 钩子要和故事核心关联

## 调用示例
**用户**：我的小说开篇是"林深坐在咖啡馆里，看着窗外的雨。她在等一个人。"帮我改成更有吸引力的开头
**技能输出**：
问题分析：
1. 太平淡，没有冲突或悬念
2. "等一个人"太模糊，读者不知道为什么要关心
3. 没有独特性（很多故事都是这样开头）
4. 没有钩子（读者不想知道接下来会怎样）

修改方案（提供3个方向）：

方向一（悬念钩）：
"林深已经在这家咖啡馆坐了三个小时。
她等的人，应该在两年前就死了。
门铃响了。
她抬起头，看到那个本不该存在的人，正朝她走来。"

方向二（反常识钩）：
"林深是来杀他的。
但她先得喝完这杯咖啡。
因为她妈妈说过，杀人前要吃饱，不然手抖。
她看着窗外的雨，数着时间。还有五分钟，他就会走进这家咖啡馆。
她摸了摸包里的刀，深吸一口气。
这是她第一次杀人。
希望也是最后一次。"

方向三（情感+悬念钩）：
"这是林深第一百次来这家咖啡馆。
也是最后一次。
因为今天，她要告诉那个男人，她怀了他的孩子——
而他的妻子，此刻就坐在隔壁桌。
雨敲打着窗户，像是倒计时。
门铃响了。
他来了。"

推荐方向二，因为：
1. 开头就有强烈的悬念和反差（杀人前先喝咖啡，妈妈说杀人前要吃饱）
2. 主角有独特的性格和声音（紧张但有幽默感，第一次杀人）
3. 有明确的倒计时和目标（还有五分钟，他会来）
4. 读者会想知道：她为什么要杀他？她能成功吗？她妈妈是什么人？
5. 和故事核心（如果是悬疑/犯罪/黑色幽默）直接相关

进一步建议：
- 开篇后立刻进入冲突（他来了，她准备动手，但发生了意外）
- 不要在第一章解释她为什么要杀他（用行动和对话逐步揭示）
- 在第一章结尾留一个强钩子（比如她发现他也带了武器，或者他说出了让她震惊的话）
...（完整的开篇修改方案）
