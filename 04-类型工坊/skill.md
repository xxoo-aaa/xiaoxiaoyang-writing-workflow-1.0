# 04-类型工坊 · 技能

> 各类型小说的专门方法论。写什么类型就用什么方法，不再一把钥匙开所有锁。

## 何时调用
- 用户确定要写某个类型，需要该类型的创作方法
- 用户需要了解某类型的惯例、读者期待、雷区
- 用户需要某类型的经典结构和套路
- 用户说"我想写科幻/悬疑/言情..."

## 输入要求
- 具体类型（科幻/奇幻/悬疑/言情/历史/恐怖/武侠/都市等）
- 可选：子类型（如科幻下的赛博朋克/太空歌剧）

## 输出格式
- 该类型的核心特征和读者期待
- 经典结构和套路
- 必须遵守的惯例和可以打破的惯例
- 常见雷区和避坑指南
- 该类型的创作 Checklist
- 推荐参考作品

## 各类型方法论要点

### 科幻
**核心特征**：基于科学/技术设定的"如果...会怎样"推演，核心是思想实验
**读者期待**：设定有逻辑自洽性，科技对社会/人性的影响有深度思考
**经典结构**：
- 软科幻：人物和情感为主，科技为背景
- 硬科幻：科技设定为核心，逻辑推演为主
- 赛博朋克：高科技+低生活，企业控制、义体、黑客
- 太空歌剧：星际尺度的冒险和史诗
**必须遵守**：核心科技设定的规则一旦建立，不能违反
**可以打破**：科学准确性（软科幻可以牺牲准确性换取故事性）
**雷区**：
- 科技设定只是背景板，没有对故事产生实质影响
- 大段科技说明变成百科全书
- 用"科技魔法"解决所有问题（deus ex machina）
**创作Checklist**：
- [ ] 核心科技设定是什么？它的规则和限制是什么？
- [ ] 这个科技如何改变了社会/人性/人际关系？
- [ ] 主角的冲突和这个科技有什么本质联系？
- [ ] 有没有为了剧情方便而违反设定规则？

### 悬疑/推理
**核心特征**：信息差驱动的解谜过程，核心是"谁干的/怎么干的/为什么"
**读者期待**：线索公平（读者和侦探获得相同信息）、逻辑严密、反转有说服力
**经典结构**：
- 本格推理：密室/不可能犯罪，逻辑解谜
- 社会派：案件背后的社会问题和人性
- 悬疑惊悚：氛围和紧张感为主，解谜为辅
- 反转流：多重反转，最后颠覆所有认知
**必须遵守**：关键线索必须在前文出现过，不能最后才抛出
**可以打破**：侦探必须是警察/专业人士（可以是普通人）
**雷区**：
- 靠巧合破案
- 凶手是之前没出现过的人
- 关键线索最后才揭示（对读者不公平）
- 反转生硬，为了反转而反转
**创作Checklist**：
- [ ] 核心谜题是什么？（谁/怎么/为什么）
- [ ] 所有关键线索是否都在前文埋下？
- [ ] 有没有至少3个嫌疑人，每个人都有动机？
- [ ] 反转是否有铺垫，而不是凭空出现？
- [ ] 读者能不能根据已有线索推理出真相？

### 言情
**核心特征**：人物关系的发展和情感张力，核心是"两个人为什么会爱上/不能爱"
**读者期待**：情感真实细腻、人物有化学反应、关系发展有层次
**经典结构**：
- 甜宠：轻松甜蜜，误会少，主要看互动
- 虐恋：误会/身份/命运阻碍，情感波折大
- 强强：双方都强，势均力敌的爱情
- 破镜重圆：分开后重新走到一起
**必须遵守**：情感发展要有铺垫，不能一见钟情就生死相许
**可以打破**：必须是HE（可以是BE，但要符合故事逻辑）
**雷区**：
- 人物为了虐而强行降智/误会
- 恋爱脑，除了恋爱什么都不做
- 一方完全依附另一方，没有独立性
- 情感转变突兀，没有过程
**创作Checklist**：
- [ ] 两个人为什么会互相吸引？（不是因为"主角光环"）
- [ ] 他们之间的核心障碍是什么？（外部/内部/身份）
- [ ] 关系发展有几个阶段？（初识→试探→靠近→危机→确认）
- [ ] 两个人是否都有独立的人格和目标？
- [ ] 情感高潮点在哪里？是否有足够的铺垫？

### 奇幻
**核心特征**：构建一个有自身规则的异世界，核心是"在这个世界里发生的故事"
**读者期待**：世界观有自洽性、有新奇感、冒险和成长
**经典结构**：
- 史诗奇幻：宏大世界，多视角，命运之战
- 都市奇幻：现代世界+隐藏的超自然元素
- 黑暗奇幻：道德灰色，残酷现实
- 轻松奇幻：冒险+幽默，低压力
**必须遵守**：世界的规则（魔法/神力/种族）一旦建立，不能随意违反
**可以打破**：必须有魔法系统（可以是低魔/无魔世界）
**雷区**：
- 世界观设定复杂但和故事无关（设定堆砌）
- 魔法没有限制，想干嘛干嘛
- 主角是天选之子，一路开挂
- 种族设定刻板（精灵都是高贵的，兽人都是野蛮的）
**创作Checklist**：
- [ ] 这个世界的核心规则是什么？（魔法/科技/社会结构）
- [ ] 这些规则如何影响普通人的生活？
- [ ] 主角的冒险和这个世界的核心矛盾有什么关系？
- [ ] 超自然力量的限制和代价是什么？
- [ ] 有没有为了剧情方便而打破世界规则？

### 历史
**核心特征**：基于真实历史背景的故事，核心是"在那个时代，这样的人会怎样"
**读者期待**：时代感真实、细节考究、历史与虚构的平衡
**经典结构**：
- 历史正剧：重大历史事件，真实人物
- 历史言情：历史背景下的爱情
- 穿越历史：现代人回到古代
- 历史悬疑：古代背景的案件
**必须遵守**：重大历史事件和人物的基本事实不能错
**可以打破**：小人物的命运可以虚构（历史空白处自由创作）
**雷区**：
- 历史常识错误（官职、服饰、制度、语言）
- 用现代价值观强行评判古人
- 穿越者用现代知识碾压一切（不考虑时代限制）
- 为了剧情改变重大历史事件的结果
**创作Checklist**：
- [ ] 故事发生的具体年代和社会背景是什么？
- [ ] 当时的政治/经济/文化/日常生活是什么样？
- [ ] 主角的身份和行为符合那个时代吗？
- [ ] 涉及的真实历史人物和事件是否准确？
- [ ] 有没有需要考据的细节？（调用21-研究与考据）

### 恐怖/惊悚
**核心特征**：通过未知、危险、氛围唤起恐惧情绪，核心是"读者感到害怕"
**读者期待**：氛围营造到位、恐惧有层次、不是单纯的血腥
**经典结构**：
- 心理恐怖：未知和暗示，最可怕的是想象
- 超自然恐怖：鬼/怪物/诅咒
- 生存恐怖：封闭空间+危险+求生
- 社会恐怖：日常中的不对劲（细思极恐）
**必须遵守**：恐怖的规则一旦建立要遵守（比如鬼杀人的条件）
**可以打破**：必须有怪物（可以是纯粹的心理恐惧）
**雷区**：
- 全靠jump scare，没有持续的紧张感
- 怪物/鬼的能力模糊，想怎样就怎样
- 主角降智，明明危险还要去作死
- 结尾用"都是梦"敷衍
**创作Checklist**：
- [ ] 恐惧的来源是什么？（未知/死亡/失控/孤独/...）
- [ ] 恐怖的规则和限制是什么？
- [ ] 氛围是如何营造的？（环境/声音/节奏/暗示）
- [ ] 恐惧是否有递进？（从不安→害怕→恐惧→绝望）
- [ ] 主角的反应是否合理？（不是无脑作死）

### 武侠/仙侠
**核心特征**：东方奇幻体系，武功/修仙+江湖/仙界，核心是"侠"与"道"
**读者期待**：武学/修仙体系有层次感、江湖/仙界有氛围感、人物有侠气
**经典结构**：
- 传统武侠：江湖恩怨，武功对决，侠之大者
- 新派武侠：更注重人物和人性，武功为辅助
- 仙侠：修仙升级，仙界格局，天道因果
- 玄幻：高魔世界，升级流，宏大格局
**必须遵守**：武学/修仙等级体系一旦建立要一致
**可以打破**：必须有明确的等级（可以是模糊的武学境界）
**雷区**：
- 战力体系崩坏，前期设定后期推翻
- 升级太快，没有过程和代价
- 江湖/仙界没有生活感，只有打斗
- 主角光环，所有厉害的都归主角
**创作Checklist**：
- [ ] 武学/修仙体系的等级和规则是什么？
- [ ] 升级的条件和代价是什么？
- [ ] 江湖/仙界的势力分布和规则是什么？
- [ ] 主角的"侠"或"道"是什么？（核心精神）
- [ ] 战力体系是否前后一致？

## 调用示例
**用户**：我想写一个悬疑短篇，给我讲讲悬疑怎么写
**技能输出**：
悬疑的核心是信息差驱动的解谜。写悬疑要注意：
1. 核心谜题要清晰（谁干的/怎么干的/为什么）
2. 线索必须公平，关键线索要在前文出现
3. 至少3个嫌疑人，每人都有动机
4. 反转要有铺垫，不能凭空出现
5. 避免靠巧合破案、凶手是没出现过的人
...（附悬疑创作Checklist和参考作品推荐）
