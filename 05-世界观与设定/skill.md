# 05-世界观与设定 · 技能

> 构建有历史纵深、有矛盾根源、有生活质感的深度世界，而不是一张设定清单。

## 何时调用
- 用户需要设计故事的世界观/背景设定
- 用户觉得世界观单薄，需要深化
- 用户需要检查世界观的自洽性
- 用户说"帮我设计一个世界观"

## 输入要求
- 故事类型和大致方向
- 已有的设定想法（可以是模糊的）
- 可选：参考作品、想要的氛围

## 输出格式
- 世界观核心设定（世界规则、核心矛盾）
- 历史纵深（这个世界过去发生过什么）
- 社会结构（权力、阶层、制度）
- 日常生活（普通人怎么生活）
- 地理与环境
- 设定自洽性检查
- 世界观与故事的关联分析

## 核心方法论

### 世界观构建五层次

**第一层：核心规则**
- 这个世界最根本的规则是什么？（魔法体系/科技水平/社会制度/自然法则）
- 这个规则的限制和代价是什么？（没有限制的力量会毁掉故事）
- 普通人如何感知/受影响于这个规则？

**第二层：历史纵深**
- 这个世界的历史上发生过哪些重大事件？（战争/革命/灾难/发现）
- 这些事件如何塑造了现在的世界？（遗留的矛盾/制度/文化）
- 有哪些被遗忘/被掩盖的历史真相？（这通常是故事的暗线）
- 上一代人经历了什么？这一代人的困境和上一代有什么关系？

**第三层：社会结构**
- 权力如何分配？（谁统治？谁被统治？权力的来源是什么？）
- 社会阶层如何划分？（阶层之间能否流动？矛盾在哪里？）
- 主流价值观和禁忌是什么？（什么被赞扬？什么被唾弃？）
- 法律和秩序如何维持？（谁执行？有没有灰色地带？）

**第四层：日常生活**
- 普通人一天怎么过？（吃什么？住在哪里？怎么工作？怎么娱乐？）
- 经济系统如何运转？（用什么货币？主要产业是什么？贫富差距如何？）
- 文化和信仰？（宗教/信仰/节日/艺术/习俗）
- 科技/魔法在日常生活中的应用？（不是只有战斗时才用）

**第五层：地理与环境**
- 世界的地理格局？（大陆/国家/城市/重要地点）
- 气候和自然环境？（对生活和文化有什么影响？）
- 重要地点和它们的意义？（每个重要地点都应该和故事有关）
- 交通和通讯？（人们怎么旅行？怎么传递信息？）

### 世界观与故事的关联
好的世界观不是独立存在的，它必须服务于故事：
- 世界的核心矛盾 = 主角面临的核心冲突的根源
- 世界的规则限制 = 主角遇到的障碍
- 世界的历史真相 = 故事的暗线/反转来源
- 世界的社会结构 = 人物关系和身份冲突的来源
- 世界的日常生活 = 场景的真实感和细节来源

**检查问题**：如果把这个故事放到另一个世界观里，故事还成立吗？如果成立，说明世界观和故事没有本质关联，需要加强。

### 设定自洽性检查清单
- [ ] 核心规则是否有明确的限制和代价？
- [ ] 有没有为了剧情方便而违反设定规则的地方？
- [ ] 历史事件的因果链是否合理？
- [ ] 社会结构是否能稳定存在（或者为什么正在崩溃）？
- [ ] 经济系统是否能支撑描述的生活水平？
- [ ] 地理和气候是否影响了文化和生活方式？
- [ ] 不同群体对同一事件/规则的看法是否不同？
- [ ] 有没有"所有人都这样想"的刻板设定？

### 世界观呈现技巧
- **不要一次性倾倒**：通过人物的行动和对话自然展现设定
- **从具体到抽象**：先写一个人怎么用魔法生火，再写魔法体系的规则
- **展示矛盾**：通过不同角色对同一规则的不同态度展示世界的复杂性
- **留白**：不需要解释所有事情，留下神秘感和想象空间
- **细节真实**：一个生动的生活细节比一千字的设定说明更有效

## 调用示例
**用户**：帮我设计一个赛博朋克世界观
**技能输出**：
核心规则：企业取代政府，义体改造普及，网络和现实边界模糊
历史纵深：2045年"大崩溃"后，国家解体，七大企业接管世界；2060年"义体战争"，改造人和纯人类的冲突...
社会结构：企业高管（0.1%）→ 技术人员/中层（9%）→ 底层（90%）；义体改造程度成为新的阶层标志...
日常生活：底层住在叠层贫民窟，吃合成食品，用廉价义体；高管住在浮空城，身体几乎全改造...
...（完整五层次设定）
与故事的关联：主角是底层义体维修师，发现自己的义体里藏着企业的秘密...
