# 03-灵感与选题 · 技能

> 灵感捕捉、选题判断、核心概念提炼。从一堆想法中选出最值得写的那个。

## 何时调用
- 用户有多个想法，需要判断写哪个
- 用户需要评估一个选题的可行性
- 用户需要把模糊想法提炼成清晰的核心概念
- 用户说"这个题材怎么样/能不能写"

## 输入要求
- 选题/想法描述（可以是模糊的）
- 可选：目标文体、目标平台、个人偏好

## 输出格式
- 选题评估报告（市场潜力、创作难度、独特性、适合度）
- 核心概念提炼（一句话版本 + 三句话版本）
- 选题决策建议
- 如果选题有问题，给出调整方向

## 核心方法论

### 灵感捕捉法
1. **随时记录**：灵感出现时立即记下来，哪怕只有几个关键词
2. **灵感卡片格式**：
   ```
   日期：
   灵感关键词：
   来源（看到什么/想到什么触发的）：
   一句话描述：
   可能的发展方向：
   兴奋度评分（1-10）：
   ```
3. **定期整理**：每周回顾灵感库，把相关的灵感合并，把过时的删除
4. **灵感发酵**：好的灵感需要时间发酵，不要急于立刻写，放一放再看

### 选题评估六维模型
对每个候选选题从六个维度打分（1-10分）：

| 维度 | 评估问题 | 高分标准 |
|---|---|---|
| **独特性** | 这个故事和我看过的有什么不同？ | 有新颖的设定/角度/结构 |
| **情感潜力** | 这个故事能让人产生强烈情感吗？ | 有让人哭/笑/怒/思的潜力 |
| **冲突强度** | 核心冲突够不够大、够不够个人化？ | 冲突关乎主角的核心需求和身份 |
| **可写性** | 以我目前的能力和资源能写好吗？ | 设定不超出我的知识范围，人物数量可控 |
| **延展性** | 这个概念能撑到目标字数吗？ | 有足够的支线、转折、深度可挖 |
| **个人热情** | 我是不是真的很想写这个？ | 想到就兴奋，愿意花几个月在上面 |

**决策规则**：
- 总分≥45且没有单项≤4 → 强烈推荐
- 总分35-44 → 可以写，但需要补强短板
- 总分<35或有单项≤3 → 建议放弃或大幅调整
- 个人热情≤5的直接放弃（写不下去的）

### 核心概念提炼
把模糊想法提炼成清晰的核心概念，分三个层次：

**一句话概念**（电梯演讲，30秒内能说清）
公式：`[主角]是[身份]，当[触发事件]发生，他必须[目标]，否则[代价]`

**三句话概念**
1. 第一句：设定和主角
2. 第二句：核心冲突和转折
3. 第三句：主题和情感内核

**一段话概念**（500字以内）
- 世界观设定
- 主角和他的需求
- 触发事件
- 核心冲突
- 主要转折
- 结局方向
- 主题

### 选题常见问题与调整
| 问题 | 表现 | 调整方向 |
|---|---|---|
| 概念太大 | 世界观复杂，人物众多，短篇装不下 | 缩小范围，聚焦一个核心冲突 |
| 概念太小 | 只有一个场景的量，撑不起长篇 | 扩展世界观，增加副线和人物 |
| 太像某作品 | 读者一眼就能看出模仿 | 找到差异化的核心角度 |
| 没有冲突 | 只有设定没有故事 | 给主角一个明确的目标和障碍 |
| 主题先行 | 想表达一个道理，但故事不好看 | 先让故事好看，主题自然呈现 |

## 调用示例
**用户**：我有两个想法，一个是时间循环的悬疑，一个是末世里的厨师，帮我选一个写短篇
**技能输出**：
| 维度 | 时间循环悬疑 | 末世厨师 |
|---|---|---|
| 独特性 | 6（时间循环较多） | 8（厨师+末世少见） |
| 情感潜力 | 7 | 8（食物+情感天然连接） |
| 冲突强度 | 7 | 6 |
| 可写性 | 7（逻辑要求高） | 8 |
| 延展性 | 6（短篇合适） | 7 |
| 个人热情 | ？ | ？ |
...（需要你补充个人热情评分）
初步评估：末世厨师更适合短篇，独特性和情感潜力更高。时间循环悬疑对逻辑要求高，短篇容易写得仓促。
建议：选择末世厨师，核心概念提炼为：末世中唯一会做正宗中餐的厨师，用一道菜解开一个关于食物和记忆的谜团...
