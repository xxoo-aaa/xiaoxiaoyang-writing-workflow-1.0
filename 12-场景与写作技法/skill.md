# 12-场景与写作技法 · 技能

> 写好每一个场景：场景结构、感官细节、动作描写、氛围营造、展示而非说明。

## 何时调用
- 用户需要写/修改具体场景
- 用户觉得场景写得干/平/没有画面感
- 用户需要场景写作的技巧和方法
- 用户说"这一幕怎么写/场景写不好"

## 输入要求
- 场景的目标和在故事中的位置
- 场景中的人物和他们的目标
- 可选：已有的草稿、想要的氛围

## 输出格式
- 场景结构分析（目标/冲突/转折/结果）
- 场景写作建议（开头/中间/结尾怎么写）
- 感官细节和氛围设计
- 动作和对话的配合
- 展示而非说明的具体改写
- 场景修订Checklist

## 核心方法论

### 场景的基本结构

**一个好场景的四要素**：
1. **目标**：场景中的角色想要什么？（场景级目标，不是故事级目标）
2. **冲突**：什么阻止了他？（人/环境/内心/时间）
3. **转折**：场景结束时和开始时，情况有什么不同？（通常是更糟了）
4. **结果**：角色得到了他想要的吗？（通常没有，而且引出了新的问题）

**场景结构模板**：
```
开头（10%）：建立场景——地点、时间、人物、氛围，快速进入
发展（60%）：核心冲突——角色追求目标，遇到障碍，冲突升级
转折（20%）：关键事件——新信息/新障碍/新选择，改变了局面
结尾（10%）：场景结果——角色的状态变化，留下钩子或余韵
```

**场景开头的常见问题**：
- ❌ 从角色起床/出门/赶路开始（无效铺垫）
- ❌ 大段环境描写后才进入冲突
- ❌ "这是一个阳光明媚的早晨..."（陈词滥调）
- ✅ 从冲突的中间开始（in medias res）
- ✅ 从一个引人注目的动作/对话/细节开始
- ✅ 从角色面临的问题开始

**场景结尾的常见问题**：
- ❌ 平淡结束，没有变化（"然后他回家了"）
- ❌ 所有问题都解决了（没有钩子）
- ❌ 用总结性语句收尾（"这一天真是难忘"）
- ✅ 留下一个新问题/悬念/转折（让读者想继续看）
- ✅ 用一个有象征意义的细节/动作收尾
- ✅ 角色的状态发生了微妙但重要的变化

### 展示而非说明（Show, Don't Tell）

**核心原则**：不要直接告诉读者角色的感受/性格/状态，而是通过具体的行动、对话、细节让读者自己感受。

**常见说明 vs 展示**：

| 说明（Tell） | 展示（Show） |
|---|---|
| 他很生气 | 他的手指攥得发白，指节咔咔作响，声音从牙缝里挤出来 |
| 她很紧张 | 她不停地搓手，目光闪躲，说话比平时快了一倍 |
| 他们关系不好 | 两人坐在沙发两端，中间隔着一个人的距离，谁也不看谁 |
| 他是个细心的人 | 他的工具按大小排列在工具箱里，标签朝外，每个都擦得发亮 |
| 她很悲伤 | 她盯着空了的茶杯，手指轻轻摩挲着杯沿，像是在摸一个人的脸 |
| 房间很破旧 | 墙纸剥落露出灰色的水泥，地板踩上去吱呀作响，窗户用纸糊着挡风 |
| 他爱上了她 | 他发现自己在人群中总能第一眼找到她，而她笑的时候他的心跳会漏一拍 |

**展示的技巧**：
1. **用动作代替形容词**：不要说"他很紧张"，写他紧张时做什么
2. **用细节代替概括**：不要说"房间很乱"，写具体的乱（外卖盒堆在床头柜，衣服搭在椅背上，地上有一只袜子）
3. **用对话代替叙述**：不要说"他们吵架了"，写他们吵架的内容和方式
4. **用感官代替描述**：不要说"咖啡很香"，写咖啡的香气如何弥漫、它的温度、它的味道
5. **用反应代替直接说**：不要说"这个消息很震惊"，写角色听到消息后的反应

**什么时候可以说明**：
- 过渡性信息（不需要展示的次要内容）
- 快速推进时间/地点
- 角色的内心反思（有限视角下可以直接写想法）
- 全知视角的评论
- 注意：说明要少而精，大部分时候应该展示

### 感官细节与氛围

**五感描写**：
1. **视觉**：颜色、形状、光线、动作、表情、空间布局
2. **听觉**：声音、噪音、沉默、对话的语气、环境音
3. **触觉**：温度、质地、重量、疼痛、舒适、风、水
4. **嗅觉**：气味、香味、臭味、空气的味道
5. **味觉**：食物、饮料、嘴里的味道（血腥味、苦味）

**感官使用原则**：
- 不要每次都写全五感，选择最能体现氛围的2-3种
- 感官细节要和角色的状态相关（紧张时听觉敏锐，悲伤时视觉模糊）
- 避免陈词滥调的感官描写（"阳光明媚"、"鸟语花香"）
- 用独特的、具体的感官细节（不是"咖啡很香"，而是"焦苦的咖啡香里混着一点肉桂"）

**氛围营造**：
- 氛围=感官细节+角色情绪+环境特征的组合
- 同样的环境，不同的角色情绪会产生不同的氛围
- 氛围应该服务于场景的目标和冲突
- 氛围可以在场景中变化（从平静到紧张，从温暖到寒冷）

**氛围营造技巧**：
1. **用天气/环境反映内心**：内心混乱时阴雨，内心平静时阳光
2. **用声音制造氛围**：滴答的钟声（紧张）、远处的笑声（孤独）、沉默（压迫）
3. **用光线制造氛围**：昏暗的灯光（神秘/压抑）、刺眼的阳光（焦虑/暴露）、温暖的黄昏（怀旧/温柔）
4. **用空间制造氛围**：拥挤的空间（压迫）、空旷的空间（孤独）、熟悉的空间（安全）、陌生的空间（不安）
5. **用对比制造氛围**：安静中的一声巨响、温暖房间外的寒风、笑声中的一丝不和谐

### 动作描写

**好的动作描写**：
- 具体、清晰，读者能"看到"动作
- 有节奏，快动作用短句，慢动作用长句
- 有目的，每个动作都推进情节或展示人物
- 有细节，不是"他打了他"，而是"他右拳直击对方面门，指节撞上鼻梁的瞬间传来软骨碎裂的触感"

**动作描写技巧**：
1. **用强动词**：不要用"走"，用"踱/溜/冲/蹒跚/大步流星"；不要用"看"，用"瞥/瞪/凝视/扫视/偷瞄"
2. **分解动作**：把复杂动作分解成连续的小动作，让读者看到过程
3. **加入感官**：动作的声音、触感、温度、气味
4. **加入反应**：动作的效果和他人的反应
5. **控制节奏**：紧张动作用短句、快节奏；舒缓动作用长句、慢节奏

**动作描写常见问题**：
- ❌ 副词滥用（"他快速地跑"→"他冲了出去"）
- ❌ 模糊不清（"他做了个手势"→什么手势？）
- ❌ 没有目的（为了动作而动作，不推进情节）
- ❌ 过度描写（每个小动作都写，拖慢节奏）

### 场景修订Checklist

写完一个场景后，用这个清单检查：

**结构**：
- [ ] 场景有明确的目标吗？
- [ ] 有冲突吗？冲突是什么？
- [ ] 场景结束时情况有变化吗？（转折）
- [ ] 结果是什么？引出了什么新问题？
- [ ] 场景开头3行内进入冲突了吗？
- [ ] 场景结尾有钩子或余韵吗？

**人物**：
- [ ] 角色的行为符合他的性格和动机吗？
- [ ] 角色的语言有辨识度吗？
- [ ] 有没有角色只是工具人（没有自己的目标）？
- [ ] 角色的情绪变化有铺垫吗？

**写作**：
- [ ] 有没有大段的说明（Tell）？可以改成展示（Show）吗？
- [ ] 感官细节够吗？（至少2-3种感官）
- [ ] 动作描写具体吗？有没有强动词？
- [ ] 对话自然吗？有没有"说明式对话"（角色说他们已经知道的事）？
- [ ] 有没有陈词滥调？
- [ ] 节奏合适吗？（紧张场景短快，舒缓场景长慢）

**功能**：
- [ ] 这个场景推进了情节吗？
- [ ] 这个场景展示/发展了人物吗？
- [ ] 这个场景和主题有关吗？
- [ ] 如果删掉这个场景，故事会受影响吗？（如果不会，考虑删掉或合并）

## 调用示例
**用户**：帮我改写这个场景——"他很生气地走进房间，看到她在等他。他们吵了一架，最后不欢而散。"
**技能输出**：
问题分析：
1. 全是说明（Tell），没有展示
2. 没有具体的动作、对话、细节
3. 冲突模糊，不知道为什么吵
4. 没有感官和氛围

改写建议（展示版）：
"门被推开时撞在墙上，震得相框跳了一下。他站在门口，胸口剧烈起伏，外套扣子扣错了一颗。
她坐在沙发边缘，双手交握在膝盖上，茶杯已经凉了。'你回来了。'她的声音很平。
'你跟他说了什么？'他的声音从牙缝里挤出来，每一个字都像是砸出来的。
她抬起眼，目光里没有惧意，只有一种疲惫的平静。'我说了实话。'
'实话？'他往前走了一步，鞋底碾过地毯上的酒渍，'你知道实话会毁了一切吗？'
'那又怎样？'她站起来，声音第一次有了波动，'你打算瞒多久？瞒一辈子？'
他张了张嘴，却没说出话。窗外的雷声滚过，房间里的灯闪了一下。
他转身，门再次被摔上，这次震得相框掉在了地上，玻璃碎了一地。
她站在原地，看着地上的碎玻璃，很久没有动。"

改写要点：
1. 用动作展示愤怒（撞门、扣子扣错、声音从牙缝挤出）
2. 用具体对话展示冲突（不是"吵了一架"，而是吵的内容）
3. 用细节展示氛围（凉了的茶杯、酒渍、雷声、灯闪）
4. 用结尾的细节留下余韵（碎玻璃、她站着不动）
5. 每个角色都有自己的立场和情绪，不是工具人
...（进一步的修订建议）

## 场景质量自检（v1.1 新增）

每个场景写完后必须检查，不通过的场景必须当场修改，不能进入下一场景。

### 检查项

**1. 人味9条（逐条对照99-全局规则第九章9.1）**
- [ ] 有没有"感到+情绪词"？有就改
- [ ] 有没有逻辑过渡词（首先/其次/然而/因此）？有就删
- [ ] 有没有连续三段长度相近？有就打碎
- [ ] 有没有排比超过两句？有就拆
- [ ] 有没有成语/四字词语扎堆？有就替换
- [ ] 有没有通用细节（很好/很乱/很漂亮）？有就具体化
- [ ] 对话是不是每个人都说完整的话？是就改得不完整
- [ ] 开头是不是在环境/心理描写？是就换到动作/细节/对话
- [ ] 结尾是不是在总结/点题？是就删掉最后一段

**2. 细节检查**
- [ ] 细节具体吗？（不是"房间很乱"，而是"床上堆着三件外套最上面那件是前女友的"）
- [ ] 每1000字至少3个具体细节吗？
- [ ] 细节服务于人物/氛围/主题吗？（不是为了细节而细节）
- [ ] 有没有至少一个"无用但有神"的细节？（和情节无关但有生活温度）
- [ ] 感官细节够吗？（至少2-3种感官，不是只有视觉）

**3. 钩子检查**
- [ ] 场景结尾有钩子吗？（悬念/冲突/疑问/反差/选择/到来）
- [ ] 读者会想继续看下一场吗？
- [ ] 钩子和故事核心有关吗？（不是为了钩而钩）
- [ ] 钩子的强度和场景的紧张度匹配吗？
- [ ] 开头3行内进入冲突了吗？（不是无效铺垫）

**4. 想象力检查**
- [ ] 有没有至少1个"意想不到但合理"的元素？
- [ ] 这个元素有逻辑支撑吗？（不是为了意外而意外）
- [ ] 场景有没有哪里太 predictable（可预测）？
- [ ] 如果有 predictable 的地方，能不能反过来写？
- [ ] 场景的氛围/细节/动作有没有独特性？（不是千篇一律的）

**5. 结构检查**
- [ ] 场景有明确的目标吗？（角色想要什么？）
- [ ] 有冲突吗？（什么阻止了他？）
- [ ] 场景结束时情况有变化吗？（转折）
- [ ] 结果是什么？引出了什么新问题？
- [ ] 这个场景推进了情节/人物/主题吗？（如果删掉不影响，考虑删掉或合并）

**6. 人物检查**
- [ ] 角色的行为符合他的性格和动机吗？
- [ ] 角色的语言有辨识度吗？（遮住名字能认出是谁吗？）
- [ ] 有没有角色只是工具人（没有自己的目标）？
- [ ] 角色的情绪变化有铺垫吗？
- [ ] 展示而非说明了吗？（不是"他很生气"，而是他生气时做什么）

### 不通过怎么办

- 人味不通过 → 对照人味9条逐条修改
- 细节不通过 → 把通用细节改成具体细节，加感官细节，加"无用但有神"的细节
- 钩子不通过 → 给场景结尾加钩子，调整开头3行内进入冲突
- 想象力不通过 → 用"反常规元素法"给场景加一个意想不到但合理的元素
- 结构不通过 → 补全场景四要素（目标/冲突/转折/结果），删掉多余的过渡场景
- 人物不通过 → 调整行为使其符合性格，给人物加独特语言特征，把说明改成展示

**只有6项全部通过的场景，才能进入下一场景写作。**
