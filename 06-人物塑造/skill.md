# 06-人物塑造 · 技能

> 设计有矛盾性、有创伤、有成长弧线的活人，而不是一张人物信息表。

## 何时调用
- 用户需要设计故事的主角/主要人物
- 用户觉得人物扁平、不够立体
- 用户需要深化人物的动机和内心
- 用户说"帮我设计一个主角"

## 输入要求
- 人物在故事中的功能（主角/对手/导师等）
- 已有的想法（可以是模糊的）
- 可选：故事类型、世界观背景

## 输出格式
- 人物核心档案（身份、外貌、性格）
- 深层心理（创伤、恐惧、渴望、矛盾）
- 动机系统（表层动机/深层动机/真实动机）
- 人物弧线（起点→转变→终点）
- 人物关系定位
- 人物独特性分析
- 开篇如何展示这个人物

## 核心方法论

### 人物设计七层次

**第一层：外在身份**
- 姓名、年龄、性别、职业、社会地位
- 外貌特征（不是"很帅/很美"，而是有辨识度的具体特征）
- 说话方式（用词、句式、语速、口头禅、口音）
- 行为习惯（小动作、习惯动作、生活规律）

**第二层：表层性格**
- 别人眼中的他/她是什么样？
- 最突出的3个性格特质
- 优点和缺点（最好是同一个特质的两面）
- 面对压力时的典型反应

**第三层：深层心理**
- **核心创伤**：过去发生了什么，塑造了现在的他/她？（被抛弃/背叛/失败/失去/虐待...）
- **核心恐惧**：他/她最害怕什么？（再次被抛弃/失败/失去控制/不被爱/死亡...）
- **核心渴望**：他/她内心最深的渴望是什么？（被爱/被认可/自由/安全/复仇/救赎...）
- **核心矛盾**：他/她内心的冲突是什么？（渴望亲密但害怕被伤害/想要自由但害怕孤独/追求正义但内心有黑暗...）

**第四层：动机系统**
- **表层动机**：故事开始时他/她明确想要什么？（找到凶手/赚到钱/保护某人/复仇...）
- **深层动机**：他/她为什么想要这个？这和核心创伤/渴望有什么关系？
- **真实动机**：他/她自己可能都没意识到的真正动机是什么？
- **动机转变**：故事过程中动机如何变化？（从为自己→为他人/从复仇→救赎）

**第五层：人物弧线**
- **起点状态**：故事开始时他/她是什么样？（有什么缺陷/错误信念）
- **触发事件**：什么打破了他/她的日常？
- **成长过程**：他/她经历了什么，如何被挑战和改变？
- **关键时刻**：他/她必须做出艰难选择的时刻是什么？（这个选择定义了他/她是谁）
- **终点状态**：故事结束时他/她变成了什么样？（成长了/堕落了/回到原点但有了新的理解）

**弧线类型**：
- 成长弧：主角克服缺陷，变得更好
- 堕落弧：主角被诱惑/压力打败，变得更坏
- 平坦弧：主角信念不变，但改变了周围的世界
- 循环弧：主角经历变化后回到起点，但有了新的理解

**第六层：人物关系**
- 他/她和主角的关系是什么？
- 这段关系的历史和现状？
- 这段关系中的矛盾和张力？
- 他/她如何影响主角？主角如何影响他/她？
- 这段关系在故事中如何变化？

**第七层：独特性**
- 这个人物和其他同类人物有什么不同？
- 他/她最令人难忘的特质是什么？
- 有没有"反差萌"（外表和内心的反差/身份和行为的反差）？
- 读者为什么会关心这个人？

### 人物深度技巧
1. **矛盾性**：立体的人物一定有矛盾（善良但残忍/勇敢但懦弱/聪明但在某方面天真）
2. **压力下的选择**：人物在压力下做出的选择，比他说的话更能定义他是谁
3. **沉默和回避**：他/她回避什么话题？在什么情况下沉默？这透露了什么？
4. **私人时刻**：独自一人时他/她是什么样？和在别人面前有什么不同？
5. **过去的阴影**：过去的经历如何影响现在的每一个决定？

### 人物展示（不要直接说）
- ❌ "他很勇敢" → ✅ 展示他在恐惧中仍然选择行动
- ❌ "她有创伤" → ✅ 展示她在特定场景下的过度反应/回避
- ❌ "他们关系不好" → ✅ 展示他们对话中的张力、回避、讽刺
- ❌ "他很聪明" → ✅ 展示他如何解决一个难题

## 调用示例
**用户**：帮我设计一个30岁的女侦探主角
**技能输出**：
外在身份：林深，30岁，私家侦探，前刑警，因一次失败的案件辞职。短发，左手无名指有一道旧伤疤，说话简短直接，习惯观察别人的手而不是脸。
表层性格：冷静、理性、不近人情；但对受害者有超出职业的共情。
深层心理：
- 核心创伤：三年前的案件中，她因为坚持程序正义而延误了救援，导致一名女孩死亡
- 核心恐惧：再次因为自己的判断错误而害死无辜的人
- 核心渴望：救赎，证明自己还能做正确的事
- 核心矛盾：相信规则和程序，但又知道规则有时会让人失望
动机系统：
- 表层动机：调查当前的案件
- 深层动机：通过破案来赎罪
- 真实动机：证明当年的自己不是错的（或者承认自己错了）
人物弧线：从"用规则保护自己不犯错"→"在规则和正义之间做出选择"→"接受不完美，但仍然选择行动"
...（完整七层次档案）

## 人物质量自检（v1.1 新增）

每个人物设计完成后必须检查，不通过的人物必须深化后才能进入下一阶段。

### 检查项

**1. 动机检查**
- [ ] 主角有明确的欲望吗？（他想要什么？）
- [ ] 他为什么想要这个？（动机能支撑他的所有关键行为吗？）
- [ ] 有表层动机/深层动机/真实动机的层次吗？
- [ ] 动机和核心创伤/渴望有关联吗？

**2. 缺陷检查**
- [ ] 主角有致命缺陷吗？（不是小缺点，是会给他带来大麻烦的缺陷）
- [ ] 这个缺陷会在故事中发挥作用吗？（会影响情节发展吗？）
- [ ] 缺陷和创伤有关联吗？（这个缺陷是怎么来的？）
- [ ] 缺陷有机会被克服/被接受吗？（人物弧线的基础）

**3. 逻辑检查**
- [ ] 主角的行为符合他的性格和经历吗？
- [ ] 列出3个关键行为，逐个检查"这个行为合理吗？"
- [ ] 人物变化有铺垫吗？（不是突然转变）
- [ ] 人物的知识/能力符合其背景吗？（不会突然会了一个他不可能会的技能）

**4. 人味检查**
- [ ] 主角有怪癖/习惯/小动作吗？
- [ ] 有秘密吗？（他不想让人知道的事）
- [ ] 有过去吗？（故事开始前他经历过什么？）
- [ ] 有至少一个"无用但有神"的细节吗？（和情节无关但有生活温度）
- [ ] 有矛盾性吗？（善良但残忍/勇敢但懦弱/聪明但在某方面天真）

**5. 想象力检查**
- [ ] 有没有"意想不到但合理"的人物细节？（杀手喜欢织毛衣/医生怕血/律师口吃）
- [ ] 这个人物和其他同类人物有什么不同？
- [ ] 有没有"反差萌"（外表和内心的反差/身份和行为的反差）？
- [ ] 读者为什么会关心这个人？（他有什么让人共情的地方？）

**6. 独特性检查**
- [ ] 这个人物是"活人"还是"人物信息表"？（有矛盾、有秘密、有怪癖的是活人）
- [ ] 遮住名字，读者能通过行为和语言认出是他吗？
- [ ] 他最令人难忘的特质是什么？
- [ ] 有没有落入刻板印象？（如果有，加一个反刻板印象的特质）

### 不通过怎么办

- 动机不通过 → 深化动机系统，加深层动机和真实动机
- 缺陷不通过 → 给主角加一个会带来麻烦的致命缺陷
- 逻辑不通过 → 调整人物性格或行为，使其一致
- 人味不通过 → 给人物加怪癖/秘密/过去/生活细节
- 想象力不通过 → 用"矛盾特质法"给人物加一个意想不到但合理的细节
- 独特性不通过 → 检查刻板印象，加反刻板印象特质，强化人物的独特声音

**只有6项全部通过的人物，才能进入结构/大纲阶段。**
