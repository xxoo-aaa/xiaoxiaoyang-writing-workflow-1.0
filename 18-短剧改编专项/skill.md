# 18-短剧改编专项 · 技能

> 把小说/故事改编成竖屏微短剧：短剧节奏、分集大纲、钩子设计、人物标签化、爽点密度、付费卡点。

## 何时调用
- 用户需要把小说/故事改编成短剧
- 用户需要写短剧剧本
- 用户需要了解短剧的创作规律和平台要求
- 用户说"改编成短剧/短剧怎么写"

## 输入要求
- 原著/故事内容（小说文本或详细大纲）
- 目标平台和集数（通常80-100集，每集1-2分钟）
- 可选：目标受众、题材方向

## 输出格式
- 原著分析（核心冲突、人物关系、名场面、可改编点）
- 改编策略（保留什么/改动什么/强化什么/删减什么）
- 人物标签化设计（短剧人物的快速识别）
- 分集大纲（80-100集，每集的核心事件和钩子）
- 付费卡点设计（关键集数的强钩子）
- 爽点/虐点分布表
- 短剧剧本格式示例
- 短剧改编Checklist

## 核心方法论

### 短剧的核心特征

**和传统影视的区别**：
- **时长极短**：每集1-2分钟，总时长80-200分钟
- **节奏极快**：前3秒必须抓人，每15秒一个小高潮
- **冲突密度极高**：几乎没有铺垫，每场都有冲突
- **人物标签化**：人物要快速识别，不需要复杂的成长弧线
- **爽点密集**：平均每3-5集一个大爽点，每集都有小爽点
- **钩子强制**：每集结尾必须有强钩子，让观众想看下一集
- **付费卡点**：在关键集数（通常第10/20/30集）设置极强钩子，诱导付费
- **情绪直接**：不搞含蓄，爱恨情仇直接表达，让观众立刻有情绪反应

**短剧的受众心理**：
- 碎片化观看（通勤、排队、睡前）
- 追求即时满足（不想等铺垫，立刻要爽/要虐/要甜）
- 情绪驱动（不是逻辑驱动，合理但不必完全合理）
- 代入感强（观众把自己代入主角，体验现实中没有的爽感）
- 社交属性（看完想分享/讨论/吐槽）

### 原著分析

**改编前必须分析的内容**：

1. **核心冲突**：原著最核心的冲突是什么？（复仇/逆袭/甜宠/虐恋/悬疑）
   - 短剧必须把核心冲突放大，放在最前面
   - 第一集就要展示核心冲突

2. **人物关系**：主要人物之间的关系和张力
   - 哪些关系最有戏剧张力？（情敌/宿敌/错位身份/秘密关系）
   - 哪些关系可以简化/合并？

3. **名场面**：原著中最精彩、最有记忆点的场景
   - 这些是短剧的"高光时刻"，必须保留并强化
   - 把名场面分布在关键集数（付费卡点附近）

4. **可改编点**：
   - 哪些设定适合短剧的快节奏？
   - 哪些需要简化（复杂的世界观/多线叙事/大量配角）？
   - 哪些可以强化（冲突/爽点/反转/情感）？

5. **删减点**：
   - 哪些支线可以删掉？（短剧通常只有1-2条主线）
   - 哪些配角可以合并或删掉？
   - 哪些心理描写/环境描写需要改成动作和对话？

### 改编策略

**核心原则：保留内核，重构外壳**

**保留什么**：
- 核心冲突和主题
- 主要人物的核心性格和关系
- 名场面和关键情节
- 让原著粉丝喜欢的"魂"

**改动什么**：
- 叙事结构（从线性改成钩子驱动的分集结构）
- 人物数量（合并/删减配角，聚焦3-5个核心人物）
- 节奏（所有铺垫压缩，冲突前置）
- 信息传递方式（从内心独白改成动作和对话）

**强化什么**：
- 冲突（所有冲突放大，增加对抗强度）
- 爽点（增加逆袭/打脸/反转的密度）
- 钩子（每集结尾都要强钩子）
- 情感（爱恨情仇更直接、更浓烈）
- 反转（增加身份反转/真相揭示的次数）

**删减什么**：
- 复杂的支线（只保留主线和1条副线）
- 大量配角（合并功能相似的角色）
- 细腻的心理描写（改成外在表现）
- 缓慢的铺垫（直接进入冲突）
- 文学性的修辞（改成直白有力的表达）

### 人物标签化设计

**短剧人物的核心：快速识别，一眼记住**

**人物标签设计方法**：
1. **身份标签**：一个有戏剧性的身份（废柴女婿/失忆千金/冷面总裁/复仇女王/隐藏大佬）
2. **性格标签**：1-2个极端性格（隐忍/暴烈/傲娇/腹黑/舔狗）
3. **目标标签**：一个明确的、强烈的目标（复仇/逆袭/保护某人/寻找真相）
4. **秘密标签**：一个隐藏的身份/真相（他其实是首富/她其实是公主/他一直在演戏）
5. **关系标签**：和其他核心人物的戏剧性关系（假夫妻/宿敌/错位身份/暗恋）

**核心人物配置（短剧标准配置）**：
- **主角**：有强烈目标和隐藏身份，观众代入的对象
  - 女频：受虐→逆袭的女主（被欺负的千金/被背叛的妻子/重生的女王）
  - 男频：废柴→逆袭的男主（赘婿/穷小子/隐藏大佬/重生者）
- **对手/反派**：给主角制造最大障碍的人，观众恨的对象
  - 通常是主角的亲近之人（继母/继妹/前夫/未婚妻/兄弟），背叛更有冲击力
- **助力/盟友**：帮助主角的人，观众喜欢的对象
  - 通常是有权力/能力的男性角色（总裁/大佬/神秘人），女频中通常是男主
- **催化剂**：引发关键事件的角色
  - 通常是带来真相/秘密/机会的人

**人物弧线（短剧版）**：
- 不需要复杂的成长弧线
- 核心是"身份/地位的反转"：从低位到高位，从被欺负到欺负人
- 人物的性格可以基本不变，变的是他的处境和别人对他的态度
- 在关键节点可以有"觉醒"时刻（主角决定不再隐忍，开始反击）

### 分集大纲设计

**分集结构（80-100集标准）**：

**第一阶段：建置+受虐（1-10集）**
- 第1集：核心冲突前置，展示主角的困境和核心冲突（3秒抓人）
- 第2-5集：主角受虐/被欺负，建立观众的同情和愤怒
- 第6-9集：出现转机/线索，主角开始觉醒
- 第10集（付费卡点）：第一个大反转/爽点，主角身份/能力初显，强钩子

**第二阶段：初反击+升级（11-30集）**
- 第11-20集：主角开始小范围反击，小爽点密集
- 第20集（付费卡点）：中等反转，主角获得重要资源/盟友
- 第21-30集：反击升级，对手开始重视主角，冲突升级
- 第30集（付费卡点）：大反转，主角的隐藏身份部分揭示，或遭遇重大危机

**第三阶段：全面对抗+高潮（31-60集）**
- 第31-40集：主角和对手全面对抗，爽点和虐点交替
- 第40集（付费卡点）：重大危机，主角似乎要失败
- 第41-50集：主角绝地反击，真相逐步揭开
- 第50集（付费卡点）：核心真相揭示，最大反转
- 第51-60集：最终对决铺垫，所有线索汇聚
- 第60集（付费卡点）：高潮前的最大危机/最强钩子

**第四阶段：高潮+结局（61-80/100集）**
- 第61-70集：最终对决，主角全面反击，大爽点密集
- 第70集（付费卡点）：终极对决开始，最强钩子
- 第71-80集：高潮+结局，所有矛盾解决，主角获得最终胜利
- 如果是100集：增加番外/后续/新冲突（为第二季铺垫）

**每集的结构（1-2分钟）**：
1. **开头（0-15秒）**：承接上集钩子，立刻进入冲突
2. **发展（15-60秒）**：冲突升级，出现新信息/新障碍
3. **转折/爽点（60-90秒）**：小反转/小爽点/情感爆发
4. **结尾钩子（最后10-15秒）**：强钩子，让观众想看下一集

**每集钩子的类型**：
- 悬念钩："他到底是谁？""接下来会发生什么？"
- 危机钩：主角遇到危险/危机
- 反转钩：意想不到的转折
- 爽点钩：主角即将反击/打脸
- 情感钩：情感爆发/关系变化
- 身份钩：身份即将揭示/被发现

### 付费卡点设计

**什么是付费卡点**：在关键集数设置极强的钩子，诱导观众付费解锁后续集数

**付费卡点的设计原则**：
1. **位置**：通常在第10/20/30/40/50/60/70集（每10集一个大卡点）
2. **强度**：比普通集结尾的钩子强得多，是"不看不行"的级别
3. **类型**：
   - 身份大反转（主角的真实身份即将被揭示）
   - 生死危机（主角面临生死关头）
   - 真相大白（核心真相即将揭开）
   - 情感爆发（最强烈的情感冲突）
   - 终极对决（主角和反派的最终对决开始）
4. **铺垫**：付费卡点前的3-5集要逐步积累张力，让观众的情绪到顶点
5. **兑现**：付费后的第一集必须兑现钩子，不能让观众觉得被骗

**付费卡点示例**：
- 第10集结尾：所有人都嘲笑主角是废物，这时一个大人物冲进来，对主角鞠躬说"少爷，您终于回来了"——黑屏，下集解锁
- 第30集结尾：主角被反派逼到绝境，似乎要输了，这时主角抬起头，露出一个意味深长的笑，说"你以为这就结束了？"——黑屏
- 第50集结尾：核心真相即将揭开，主角打开一个盒子，里面的东西让所有人震惊——镜头给到盒子，但观众看不到里面是什么——黑屏

### 爽点/虐点设计

**爽点类型（短剧最核心的吸引力）**：
1. **打脸爽**：主角被看不起→展示实力→打脸所有人
2. **逆袭爽**：主角从低位→获得权力/财富/身份
3. **复仇爽**：主角对伤害过他的人进行报复
4. **身份爽**：主角的隐藏身份被揭示，所有人震惊
5. **能力爽**：主角展示超强能力，解决别人解决不了的问题
6. **护短爽**：主角保护自己在乎的人，碾压对手
7. **反杀爽**：主角在绝境中反杀对手
8. **甜宠爽**：男主/女主对主角的特殊宠爱和保护

**虐点类型（和爽点交替，增加情感张力）**：
1. **背叛虐**：被信任的人背叛
2. **误会虐**：被误解，百口莫辩
3. **身份虐**：因为身份/地位被歧视/欺负
4. **情感虐**：相爱却不能在一起/被迫分离
5. **牺牲虐**：为了保护某人而牺牲自己
6. **真相虐**：发现真相后无法接受

**爽虐节奏**：
- 先虐后爽（虐得越深，爽得越狠）
- 爽点和虐点交替，不要一直爽（会麻木）也不要一直虐（会憋屈）
- 每3-5集一个大爽点，每集都有小爽点或小虐点
- 付费卡点前通常是大虐点（主角遭遇最大危机），付费后是大爽点（主角反击）

### 短剧剧本格式

**短剧剧本和传统剧本的区别**：
- 更精简（每场只有几行动作和对话）
- 冲突更直接（没有铺垫，直接进入冲突）
- 钩子更明确（每集结尾标注钩子）
- 通常标注"本集钩子"和"下集预告"

**短剧剧本格式示例**：

```
第1集  废柴女婿

【场景1】客厅 日
王家客厅，一家人围坐吃饭。王母把一盘菜推到林辰面前。

王母
（嫌弃）
吃啊，废物，今天的剩饭都给你。

林辰低头，默默吃饭。妻子王雪坐在旁边，不敢说话。

王父
下个月是老爷子寿宴，你打算送什么？别给我们家丢人。

林辰
（抬头）
我会准备一份大礼。

王母
（大笑）
大礼？你一个上门女婿，能拿出什么大礼？别笑死人了！

【场景2】门口 日
林辰出门，王雪追出来。

王雪
（低声）
林辰，对不起，我爸妈他们...

林辰
（平静）
没关系。

王雪
你真的能准备大礼？

林辰看了她一眼，没有回答，转身离开。

【本集钩子】
林辰走到街角，一辆黑色豪车停在他面前。司机下车，鞠躬。

司机
少爷，您终于肯回来了。

【下集预告】
林辰的真实身份是什么？他会如何反击王家？
```

### 短剧改编Checklist

**原著分析**：
- [ ] 核心冲突是否明确？是否适合短剧？
- [ ] 名场面是否识别出来？是否分布在关键集数？
- [ ] 人物关系是否简化？（聚焦3-5个核心人物）
- [ ] 支线是否删减？（只保留主线和1条副线）

**改编策略**：
- [ ] 冲突是否前置？（第一集就展示核心冲突）
- [ ] 铺垫是否压缩？（没有多余的过渡）
- [ ] 爽点是否增加？（密度是否足够）
- [ ] 反转是否增加？（身份反转/真相揭示）
- [ ] 情感是否更直接？（不搞含蓄）

**分集结构**：
- [ ] 每集是否有明确的核心事件？
- [ ] 每集结尾是否有强钩子？
- [ ] 付费卡点（第10/20/30...集）是否有极强钩子？
- [ ] 爽点和虐点是否交替？
- [ ] 整体节奏是否前快后更快？（没有疲软期）

**人物**：
- [ ] 主角是否有明确的身份标签和目标？
- [ ] 主角是否有隐藏身份/秘密？
- [ ] 对手是否足够可恨？（让观众有代入感的愤怒）
- [ ] 盟友是否有魅力？（让观众喜欢）
- [ ] 人物数量是否可控？（不超过5个核心人物）

**剧本**：
- [ ] 前3秒是否抓人？
- [ ] 每15秒是否有小高潮/新信息？
- [ ] 对话是否精简？（没有废话）
- [ ] 动作是否明确？（能拍出来）
- [ ] 每集时长是否控制在1-2分钟？

## 调用示例
**用户**：帮我把一个"重生复仇"的小说改编成80集短剧，女主被丈夫和闺蜜害死，重生回到三年前，开始复仇
**技能输出**：
原著分析：
- 核心冲突：女主重生后向背叛她的丈夫和闺蜜复仇
- 名场面：重生瞬间、第一次反击、身份揭示、最终复仇
- 可改编点：重生设定天然适合短剧（有信息差和预知能力），复仇线爽点密集
- 删减点：原著中的商战细节、次要人物、心理描写都要简化

改编策略：
- 保留：重生设定、核心人物（女主/丈夫/闺蜜/新男主）、复仇主线、名场面
- 改动：把缓慢的复仇计划改成快速反击，每几集一个小胜利
- 强化：爽点密度（打脸/反杀/身份揭示）、女主的气场和智慧、男女主的甜宠线
- 删减：商战细节、次要配角、女主的内心挣扎（改成果断行动）

人物标签化：
- 女主：重生复仇女王（表面温柔，内心腹黑，预知未来）
- 丈夫：伪善渣男（表面深情，内心贪婪，和闺蜜有染）
- 闺蜜：白莲花（表面闺蜜，内心嫉妒，勾引女主丈夫）
- 男主：隐藏大佬（表面是普通总裁，实际是商业帝国继承人，守护女主）

分集大纲（80集）：
第一阶段（1-10集）：重生+觉醒
- 第1集：女主被丈夫和闺蜜害死，重生回到三年前婚礼当天（3秒抓人：死亡场景→重生）
- 第2-5集：女主假装什么都没发生，暗中收集证据，小范围反击（破坏闺蜜的第一次算计）
- 第6-9集：女主遇到男主，男主被女主的变化吸引，开始帮助她
- 第10集（付费卡点）：女主在宴会上第一次公开打脸闺蜜和丈夫，所有人震惊，强钩子：丈夫开始怀疑女主

第二阶段（11-30集）：初反击+升级
- 第11-20集：女主逐步瓦解丈夫的商业计划，小爽点密集，闺蜜的阴谋一次次被女主识破
- 第20集（付费卡点）：女主获得重要证据，丈夫的第一个大项目被女主破坏，丈夫开始调查女主
- 第21-30集：女主和男主的感情升温，丈夫和闺蜜的矛盾出现（互相猜忌）
- 第30集（付费卡点）：女主的重生秘密差点被发现，最大危机：丈夫拿到了女主"预知未来"的证据
