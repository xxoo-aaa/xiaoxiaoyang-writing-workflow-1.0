# 24-内容审核 · 技能

> 内容合规与风险审核：敏感内容排查、平台规则适配、版权风险、法律风险。确保作品能安全发布。

## 何时调用
- 用户的作品涉及敏感题材，需要审核风险
- 用户需要在特定平台发布，需要了解平台规则
- 用户需要检查作品是否有版权/法律风险
- 用户说"能不能发/有没有风险/内容审核"

## 输入要求
- 待审核的作品（全文或关键部分）
- 目标发布平台（可选）
- 作品类型和题材

## 输出格式
- 风险评估报告（风险等级、具体风险点）
- 敏感内容排查清单
- 平台规则适配建议
- 版权风险检查
- 法律风险提示
- 修改建议（如何规避风险同时保留故事核心）
- 内容审核Checklist

## 核心方法论

### 内容审核的核心理念

**内容审核不是"自我阉割"，而是"在规则内最大化表达"。**
- 了解规则不是为了害怕，而是为了知道边界在哪里，然后在边界内自由创作
- 很多敏感内容可以通过"暗示""侧面描写""艺术化处理"来表达，不需要直接描写
- 不同平台/地区/时代的规则不同，需要了解目标平台的具体规则
- 创作自由和社会责任是平衡的，不是对立的

### 敏感内容排查

**政治敏感**：
- 涉及现实政治人物、政治事件、政治制度的内容
- 涉及国家主权、领土完整、民族关系的内容
- 涉及宗教信仰、宗教冲突的内容
- 涉及历史敏感事件的内容
- 风险等级：高（直接涉及现实政治的内容风险最高）
- 处理建议：
  - 避免直接使用现实政治人物的真实姓名和身份
  - 涉及政治制度时，可以虚构一个国家/制度，不要直接对应现实
  - 历史题材要尊重基本史实，不要美化侵略、殖民、法西斯
  - 民族和宗教题材要尊重，不要丑化或刻板印象

**暴力血腥**：
- 过度描写暴力、血腥、残忍的场景
- 详细描写杀人、酷刑、自残的过程
- 美化暴力、以暴制暴的价值观
- 风险等级：中（适度的暴力描写可以接受，过度描写有风险）
- 处理建议：
  - 暴力场景重点写"结果"和"影响"，而不是"过程"的细节
  - 用暗示和侧面描写代替直接描写（比如写血迹、反应，而不是详细描写伤口）
  - 暴力应该有代价和后果，不要美化暴力
  - 避免详细描写酷刑、虐待的过程
  - 未成年人参与暴力场景要特别谨慎

**色情低俗**：
- 直接描写性行为、性器官的内容
- 低俗、猥琐、物化女性/男性的内容
- 涉及未成年人的性内容（绝对禁止）
- 风险等级：高（直接的性描写风险最高）
- 处理建议：
  - 性场景用"暗示"和"留白"，不要直接描写
  - 重点写情感和关系，而不是身体细节
  - 避免物化任何性别，角色应该是独立的人，不是性对象
  - 绝对禁止涉及未成年人的任何性内容
  - 强奸/性暴力场景要特别谨慎，不要详细描写，重点写受害者的创伤和恢复

**恐怖惊悚**：
- 过度恐怖、血腥、恶心的描写
- 宣扬封建迷信、邪教的内容
- 风险等级：低-中（恐怖题材本身可以接受，但过度描写有风险）
- 处理建议：
  - 恐怖重点在"氛围"和"心理"，而不是"血腥"和"恶心"
  - 避免详细描写尸体、伤口、腐烂的细节
  - 不要宣扬封建迷信（可以写角色相信，但故事整体不要宣扬）
  - 邪教题材要谨慎，不要美化或详细描写邪教仪式

**毒品/犯罪**：
- 详细描写毒品制作、使用过程的内容
- 美化犯罪、教读者犯罪方法的内容
- 风险等级：中（犯罪题材可以写，但不能美化或教学）
- 处理建议：
  - 犯罪应该有代价和后果，不要美化犯罪
  - 不要详细描写犯罪方法（制毒、开锁、诈骗流程等），避免成为"犯罪教程"
  - 毒品题材重点写危害和后果，不要详细描写吸毒过程和快感
  - 反派可以犯罪，但最终应该受到惩罚（至少在价值观上不要肯定犯罪）

**歧视与偏见**：
- 基于性别、种族、民族、宗教、地域、职业、疾病等的歧视内容
- 刻板印象、丑化特定群体的内容
- 风险等级：中（歧视性内容会引发争议和投诉）
- 处理建议：
  - 避免刻板印象（比如"女性都是感性的""某个地域的人都是骗子"）
  - 角色应该是立体的个人，不是群体的代表
  - 反派可以有偏见，但故事整体不要宣扬偏见
  - 涉及特定群体时，尽量做研究，避免无知导致的冒犯
  - 残疾、精神疾病等题材要尊重，不要丑化或浪漫化

**自杀/自残**：
- 详细描写自杀、自残方法的内容
- 美化自杀、把自杀描写成"解脱"的内容
- 风险等级：高（自杀内容有社会风险，可能引发模仿）
- 处理建议：
  - 不要详细描写自杀方法和过程
  - 不要美化自杀，不要把自杀描写成解决问题的方式
  - 如果角色有自杀倾向，应该展示他的痛苦和求助，最终应该有积极的方向（至少不要肯定自杀）
  - 可以写角色经历自杀危机后恢复，传递希望
  - 涉及自杀内容时，建议在作品末尾附上心理援助热线

### 平台规则适配

**不同平台的审核尺度不同**：
- **严肃文学/出版**：尺度相对宽松，可以涉及更多敏感题材，但仍需遵守法律
- **网络文学平台**：有明确的审核规则，涉及政治、色情、暴力的内容会被审核
- **短视频/短剧平台**：审核最严格，对暴力、色情、敏感内容的限制最多
- **自媒体平台**：有社区规范，违规内容会被删除或封号
- **海外平台**：规则不同，但也要遵守当地法律

**平台规则研究方法**：
1. 阅读目标平台的"用户协议""社区规范""内容审核规则"
2. 研究平台上的热门作品，看看什么内容能发，什么内容被删
3. 加入作者社群，了解平台的"潜规则"（哪些内容虽然规则没写但会被删）
4. 发布前用平台的"自查工具"或"敏感词检测"检查
5. 不确定的内容，可以先问平台编辑或客服

**常见平台敏感词类型**：
- 政治敏感词（领导人名字、敏感事件、分裂言论等）
- 色情低俗词（性器官、性行为的直接描述）
- 暴力血腥词（酷刑、残忍手段的详细描述）
- 毒品相关词（毒品名称、制作方法）
- 赌博相关词（赌博方法、平台推荐）
- 侮辱歧视词（种族歧视、性别歧视、地域歧视）
- 注意：敏感词列表会变化，需要定期更新

### 版权风险检查

**常见版权风险**：
1. **抄袭**：直接复制他人作品的情节、人物、对话
2. **洗稿**：改变表达方式但复制核心创意和结构
3. **未经授权使用**：使用他人的诗歌、歌词、图片、人物形象
4. **同人创作**：使用他人作品的人物和世界观进行二次创作
5. **真实人物**：使用真实人物（尤其是公众人物）的姓名、形象、经历

**版权风险规避方法**：
- 原创是最好的保护，尽量创作完全原创的内容
- 借鉴要"学习方法和结构"，不要"复制具体内容"
- 引用他人作品要注明来源，且引用比例不能过高
- 歌词、诗歌等文字作品，不要大段引用，最好只引用一两句并注明
- 同人创作要了解原作者的版权声明，有些作者允许同人，有些不允许
- 涉及真实人物时，尽量使用虚构姓名，或者明确标注"虚构作品"
- 不确定时，咨询专业人士（版权律师、编辑）

**合理使用的边界**：
- 为了评论、批评、新闻报道、教学等目的，可以适当引用
- 引用比例要适当，不能构成作品的核心部分
- 不能影响原作品的正常使用和市场价值
- 最好注明来源和作者
- 注意："合理使用"的判断是复杂的，不确定时要谨慎

### 法律风险提示

**常见法律风险**：
1. **诽谤**：捏造事实损害他人名誉（尤其是真实人物）
2. **侵犯隐私**：披露他人不愿公开的私人信息
3. **侵犯肖像权**：未经同意使用他人肖像（尤其是商业用途）
4. **煽动仇恨**：煽动对特定群体的仇恨和暴力
5. **传播违法内容**：传播色情、暴力、恐怖主义等违法内容

**法律风险规避方法**：
- 涉及真实人物时，使用虚构姓名，或者明确标注"虚构作品，如有雷同纯属巧合"
- 不要捏造真实人物的负面事实
- 不要披露他人的真实隐私信息
- 商业用途（出版、改编、广告）要特别注意版权和肖像权
- 不确定时，咨询专业律师

### 敏感内容的艺术化处理

**核心原则：用暗示代替直接，用侧面代替正面，用结果代替过程。**

**处理技巧**：

1. **留白法**：不直接描写，写到关键处停住，让读者自己想象
   - ❌ 详细描写性行为
   - ✅ "灯灭了。窗外的月光照进来，落在地板上。"

2. **侧面描写法**：不直接描写事件本身，描写事件的影响和他人的反应
   - ❌ 详细描写暴力场景
   - ✅ "第二天，人们在巷子里发现了他。墙上的血迹已经干了。"

3. **象征隐喻法**：用象征和隐喻表达敏感内容
   - ❌ 直接描写死亡
   - ✅ "他看到那只鸟从树上掉下来，再也没有飞起来。"

4. **时间跳跃法**：跳过敏感内容的过程，直接写结果
   - ❌ 详细描写酷刑过程
   - ✅ "三天后，他从那个房间里出来。他的眼神变了，再也不是从前的他了。"

5. **角色视角法**：通过角色的有限视角展示，不展示全貌
   - ❌ 全知视角详细描写
   - ✅ 角色只听到声音/只看到部分/只知道结果

6. **情感重点法**：重点写角色的情感和心理，而不是事件细节
   - ❌ 详细描写强奸过程
   - ✅ 重点写受害者的恐惧、痛苦、创伤后的反应

## 调用示例
**用户**：我写了一个犯罪悬疑小说，里面有详细的杀人手法描写，还有一些性暴力场景，能发吗？
**技能输出**：
风险评估报告：

一、风险等级：中高

二、具体风险点：

1. **详细的杀人手法描写**（高风险）
   - 问题：详细描写杀人方法、过程、工具，可能被视为"犯罪教程"
   - 风险：平台可能要求修改或删除；如果方法具有可操作性，可能有法律风险
   - 建议：
     - 不要详细描写杀人的具体步骤和工具使用方法
     - 重点写"结果"（尸体状态、现场痕迹）和"影响"（对调查者/相关人的影响）
     - 杀人手法可以通过侦探的推理和分析来展示，而不是直接描写过程
     - 如果手法是故事核心（比如"不可能犯罪"），可以写手法的"原理"，但不要写"操作步骤"
     - 示例修改：
       - ❌ "他先用绳子勒住受害者的脖子，从背后绕三圈，然后用力拉紧，持续三分钟，直到受害者停止挣扎..."
       - ✅ "现场没有打斗痕迹。受害者颈部有明显的勒痕，法医判断是从背后突袭，一击致命。凶手的手法干净利落，显然有经验。"

2. **性暴力场景**（高风险）
   - 问题：直接描写性暴力过程，有极高的审核风险
   - 风险：几乎所有平台都会要求删除或大幅修改；可能引发读者投诉；有社会风险（可能引发模仿或对受害者的二次伤害）
   - 建议：
     - 绝对不要详细描写性暴力的过程
     - 重点写受害者的创伤、恐惧、恢复过程，而不是暴力本身
     - 用"暗示"和"侧面描写"代替直接描写
     - 如果性暴力是故事核心（比如受害者复仇），重点写"事件后的影响"，而不是"事件本身"
     - 可以通过受害者的闪回、噩梦、心理反应来展示事件的影响，但闪回也要克制，不要详细描写
     - 示例修改：
       - ❌ 详细描写强奸过程
       - ✅ "那扇门关上的时候，她知道一切都完了。很多年后，她仍然会在半夜惊醒，浑身冷汗。她再也不敢走那条巷子，再也不敢穿那件颜色的衣服。"

3. **犯罪题材的整体风险**（中风险）
   - 问题：犯罪题材本身有一定风险，尤其是如果美化犯罪或反派魅力过大
   - 建议：
     - 犯罪必须有代价和后果，反派最终受到惩罚
     - 主角如果是罪犯，最终应该有道德反思或代价（不能"犯罪很爽还不用负责"）
     - 侦探/正义一方最终应该获得胜利（至少在价值观上）
     - 不要详细描写反侦察手段、逃避警方追捕的方法
     - 警方的形象不要过于负面（可以写个别坏警察，但不要整体抹黑执法机构）

4. **其他需要注意的风险**（低-中风险）
   - 如果涉及真实城市/真实机构，建议使用虚构名称
   - 如果涉及毒品，不要详细描写制作和使用过程
   - 如果涉及未成年人，要特别谨慎（未成年人参与暴力/性内容风险极高）
   - 检查有没有歧视性内容（对特定职业/地域/群体的刻板印象）

三、平台适配建议：

- **网络文学平台**：修改后可以发布，但需要通过平台审核。建议发布前用平台的自查工具检查，敏感内容用"拼音""符号""留白"处理（但不要过度，影响阅读体验）
- **严肃文学/出版**：尺度相对宽松，但仍需修改最直接的描写。建议咨询编辑，了解出版社的具体要求
- **短视频/短剧改编**：审核最严格，性暴力场景几乎不可能通过，建议改编时大幅修改或删除
- **海外平台**：规则不同，但性暴力和详细犯罪手法也是敏感内容

四、修改优先级：

必须修改（不修改无法发布）：
1. 删除或大幅修改性暴力场景的直接描写
2. 删除杀人手法的详细操作步骤，改为结果和推理展示
3. 确保犯罪有代价，反派最终受到惩罚

建议修改（提升通过概率和作品质量）：
4. 检查并修改其他过度暴力/血腥的描写
5. 使用虚构的城市/机构名称
6. 检查有没有歧视性内容
7. 如果有毒品/赌博内容，检查有没有详细描写方法

五、总结：

你的作品核心创意（犯罪悬疑）是可以的，但目前的描写方式风险较高。通过"用暗示代替直接、用结果代替过程、用影响代替细节"的艺术化处理，可以在保留故事核心的同时大幅降低风险。修改后应该可以在大部分网络文学平台发布。

建议：
1. 先按上述建议修改高风险内容
2. 选择目标平台，仔细阅读该平台的审核规则
3. 发布前用平台自查工具检查
4. 如果不确定，可以先发几章试试，根据平台反馈调整
5. 保留原稿，如果平台要求修改，可以有针对性地调整

## 正反示例对比

### 示例：敏感内容处理的好与坏

❌ **差的处理（直接描写，高风险）**：
> 他把她按在墙上，一只手捂住她的嘴，另一只手撕扯她的衣服。她拼命挣扎，但他的力气太大了。他的手在她身上游走，她感到一阵恶心……（接下来500字详细描写性暴力过程）
>
> （问题：直接描写性暴力过程，风险极高，几乎所有平台都会要求删除或大幅修改，可能引发读者投诉，对受害者造成二次伤害。）

✅ **好的处理（艺术化处理，低风险）**：
> 那扇门关上的时候，她知道一切都完了。
>
> 她没有哭，也没有叫。她只是盯着墙上的那道裂缝，看着灰尘从裂缝里慢慢落下来。
>
> 很多年后，她仍然会在半夜惊醒，浑身冷汗。她再也不敢走那条巷子，再也不敢穿那件颜色的衣服。有人问她那天发生了什么，她只是摇摇头，说："都过去了。"
>
> 但她知道，有些事，永远过不去。
>
> （好的原因：没有直接描写暴力过程，用"门关上""盯着裂缝""半夜惊醒""不敢走那条巷子"等细节暗示事件的影响，重点写受害者的创伤和长期影响，而不是暴力本身。既保留了故事的情感冲击力，又大幅降低了审核风险。）

### 示例：暴力场景处理的好与坏

❌ **差的处理（详细描写暴力过程）**：
> 他举起刀，狠狠地砍在对方的肩膀上。骨头断裂的声音清脆刺耳，鲜血喷溅出来，洒了他一脸。对方惨叫一声，倒在地上。他没有停，继续一刀一刀地砍，直到对方不再动弹。地上全是血和碎肉，空气中弥漫着血腥味……
>
> （问题：过度描写暴力、血腥、残忍的过程，风险高，平台可能要求修改或删除，读者可能感到不适。）

✅ **好的处理（重点写结果和影响）**：
> 刀落下去的时候，他没有看对方的脸。
>
> 他只听到一声闷响，然后是身体倒地的声音。
>
> 等他回过神来，一切都结束了。
>
> 他站在原地，看着自己的手。手在抖。刀掉在地上，发出清脆的响声。
>
> 窗外，有人在喊救命。远处，警笛声越来越近。
>
> 他知道，从这一刻起，他的人生再也回不去了。
>
> （好的原因：没有详细描写暴力过程，用"刀落下去""闷响""身体倒地"暗示暴力，重点写主角的反应（手抖、刀掉在地上、知道人生回不去了）和后果（警笛声、人生改变）。既保留了暴力的冲击力，又避免了过度血腥的描写。）

### 示例：政治敏感内容处理的好与坏

❌ **差的处理（直接涉及现实政治）**：
> 故事发生在2024年的北京。主角是一个记者，他调查了一个真实存在的政治事件，揭露了某个真实存在的高级官员的腐败行为。在小说中，他直接使用了真实的人名、地名、事件名，并且对政治制度进行了直接的批评……
>
> （问题：直接涉及现实政治人物、政治事件、政治制度，风险极高，几乎肯定会被下架或封号，可能有法律风险。）

✅ **好的处理（虚构化处理）**：
> 故事发生在一个虚构的国家"华国"，一个虚构的城市"滨海市"。主角是一个记者，他调查了一个虚构的腐败案件，揭露了一个虚构的高官的罪行。小说中的人名、地名、事件名都是虚构的，但故事反映的社会问题（权力腐败、新闻自由、正义与妥协）是真实的。
>
> （好的原因：通过虚构国家、城市、人名、事件名，避免了直接涉及现实政治，降低了政治风险。同时，故事的核心主题和社会批判仍然保留，读者可以自己联想到现实，但作者不需要直接承担政治风险。）

## 常见问题及解法

| 问题 | 表现 | 解法 |
|------|------|------|
| **不知道什么能发什么不能发** | 对审核规则不了解，担心踩雷 | 先研究目标平台的审核规则（用户协议/社区规范/内容审核规则）；用本模块的Checklist逐项检查；不确定的内容用艺术化处理（暗示/侧面/留白）；发布前用平台自查工具检查 |
| **为了过审把故事改得面目全非** | 过度自我审查，把故事的核心冲突和情感都删掉了 | 记住：审核不是"自我阉割"，是"在规则内最大化表达"；很多敏感内容可以通过艺术化处理保留核心；区分"必须删的"（直接描写）和"可以保留的"（情感、主题、影响）；先写完整的故事，再根据审核要求修改，不要一开始就自我限制 |
| **平台要求修改但不知道怎么改** | 收到平台的修改通知，但只说"内容违规"，不说具体哪里违规 | 仔细看平台的修改通知，通常会标注具体章节和问题；如果没有标注，联系平台编辑或客服询问；用本模块的Checklist逐项自查；重点检查高风险内容（政治/色情/暴力/自杀）；保留原稿，修改后对比 |
| **不同平台规则不一样** | 在A平台能发的内容，在B平台被要求修改 | 每个平台有自己的审核尺度，发布前研究目标平台的规则；准备多个版本（完整版/修改版/精简版），根据平台要求选择；优先选择审核尺度和你的作品风格匹配的平台 |
| **写真实事件/真实人物怕有风险** | 想写基于真实事件/真实人物的故事，但担心法律风险 | 涉及真实人物时，使用虚构姓名，或者明确标注"虚构作品，如有雷同纯属巧合"；不要捏造真实人物的负面事实（诽谤风险）；不要披露他人的真实隐私信息；重大历史事件要尊重基本史实，不要美化侵略/殖民/法西斯；不确定时咨询专业律师 |
| **同人创作怕侵权** | 想写同人小说，但担心侵犯原作者版权 | 了解原作者的版权声明——有些作者明确允许同人创作，有些不允许；非商业、明确标注"同人创作"通常风险较低；商业用途（出版/改编/收费）需要获得原作者授权；不要大段复制原文，用自己的语言创作；原创角色和原创剧情越多，侵权风险越低 |
| **引用歌词/诗歌怕侵权** | 想在小说中引用歌词或诗歌，但担心侵权 | 不要大段引用，最好只引用一两句并注明来源；引用比例要适当，不能构成作品的核心部分；歌词的版权通常比较严格，尽量少引用或改用原创；诗歌如果作者去世超过50年（中国）或70年（欧美），进入公共领域，可以自由使用；不确定时咨询专业人士 |
| **海外发布规则不了解** | 想在海外平台发布，但不了解当地的审核规则和法律 | 研究目标国家/平台的审核规则和法律；不同国家对政治、宗教、性、暴力的容忍度不同；注意目标国家的敏感历史事件和文化禁忌；商业用途要特别注意版权和肖像权；不确定时咨询当地的专业人士或平台编辑 |
| **AI生成内容的审核风险** | 用AI辅助写作，担心AI生成的内容有违规或侵权风险 | AI生成的内容需要人工审核，不要直接发布；AI可能生成和已有作品相似的内容，需要做原创性检查；AI可能生成违规内容（政治/色情/暴力），需要人工过滤；重要内容建议自己写或大幅修改AI生成的内容；保留AI使用记录和修改记录 |
| **审核越来越严，不知道以后还能不能写** | 担心审核规则越来越严，自己的创作空间越来越小 | 审核规则会变化，需要持续关注；好的故事核心（人物、情感、主题）是永恒的，不会因为审核规则变化而失去价值；学会艺术化处理，在规则内最大化表达；不要把精力放在"对抗审核"上，把精力放在"讲好故事"上；记住：真正的好作品，即使在严格的审核下，也能找到表达的方式 |

## 内容审核质量自检清单

发布前，用以下清单做最终审核：

### 政治敏感
- [ ] 没有直接使用现实政治人物的真实姓名和身份
- [ ] 没有涉及国家主权、领土完整的敏感内容
- [ ] 民族和宗教题材尊重，没有丑化或刻板印象
- [ ] 历史题材尊重基本史实，没有美化侵略/殖民/法西斯
- [ ] 没有煽动颠覆国家政权、破坏社会稳定的内容
- [ ] 涉及政治制度时使用虚构国家/制度，不直接对应现实

### 暴力血腥
- [ ] 暴力场景重点写结果和影响，不是过程细节
- [ ] 没有详细描写酷刑、虐待、自残的过程
- [ ] 暴力有代价和后果，没有美化暴力
- [ ] 未成年人参与暴力场景处理谨慎
- [ ] 没有过度血腥、恶心的描写
- [ ] 没有详细描写杀人/犯罪的具体操作步骤（避免成为"犯罪教程"）

### 色情低俗
- [ ] 性场景用暗示和留白，没有直接描写
- [ ] 没有物化任何性别，角色是独立的人
- [ ] 绝对没有涉及未成年人的性内容
- [ ] 强奸/性暴力场景没有详细描写，重点写创伤和恢复
- [ ] 没有低俗、猥琐的内容
- [ ] 没有详细描写性器官和性行为

### 恐怖惊悚
- [ ] 恐怖重点在氛围和心理，不是血腥和恶心
- [ ] 没有详细描写尸体、伤口、腐烂的细节
- [ ] 没有宣扬封建迷信、邪教
- [ ] 邪教题材谨慎，没有美化或详细描写仪式

### 毒品/犯罪
- [ ] 犯罪有代价和后果，没有美化犯罪
- [ ] 没有详细描写犯罪方法（制毒/开锁/诈骗流程等）
- [ ] 毒品题材重点写危害和后果，没有详细描写吸毒过程和快感
- [ ] 反派犯罪最终受到惩罚（价值观上不肯定犯罪）
- [ ] 没有详细描写反侦察手段、逃避警方追捕的方法
- [ ] 没有美化赌博、详细描写赌博方法

### 歧视与偏见
- [ ] 没有基于性别/种族/民族/宗教/地域/职业/疾病的歧视
- [ ] 没有刻板印象，角色是立体的个人
- [ ] 反派可以有偏见，但故事整体不宣扬偏见
- [ ] 残疾/精神疾病题材尊重，没有丑化或浪漫化
- [ ] 涉及特定群体时做过研究，避免无知导致的冒犯

### 自杀/自残
- [ ] 没有详细描写自杀方法和过程
- [ ] 没有美化自杀，没有把自杀描写成解决问题的方式
- [ ] 有自杀倾向的角色最终有积极方向（至少不肯定自杀）
- [ ] 涉及自杀内容时建议附上心理援助热线
- [ ] 没有详细描写自残的方法和过程

### 版权
- [ ] 没有抄袭或洗稿他人作品
- [ ] 引用他人作品注明来源，比例适当
- [ ] 没有大段引用歌词、诗歌
- [ ] 同人创作了解原作者的版权声明
- [ ] 涉及真实人物使用虚构姓名或标注"虚构"
- [ ] 没有未经授权使用他人的图片、音乐、人物形象

### 法律
- [ ] 没有捏造真实人物的负面事实（诽谤）
- [ ] 没有披露他人的真实隐私信息
- [ ] 商业用途注意版权和肖像权
- [ ] 没有传播违法内容
- [ ] 没有煽动仇恨和暴力

### 平台适配
- [ ] 了解目标平台的审核规则
- [ ] 检查了平台敏感词
- [ ] 不确定的内容咨询了平台编辑/客服
- [ ] 有备选方案（如果某部分被要求修改）
- [ ] 保留了原稿，方便修改和对比

### 整体评估
- [ ] 作品的核心创意和主题在审核后还能保留吗？
- [ ] 敏感内容都经过了艺术化处理吗？（暗示/侧面/留白/结果/影响）
- [ ] 没有为了过审把故事改得面目全非吗？
- [ ] 你自己对作品的内容负责吗？（不是"平台没说不能写就写"）
- [ ] 如果是你自己的孩子/父母看这个作品，你会觉得合适吗？

**任何一项不通过，回到对应部分修改，修改后重新自检。全部通过后，可以发布。**

**重要提醒**：本模块提供的是一般性的内容审核指导，不构成法律意见。具体的法律问题请咨询专业律师。不同平台和地区的审核规则会变化，发布前请以目标平台的最新规则为准。

---

> **内容审核的终极目标**：让你的作品既能安全发布，又能保留核心表达。好的作者不是"什么都敢写"，而是"知道边界在哪里，然后在边界内写出最好的作品"。记住：审核不是敌人，是规则——就像游戏有规则一样，创作也有规则。真正的高手，能在规则内玩出最精彩的花样。当你学会用"暗示代替直接、侧面代替正面、结果代替过程"，你会发现，你的作品不仅更安全，也更高级——因为留白和暗示，往往比直接描写更有力量。
