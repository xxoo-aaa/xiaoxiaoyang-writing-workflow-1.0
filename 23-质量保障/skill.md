# 23-质量保障

> 作品质量的最终把关人。负责全流程质量门禁、六维质量评分、风格一致性检查、逻辑漏洞检测、质量提升指导。不只是找问题，还要教你怎么改好。

---

## 一、技能定位

- **名称**：质量保障
- **功能**：质量检查 + 评分 + 问题诊断 + 具体修改建议 + 迭代提升指导
- **适用场景**：每个阶段门禁检查、初稿完成后全面质检、终稿最终评分、用户要求"帮我看看哪里有问题"时
- **核心原则**：不只是说"这里有问题"，必须说"问题是什么+为什么是问题+具体怎么改+改成什么样"
- **不做什么**：不替用户做创作决策，只给问题和建议；不直接修改正文（除非用户明确要求"直接改"）

## 二、全流程质量门禁检查清单

> 对应99-全局规则第十一章。每个阶段完成后必须通过门禁才能进入下一阶段。以下是每个阶段的具体检查操作方法。

### 2.1 创意阶段门禁

**检查项1：创新点检查**
- 操作：列出作品所有创新点→逐个问"这个在同类作品里常见吗？"→常见的标红
- 通过标准：至少1个核心创新点，且通过独特性检查
- 不通过：回到02-创意引擎，用创新五法重新生成

**检查项2：独特性检查**
- 操作：用一句话概括核心设定→搜索/回忆是否有高度相似的作品→有则标红
- 通过标准：不是烂大街的设定，有明显的差异化元素
- 不通过：调整核心设定，加入差异化元素

**检查项3：情感动机检查**
- 操作：问"作者为什么想写这个？"→答案是否具体→不具体则标红
- 通过标准：有明确的"为什么想写"，不是"就是想写"
- 不通过：回到27-写作搭档阶段二，重新挖掘情感动机

### 2.2 人物阶段门禁

**检查项1：动机检查**
- 操作：列出主角的欲望→问"他为什么想要这个？"→动机是否能支撑所有关键行为
- 通过标准：主角有明确的欲望+为什么想要+动机能支撑行为
- 不通过：回到06-人物塑造，深化动机

**检查项2：缺陷检查**
- 操作：列出主角的缺陷→问"这个缺陷会给他带来麻烦吗？"→缺陷是否在故事中发挥作用
- 通过标准：主角有致命缺陷，且缺陷会影响情节发展
- 不通过：给主角加一个会带来麻烦的缺陷

**检查项3：逻辑检查**
- 操作：列出主角的3个关键行为→逐个问"这个行为符合他的性格和经历吗？"
- 通过标准：主角的行为可预测（符合性格的可预测，不是剧透的可预测）
- 不通过：调整人物性格或行为，使其一致

**检查项4：人味检查**
- 操作：检查主角是否有怪癖/习惯/秘密/过去→是否有至少一个"无用但有神"的细节
- 通过标准：主角有怪癖/习惯/秘密/过去，有至少一个生活细节
- 不通过：给主角加人味细节

### 2.3 世界观阶段门禁

**检查项1：自洽检查**
- 操作：列出世界观所有规则→逐个检查规则之间是否有矛盾
- 通过标准：规则之间不矛盾，超自然/科幻设定有内部逻辑
- 不通过：统一规则，消除矛盾

**检查项2：层次检查**
- 操作：检查世界观是否有表层规则+深层历史+边缘地带
- 通过标准：有三个层次，不是只有一个扁平的设定
- 不通过：补全世界观层次

**检查项3：创新检查**
- 操作：问"这个世界观是通用的魔法/科幻设定吗？有没有独特的规则？"
- 通过标准：不是通用设定，有至少1个独特的规则
- 不通过：用假设颠覆法给世界观加独特规则

### 2.4 结构阶段门禁

**检查项1：冲突检查**
- 操作：列出核心冲突→问"双方力量对比合理吗？冲突足够强吗？"
- 通过标准：核心冲突足够强，双方力量对比合理（不是一边倒）
- 不通过：加强冲突或调整力量对比

**检查项2：转折检查**
- 操作：列出所有转折点→逐个检查"有伏笔吗？改变了故事走向吗？"
- 通过标准：每个转折有伏笔，且改变了故事走向
- 不通过：给转折加伏笔，或调整转折使其影响更大

**检查项3：节奏检查**
- 操作：标出每个场景的紧张度（1-10）→画出曲线→检查是否有连续三个高位或连续三个低位
- 通过标准：张弛曲线合理，有紧张有缓冲
- 不通过：调整场景顺序或加缓冲场景/冲突场景

**检查项4：逻辑检查**
- 操作：列出因果链→每个事件问"为什么会发生？"→检查是否有"巧合解决问题"
- 通过标准：因果链完整，没有巧合解决问题，主角靠自己解决问题
- 不通过：把巧合改成有因果的事件

### 2.5 场景写作门禁

**检查项1：人味9条**
- 操作：逐条对照99-全局规则第九章9.1的9条标准检查
- 通过标准：9条全过
- 不通过：当场修改该场景

**检查项2：细节检查**
- 操作：检查场景中的细节是否具体→有没有通用描写（很好/很乱/很漂亮）
- 通过标准：细节具体不通用，每1000字至少3个具体细节
- 不通过：把通用细节改成具体细节

**检查项3：钩子检查**
- 操作：检查场景结尾→问"读者想继续看下一场吗？"
- 通过标准：场景结尾有钩子（悬念/冲突/疑问/反差）
- 不通过：给场景结尾加钩子

**检查项4：想象力检查**
- 操作：检查场景是否有至少1个"意想不到但合理"的元素
- 通过标准：有至少1个反常规元素，且有逻辑支撑
- 不通过：给场景加想象力元素

### 2.6 对话阶段门禁

**检查项1：潜台词检查**
- 操作：检查每段对话→问"每个人都在说真心话吗？还是有话没说出来？"
- 通过标准：不是所有人都说真心话，至少有1处有潜台词
- 不通过：给对话加潜台词

**检查项2：差异化检查**
- 操作：遮住人名，只读对话→问"能分辨是谁在说吗？"
- 通过标准：每个人说话方式不同，能只看对话分辨人物
- 不通过：给每个人物加独特的语言特征

**检查项3：人味检查**
- 操作：检查对话是否有打断/答非所问/不了了之→是否每个人都说完整的话
- 通过标准：有打断/答非所问/不了了之，不是每个人都说完整的话
- 不通过：把完整对话改成不完整的、有生活气息的对话

### 2.7 初稿完成门禁

**检查项1：六维全面检查**
- 操作：按六维标准（人味/创新/逻辑/准确/丰富/想象力）全面检查
- 通过标准：各维度无致命问题
- 不通过：列出问题清单，按优先级修订

**检查项2：风格一致性检查**
- 操作：加载风格参数卡→逐段检查是否有风格漂移
- 通过标准：风格无漂移，全文风格统一
- 不通过：标注漂移段落，给出修改建议

**检查项3：伏笔回收检查**
- 操作：列出所有伏笔→逐个检查是否有回收→回收时是否和前面对得上
- 通过标准：所有伏笔有回收，回收时和前面对得上
- 不通过：给未回收的伏笔安排回收点，或删掉不需要的伏笔

### 2.8 终稿门禁

**检查项1：六维质量评分**
- 操作：按六维评分体系评分（见第三章）
- 通过标准：总分≥45/60
- 不通过：找出最弱的2个维度，用质量提升操作手册针对性修订

**检查项2：最终逻辑检查**
- 操作：最终检查人物逻辑/情节逻辑/世界观逻辑/时间线
- 通过标准：无逻辑漏洞
- 不通过：修复漏洞

**检查项3：内容审核**
- 操作：转24-内容审核模块，检查敏感内容和平台规则
- 通过标准：无敏感内容，符合目标平台规则
- 不通过：按24模块建议修改

## 三、六维质量评分体系

### 3.1 评分标准（每维10分，总分60）

| 维度 | 10分（完美） | 7分（良好） | 4分（及格） | 1分（差） |
|------|-------------|-----------|-----------|----------|
| **人味** | 完全无AI味，每个细节都有人的温度，对话像真人 | 基本无AI味，个别段落有痕迹 | AI味明显，多处情绪标签和通用描写 | 通篇AI味，像机器写的 |
| **创新** | 3个以上创新点，每个都让人眼前一亮 | 有2个创新点，其中1个比较新颖 | 只有1个创新点或创新点很弱 | 完全是套路，没有任何创新 |
| **逻辑** | 人物/情节/世界观/时间线完全自洽，找不到漏洞 | 基本自洽，有1-2个小漏洞但不影响阅读 | 有明显逻辑漏洞，需要读者自行脑补 | 逻辑混乱，多处硬伤 |
| **准确** | 所有细节准确，情感反应精准，节奏完美 | 基本准确，个别细节有瑕疵 | 有多处不准确，影响代入感 | 大量错误，完全不可信 |
| **丰富** | 细节/人物/世界都非常丰富，每个角落都有东西 | 比较丰富，主要维度都覆盖了 | 比较单薄，只有主线没有血肉 | 极度贫瘠，只有骨架没有肉 |
| **想象力** | 多处意想不到但合理的元素，让人惊叹 | 有几处想象力亮点 | 想象力一般，偶尔有亮点 | 完全 predictable，没有任何意外 |

### 3.2 评分等级

| 分数 | 等级 | 建议 |
|------|------|------|
| 55-60 | 神作级 | 可以直接投稿/发表 |
| 45-54 | 优秀 | 小修后可以投稿/发表 |
| 35-44 | 良好 | 需要中等程度修订 |
| 25-34 | 及格 | 需要大幅修订 |
| 25以下 | 建议重写 | 问题在根基，建议回到对应阶段重构 |

### 3.3 评分操作方法

1. **逐维度评分**：每个维度给出具体分数，不能只给总分
2. **每个维度给理由**：至少举出2个具体例子（好的例子和差的例子），不能只给分
3. **给出总分和等级**：六维分数相加，对应等级
4. **给出改进方向**：列出"最需要改进的3个维度"和具体改进建议
5. **使用模板**：用templates/作品质量评分表.md记录评分结果

## 四、风格一致性检查

### 4.1 检查方法

1. 加载作品确定的风格参数卡（templates/风格参数卡.md）
2. 逐段检查：用词是否符合风格？句子节奏是否符合？情绪表达是否符合？细节密度是否符合？叙事距离是否符合？
3. 标红风格漂移的段落
4. 给出修改建议（应该改成什么样）

### 4.2 常见风格漂移

| 风格 | 常见漂移 | 修改方向 |
|------|---------|---------|
| 冷峻 | 突然出现煽情段落 | 删掉煽情，用动作泄露情绪 |
| 温暖 | 突然出现过于残酷的描写 | 残酷的部分用侧面描写，保持温度 |
| 荒诞 | 突然出现过于严肃的段落 | 给严肃段落加荒诞元素，保持戏谑感 |
| 诗意 | 突然出现过于口语化的表达 | 把口语化表达改成意象化表达 |
| 黑色幽默 | 突然变得完全悲伤没有幽默 | 在悲伤中加幽默元素，保持冷面笑匠感 |
| 致郁 | 突然出现过于明亮的段落 | 把明亮的部分改成"短暂的希望然后破灭" |
| 史诗 | 突然出现过于私人化的琐碎描写 | 把琐碎描写和宏大叙事结合起来 |
| 日常 | 突然出现过于戏剧化的情节 | 把戏剧化情节改成日常中的小意外 |

## 五、逻辑漏洞检测

### 5.1 人物逻辑检测

1. 列出主角每个关键行为→检查动机是否成立
2. 检查人物变化是否有铺垫
3. 检查人物语言风格是否统一
4. 检查人物的知识/能力是否符合其背景（不能突然会了一个他不可能会的技能）

### 5.2 情节逻辑检测

1. 列出每个关键事件→检查因果关系
2. 检查是否有"巧合解决问题"的情况（巧合只能引发麻烦，不能解决麻烦）
3. 检查主角是否靠自己解决问题（不能靠外部救援或突然出现的帮手）
4. 检查信息差是否合理（人物知道什么、不知道什么，是否符合逻辑）

### 5.3 世界观逻辑检测

1. 列出所有规则→检查是否有矛盾
2. 检查超自然/科幻设定是否有内部逻辑（不能想怎样就怎样）
3. 检查社会规则是否符合世界观设定（科技水平/政治制度/经济体系是否自洽）
4. 检查世界观规则是否被情节违反（设定了不能做的事，后面角色做了却没有解释）

### 5.4 时间线检测

1. 列出所有事件的时间→检查顺序和间隔
2. 检查人物年龄是否一致
3. 检查季节/天气是否一致
4. 检查时间流逝是否合理（不能一天之内发生了需要一个月才能完成的事）

### 5.5 伏笔回收检测

1. 列出所有伏笔→检查是否有回收
2. 检查回收时是否和前面的伏笔对得上（细节一致）
3. 标红"埋了但没回收"的伏笔
4. 检查是否有"突然出现的回收"（前面没埋，后面突然说"其实之前XX"）

## 六、质量提升操作手册

> 发现问题只是第一步，更重要的是具体怎么改才能变好。每个维度的问题都有对应的提升操作方法和示例。

### 6.1 人味提升操作手册

| 问题 | 具体提升方法 | 示例 |
|------|------------|------|
| 有情绪标签 | 把"他很愤怒"改成三步：①生理反应②动作③他人反应，三选二 | ❌他很愤怒 → ✅他攥着杯子，指节发白，没说话 |
| 有逻辑过渡词 | 删掉"然而/因此/于是"，用动作或场景自然过渡 | ❌然而他不知道，危险正在逼近 → ✅他没回头。身后的影子越拉越长 |
| 段落长度单一 | 把长段拆成短段，在关键情绪点用1-2句的极短段 | （一段5句的情绪描写→拆成3段，最后一段只有一句："他没哭。"） |
| 细节通用 | 把"房间很乱"改成具体的、能透露人物信息的细节 | ❌房间很乱 → ✅床上堆着三件外套，最上面那件是前女友的，吊牌还没剪 |
| 对话太完整 | 给对话加打断、答非所问、潜台词、不了了之 | ❌"你为什么不告诉我？""我怕你担心。" → ✅"你为什么——""吃饭了吗？"她把碗推过来 |
| 结尾在总结 | 删掉最后一段的总结/点题，停在前面的画面或动作上 | ❌他知道，一切都回不去了。 → ✅他把钥匙放在门口的鞋柜上，没带走 |
| 开头在环境/心理描写 | 把开头换到动作/细节/对话上 | ❌那天天气很好，他心情很复杂。 → ✅他把第三根烟掐灭在泡面汤里，汤面上浮着一层油花 |

### 6.2 创新提升操作手册

| 问题 | 具体提升方法 | 示例 |
|------|------------|------|
| 设定太常见 | 用假设颠覆法：把这个设定的核心规则反过来 | 常见：穿越者想回去 → 颠覆：穿越者不想回去，因为现代世界有他不敢面对的事 |
| 人物太扁平 | 给人物加一个矛盾特质：他的职业/身份和他的某个特质是矛盾的 | 医生怕血、杀手喜欢织毛衣、律师口吃、消防员怕火 |
| 情节太套路 | 在读者最预期的地方反着来：读者以为A会发生，结果发生了B，但B又合理 | 读者以为主角会在最后时刻赶到救人 → 主角迟到了，人已经死了，但他发现死者留下了线索 |
| 反转太刻意 | 给反转加3个伏笔，散落在前面，回头看所有细节都对得上 | 反转：管家是凶手 → 前面埋：①管家总戴手套②管家对死者的房间比谁都熟③案发前管家买了和死者同款的药 |
| 没有创新点 | 用跨界碰撞法：把故事和一个完全不相关的领域结合 | 宫廷斗争+职场政治（后宫就是办公室，争宠就是KPI）、武侠+快递业（镖局就是古代快递） |
| 创新点是伪创新 | 检查：换了皮之后核心故事是不是一样？一样就是伪创新，必须改核心设定 | 伪创新：把男主换成女主，但故事还是"废柴逆袭" → 真创新：女主不是废柴，她是故意装废柴，因为太强了会被灭口 |

### 6.3 逻辑提升操作手册

| 问题 | 具体提升方法 | 示例 |
|------|------------|------|
| 人物动机不足 | 给人物的行为加一个"为什么"，并且这个为什么必须和他的过去/创伤/欲望挂钩 | 主角为什么要救陌生人？→ 因为他小时候亲眼看着妹妹淹死，他没能救，现在看到有人落水就控制不住 |
| 情节有漏洞 | 用因果链检查：每个事件问"为什么会发生？"，如果答案是"巧合"或"作者需要"，就改成有因果的 | 主角恰好遇到关键人物 → 改成：主角一直在找这个人，通过线索追踪到这里，遇到是必然 |
| 世界观不自洽 | 列出所有规则，检查规则之间的矛盾，然后统一规则 | 设定：这个世界没有谎言 → 但人们怎么保守秘密？→ 补充规则：人们可以沉默，可以说部分真相，但不能说假话，秘密靠"不说"来保守 |
| 时间线混乱 | 画一条时间线，把所有事件标上去，检查顺序和间隔是否合理 | 发现：主角上周还在北京，这周就到了纽约，但没写他怎么去的 → 补充：他坐了红眼航班，在飞机上发生了XX |
| 伏笔没回收 | 列出所有伏笔，给每个伏笔安排回收点，回收时必须和前面的伏笔呼应 | 前面写：主角总摸口袋里的一枚硬币 → 后面回收：这枚硬币是他女儿给他的，他最后用这枚硬币做了一个关键决定 |
| 人物突然会了不可能的技能 | 检查：这个技能他之前有铺垫吗？没有就加铺垫，或者删掉这个技能 | 主角突然会开锁 → 加铺垫：前面写他小时候在配钥匙店打过工，或者他爸是锁匠 |

### 6.4 准确提升操作手册

| 问题 | 具体提升方法 | 示例 |
|------|------------|------|
| 职业细节错误 | 涉及专业领域时，必须查证：查该职业的真实工作流程、术语、工具、环境 | 写医生手术 → 查证：手术流程、器械名称、医生在手术中的对话方式、手术室的真实环境 |
| 情感反应不准 | 问：一个有这样性格/经历的人，遇到这种事，真实反应是什么？不是"应该"的反应，是"真实"的反应 | 亲人去世 → 真实反应不一定是哭，可能是麻木、是笑、是继续做家务、是反复整理遗物 |
| 节奏不对 | 画节奏曲线：标出每个场景的紧张度（1-10），连续高位就加缓冲场景，连续低位就加冲突 | 发现：连续5个场景都是紧张度8以上 → 在第3个后面加一个缓冲场景（主角在便利店吃泡面，和店员闲聊），然后再回到紧张 |
| 历史/时代错误 | 查证该时代的服饰、用语、科技、社会规则、生活细节 | 写唐朝故事 → 查证：唐朝没有椅子（坐榻）、没有辣椒、货币是铜钱和绢帛、普通人的名字是什么样的 |
| 科技细节错误 | 查证现有科技的真实能力，未来科技要有内部逻辑 | 写黑客 → 查证：真实的黑客攻击是什么样的（不是敲几下键盘就黑进五角大楼），用什么工具，需要多长时间 |

### 6.5 丰富提升操作手册

| 问题 | 具体提升方法 | 示例 |
|------|------------|------|
| 细节太少 | 每1000字至少加3个具体细节，细节必须能透露人物/氛围/主题 | 加细节：主角的指甲缝里有洗不掉的机油味（透露他的职业）、他总把笔帽咬变形（透露他的焦虑习惯） |
| 人物太单薄 | 给每个人物加3个维度：他的秘密、他的怪癖、他和主线无关的一个爱好 | 配角不只是"主角的朋友" → 他有自己的秘密（他欠了赌债）、他的怪癖（他收集酒店的一次性牙刷）、他的爱好（他周末去跳广场舞） |
| 世界太扁平 | 给世界观加3个层次：表层规则、深层历史、边缘地带 | 魔法世界不只是"有魔法" → 表层：魔法需要执照，无证施法是犯罪；深层：魔法来源于一种即将枯竭的矿物；边缘：有一群人住在魔法辐射区，变异了但有特殊能力 |
| 没有"无用但有神"的细节 | 给每个主要场景加一个和情节无关但有生活温度的细节 | 场景：两人在咖啡馆谈判 → 加细节：窗外有只猫一直在追自己的尾巴，谈判最紧张的时候猫撞到了玻璃，两人都愣了一下 |
| 反派太单薄 | 给反派加：合理的动机、自己的逻辑、不为人知的一面 | 反派不只是"坏人" → 他的动机：他做的一切是为了给女儿治病，他的逻辑：他认为牺牲少数人救多数人是对的，他的一面：他在孤儿院做志愿者 |

### 6.6 想象力提升操作手册

| 问题 | 具体提升方法 | 示例 |
|------|------------|------|
| 情节太 predictable | 在读者最预期的地方问："如果反过来会怎样？"然后把反过来的版本写得合理 | 读者预期：主角会在决斗中赢 → 反过来：主角输了，但输了反而达成了他真正的目的（他故意输，因为赢了会被灭口） |
| 人物没有意外 | 给人物加一个"意想不到但合理"的特质，这个特质必须和他的身份/经历有逻辑关系 | 一个冷面杀手 → 意想不到：他每周去孤儿院做志愿者，因为他自己就是孤儿院出来的，他不想让那些孩子和他一样 |
| 场景没有意外 | 给场景加一个"反常规"元素，这个元素必须和场景的情绪/主题形成反差 | 葬礼场景 → 反常规：死者的遗像在笑，而且是那种很调皮的笑，家属说"他生前就这德行，死了也不改" |
| 对话没有意外 | 给对话加一个"意外的潜台词"：嘴上说的是A，实际意思是B，而且B是读者没想到的 | 两人分手，一方说"你以后要好好吃饭" → 潜台词：我还爱你，但我不能再照顾你了，这句话是我最后的关心 |
| 结构没有意外 | 给结构加一个"反套路"的设计：读者以为故事是A结构，结果发现是B结构 | 读者以为是线性叙事 → 结果发现：前面所有的场景都是主角在昏迷中的回忆，现实中他躺在医院里，故事的"现在"其实是他的濒死体验 |
| 世界观没有意外 | 给世界观加一个"反常识但自洽"的规则：这个规则和读者的常识相反，但在这个世界里是合理的 | 常见：魔法越强越好 → 反常识：在这个世界里，魔法越强，寿命越短，所以最强的魔法师都在拼命隐藏自己的能力 |

## 七、质量迭代提升机制

> 不是"检查完就完了"，而是"评分→针对性提升→再评分→直到达到目标"的迭代循环。

### 7.1 迭代流程

```
初稿完成
  ↓
六维评分（每维10分，总分60）
  ↓
确定目标分数（用户设定，比如"我要达到50分"）
  ↓
如果达到目标 → 完成，进入内容审核
如果没达到 → 找出得分最低的2个维度
  ↓
用质量提升操作手册，针对这2个维度给出具体修改建议（逐段标注+修改示例）
  ↓
用户修改（或AI辅助修改）
  ↓
重新评分（只评修改过的维度，其他维度保持）
  ↓
循环，直到达到目标分数
```

### 7.2 迭代规则

1. **每次迭代只聚焦1-2个最弱的维度**，不贪多
2. **每次迭代必须给出具体到段落的修改建议**，不能只说"人味不够"
3. **每次迭代后重新评分**，记录分数变化，让用户看到进步
4. **最多迭代5轮**，5轮后还没达到目标，说明问题在根基（创意/人物/结构），建议回到对应阶段重构
5. **用户可以随时说"够了，就这样"**，停止迭代，当前分数即为最终分数

### 7.3 质量提升报告模板

```
质量提升报告 · 第X轮迭代
作品名称：
当前总分：X/60
目标分数：X/60

本轮聚焦维度：
1. XX（当前X分，目标X分）
2. XX（当前X分，目标X分）

具体修改建议（逐段标注）：
【第X段】问题：XX → 修改建议：XX → 修改示例：❌XX → ✅XX
【第X段】问题：XX → 修改建议：XX → 修改示例：❌XX → ✅XX
...

修改后预期分数：X/60
下一步：修改完成后重新评分
```
