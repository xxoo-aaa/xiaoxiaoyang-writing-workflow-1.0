# 22-修订与审校 · 技能

> 把初稿打磨成定稿：修订流程SOP、大修与小修、常见问题排查、自我审校方法、反馈处理。

## 何时调用
- 用户需要修订/修改已写的稿子
- 用户需要自我审校的方法和清单
- 用户收到反馈需要处理
- 用户说"帮我改稿/修订/审校"

## 输入要求
- 待修订的文稿（全文或具体段落）
- 修订目标（大修/小修/特定问题）
- 可选：反馈意见、参考标准

## 输出格式
- 修订计划（先改什么后改什么）
- 具体问题诊断（结构/人物/节奏/文字等层面的问题）
- 修改建议和示例
- 修订后的文本（如果需要直接改写）
- 修订Checklist
- 自我审校方法

## 核心方法论

### 修订的核心理念

**初稿是把故事写出来，修订是把故事写好。**
- 初稿关注"有没有"，修订关注"好不好"
- 初稿是创作，修订是雕刻
- 不要在初稿阶段就追求完美（那会写不下去），也不要在修订阶段敷衍（那会浪费初稿）

**修订的层次（从大到小）**：
1. **结构修订（大修）**：故事结构、情节逻辑、人物弧线、主题表达
2. **场景修订（中修）**：场景的目标/冲突/转折、场景顺序、场景删减
3. **人物修订（中修）**：人物一致性、动机、关系、语言差异化
4. **节奏修订（中修）**：张弛节奏、信息密度、场景长度、悬念维持
5. **文字修订（小修）**：用词、句式、对话、描写、展示vs说明
6. **校对（微修）**：错别字、标点、语法、格式

**修订顺序原则**：先大后小。先改结构，再改场景，再改文字。不要一开始就纠结用词，因为后面可能整段都删掉。

### 修订流程SOP

**第一步：冷却**
- 初稿完成后，放至少3天（最好7天），不要看
- 让自己从"创作者"心态切换到"读者"心态
- 冷却后再读，会看到很多写作时看不到的问题

**第二步：通读（不修改）**
- 完整通读一遍，不要停下来修改
- 只做标记：哪里觉得无聊、哪里困惑、哪里感动、哪里想跳过去
- 记录整体印象：故事讲清楚了吗？人物立住了吗？节奏怎么样？
- 这一步的目标是获得整体感受，不是找具体问题

**第三步：诊断**
- 按层次诊断问题：
  - 结构层面：三幕是否完整？转折点是否有力？有没有松散的部分？
  - 人物层面：主角的动机清晰吗？人物一致吗？弧线完整吗？
  - 场景层面：每个场景都有目标/冲突/转折吗？有没有可以删掉的场景？
  - 节奏层面：有没有拖沓的部分？有没有太快的部分？张弛交替吗？
  - 文字层面：有没有说明（Tell）可以改成展示（Show）？对话自然吗？
- 列出问题清单，按严重程度排序
- 确定哪些是必须改的，哪些是可选的

**第四步：大修（结构/情节/人物）**
- 先解决最大的问题：结构、情节逻辑、人物弧线
- 可能需要增删场景、调整顺序、重写人物、修改结局
- 大修后可能需要重新通读，因为结构变了
- 大修是最痛苦但最重要的阶段

**第五步：中修（场景/节奏/对话）**
- 结构确定后，修改每个场景
- 确保每个场景都有目标、冲突、转折
- 调整场景顺序和长度，控制节奏
- 修改对话，让对话更自然、更有潜台词、更有辨识度
- 检查信息释放节奏，确保悬念维持

**第六步：小修（文字/描写）**
- 结构和场景都确定后，再改文字
- 把说明（Tell）改成展示（Show）
- 优化用词，删除冗余，增强感官细节
- 调整句式节奏（长短句交替）
- 检查重复用词和陈词滥调

**第七步：校对**
- 最后检查错别字、标点、语法、格式
- 可以用工具辅助（拼写检查、语法检查）
- 但不要完全依赖工具，人工通读一遍
- 校对是最后一步，不要在前面的阶段花时间在校对上

**第八步：最终通读**
- 全部改完后，完整通读最后一遍
- 检查整体流畅度，确保修改没有引入新问题
- 确认达到了定稿标准

### 常见问题诊断与修改

**结构问题**：
| 问题 | 表现 | 修改方向 |
|---|---|---|
| 开头拖沓 | 前3章没有进入核心冲突 | 删掉铺垫，从冲突开始，把背景信息推后 |
| 中段疲软 | 中间1/3无聊，没有进展 | 增加大反转，提高 stakes，引入新冲突/人物 |
| 结尾仓促 | 最后解决所有问题太突然 | 提前铺垫，增加过渡，让变化有过程 |
| 转折点无力 | 关键转折没有冲击力 | 提高转折的 stakes，增加铺垫，让转折改变故事方向 |
| 副线松散 | 支线和主线没有关系 | 让副线和主线交汇，或删掉无关副线 |

**人物问题**：
| 问题 | 表现 | 修改方向 |
|---|---|---|
| 动机不明 | 不知道主角为什么这么做 | 明确主角的目标和动机，通过行动展示 |
| 人物不一致 | 前后性格/行为矛盾 | 建立人物档案，确保变化有铺垫和过程 |
| 人物扁平 | 人物没有深度，像工具人 | 增加内在冲突、核心创伤、矛盾性 |
| 对话雷同 | 所有人说话方式一样 | 给每个人物独特的语言特征（用词/句式/语气） |
| 关系无变化 | 人物关系从头到尾一样 | 设计关系的变化曲线（初识→靠近→危机→确认） |

**节奏问题**：
| 问题 | 表现 | 修改方向 |
|---|---|---|
| 拖沓 | 大段说明/日常，没有进展 | 删掉无关内容，加快节奏，每个场景都推进 |
| 太快 | 重要变化没有过程，跳跃 | 增加过渡场景，让变化有铺垫和过程 |
| 一直紧张 | 没有喘息空间，读者疲劳 | 插入舒缓场景，张弛交替 |
| 一直平淡 | 没有高潮，张力不够 | 增加冲突和转折，提高 stakes |
| 信息倾倒 | 大段背景说明 | 把信息分散到场景中，通过行动/对话展示 |

**文字问题**：
| 问题 | 表现 | 修改方向 |
|---|---|---|
| 说明过多 | 直接告诉读者人物的感受/性格 | 改成展示（Show），用行动/细节/对话 |
| 副词滥用 | "他快速地跑""她生气地说" | 用强动词代替，用对话/动作展示情绪 |
| 陈词滥调 | "阳光明媚""心如刀绞""鸦雀无声" | 用具体的、独特的描写代替 |
| 重复用词 | 同一个词/短语反复出现 | 替换同义词，或用不同的表达方式 |
| 句式单一 | 都是短句或都是长句 | 长短句交替，根据情绪调整句式 |
| 感官缺失 | 只有视觉，没有其他感官 | 增加听觉/触觉/嗅觉/味觉细节 |

### 自我审校方法

**角色切换法**：
- 以"作者"身份写完后，切换到"读者"身份读
- 问自己：如果这是别人写的，我会想继续读吗？哪里会想跳过去？
- 切换到"编辑"身份：如果我是编辑，会接受这篇稿子吗？最大的问题是什么？
- 切换到"目标读者"身份：作为这个类型的读者，我满意吗？爽点/泪点够吗？

**朗读法**：
- 把稿子大声朗读出来
- 读的时候会发现：哪里不通顺、哪里节奏不对、哪里对话不自然
- 朗读是发现文字问题最有效的方法之一

**倒读法**：
- 从最后一段开始，倒着往前读
- 这样可以打破对故事的熟悉感，更容易发现文字层面的问题
- 适合小修和校对阶段

**场景检查法**：
- 逐个场景检查，每个场景问：
  - 这个场景的目标是什么？
  - 冲突是什么？
  - 转折是什么？（结束时和开始时有什么不同？）
  - 推进了情节/人物/关系吗？
  - 如果删掉这个场景，故事会受影响吗？
- 回答不上来的场景，考虑删掉或合并

**人物一致性检查法**：
- 列出主要人物的核心性格、说话方式、习惯
- 逐个场景检查：这个人物在这个场景的行为/语言符合他的设定吗？
- 如果有变化，有铺垫和过程吗？

**时间线检查法**：
- 列出所有重要事件的时间顺序
- 检查有没有时间矛盾（A事件在B之前，但叙事中暗示相反）
- 检查人物年龄、季节、历史事件是否一致

### 反馈处理

**收到反馈后的处理流程**：
1. **冷却**：不要立刻反应，放至少24小时
2. **分类**：把反馈分类（结构/人物/节奏/文字/个人偏好）
3. **验证**：每条反馈问自己：这是普遍问题还是个人偏好？有具体例子吗？
4. **优先级**：按严重程度排序，先改普遍的、严重的问题
5. **修改**：根据反馈修改，但不要盲目听从所有反馈（保持自己的判断）
6. **感谢**：感谢反馈者，即使你不认同所有意见

**处理反馈的原则**：
- 不要把反馈当成对个人的攻击，它是对作品的评价
- 不要盲目听从所有反馈，不同读者有不同偏好
- 但如果多个反馈者提到同一个问题，那很可能是真问题
- 反馈者说"我不喜欢"时，问"为什么"，找到具体原因
- 最终决定权在你，你是作者

### 修订Checklist

**结构**：
- [ ] 三幕结构完整吗？
- [ ] 激励事件足够打破日常吗？
- [ ] 第一幕转折点是主角主动选择吗？
- [ ] 中点改变了故事方向吗？
- [ ] 最低点足够"低"吗？
- [ ] 高潮是主角主动选择吗？（不是巧合/外力解决）
- [ ] 结局回应了开篇和主题吗？
- [ ] 有没有可以删掉的松散部分？

**人物**：
- [ ] 主角的目标和动机清晰吗？
- [ ] 主角有内在冲突和弧线吗？
- [ ] 人物行为前后一致吗？（变化有铺垫）
- [ ] 每个主要人物都有独特的说话方式吗？
- [ ] 人物关系有变化和发展吗？
- [ ] 反派有说服力的动机吗？
- [ ] 有没有工具人（没有自己目标的配角）？

**场景**：
- [ ] 每个场景都有明确的目标吗？
- [ ] 每个场景都有冲突吗？
- [ ] 每个场景结束时情况都有变化吗？
- [ ] 每个场景都推进了情节/人物/关系吗？
- [ ] 场景开头3行内进入冲突了吗？
- [ ] 场景结尾有钩子或余韵吗？
- [ ] 有没有可以删掉或合并的场景？

**节奏**：
- [ ] 紧张场景和舒缓场景交替吗？
- [ ] 有没有连续3个以上的快/慢场景？
- [ ] 信息释放节奏合适吗？（不是一次倒完）
- [ ] 悬念维持到最后了吗？
- [ ] 高潮前有"暴风雨前的宁静"吗？
- [ ] 整体节奏符合三幕结构吗？

**文字**：
- [ ] 有没有大段说明（Tell）？可以改成展示（Show）吗？
- [ ] 有没有副词滥用？（用强动词代替）
- [ ] 有没有陈词滥调？
- [ ] 有没有重复用词？
- [ ] 句式有变化吗？（长短句交替）
- [ ] 感官细节够吗？（至少2-3种感官）
- [ ] 对话自然吗？有潜台词吗？
- [ ] 有没有多余的形容词/修饰语？

**校对**：
- [ ] 有没有错别字？
- [ ] 标点正确吗？
- [ ] 语法正确吗？
- [ ] 格式统一吗？（人名/地名/时间格式）
- [ ] 前后一致吗？（人名/地名/设定没有矛盾）

## 调用示例
**用户**：帮我看看这段写得怎么样——"林深很生气。她走进房间，看到陈默在那里。她问他为什么要骗她。陈默说他没有骗她。他们吵了一架。最后林深哭着跑了出去。"
**技能输出**：
问题诊断：

1. **全是说明（Tell），没有展示（Show）**：
   - "林深很生气"→直接告诉读者情绪，没有展示
   - "他们吵了一架"→概括，没有具体内容
   - "林深哭着跑了出去"→有动作但太笼统

2. **没有冲突细节**：
   - 不知道他们吵了什么
   - 不知道陈默的反应和态度
   - 冲突没有升级过程

3. **没有感官和氛围**：
   - 房间是什么样的？
   - 天气/时间/环境？
   - 声音/温度/气味？

4. **节奏太平**：
   - 从头到尾都是概括，没有起伏
   - 没有转折点，冲突一开始就结束了

5. **人物没有辨识度**：
   - 不知道林深和陈默的性格
   - 他们说话方式没有区别

修改建议（展示版）：

"门被推开时撞在墙上，震得相框跳了一下。
林深站在门口，胸口剧烈起伏，外套扣子扣错了一颗。她的目光扫过房间，落在陈默身上。
陈默坐在沙发边缘，双手交握在膝盖上，茶杯已经凉了。'你回来了。'他的声音很平。
'你跟她说了什么？'林深的声音从牙缝里挤出来，每一个字都像是砸出来的。
陈默抬起眼，目光里没有惧意，只有一种疲惫的平静。'我说了实话。'
'实话？'林深往前走了一步，鞋底碾过地毯上的酒渍，'你知道实话会毁了一切吗？'
'那又怎样？'陈默站起来，声音第一次有了波动，'你打算瞒多久？瞒一辈子？'
林深张了张嘴，却没说出话。
窗外的雷声滚过，房间里的灯闪了一下。
她转身，门再次被摔上，这次震得相框掉在了地上，玻璃碎了一地。
陈默站在原地，看着地上的碎玻璃，很久没有动。"

修改要点：
1. **用动作展示情绪**：撞门、扣子扣错、声音从牙缝挤出、碾过酒渍——这些动作展示了愤怒，不需要说"她很生气"
2. **具体的对话内容**：不是"吵了一架"，而是具体的争吵内容，展示了冲突的核心（瞒vs说实话）
3. **感官和氛围**：凉了的茶杯、酒渍、雷声、灯闪、碎玻璃——这些细节营造了氛围
4. **节奏和转折**：从林深进门→质问→陈默反击→林深语塞→摔门离开，有起伏和转折
5. **人物性格**：林深的激烈（撞门、碾酒渍）和陈默的平静但坚定（声音平、站起来反驳）形成对比
6. **结尾余韵**：陈默看着碎玻璃不动，比"他很伤心"更有力量

进一步建议：
- 可以增加一个细节：林深的手在发抖，或者她的眼眶红了但忍住没哭——展示她在愤怒之下的脆弱
- 陈默的"实话"具体是什么？可以在对话中暗示，但不要完全说破，留悬念
- 场景开头可以更快：直接从林深进门开始，不要铺垫
- 如果这是关键场景，可以写得更长，增加冲突升级的过程

## 正反示例对比

### 示例：修订流程的好与坏

❌ **差的修订方式**：
> 小明写完初稿，当天就开始修改。
> 他从第一段开始，逐字逐句改用词、改句式、改标点。
> 改了三天，改完了前三章，觉得"写得真好"。
> 然后继续改第四章，改到一半发现：第三章的人物动机有问题，需要大改。
> 结果前三章白改了——因为人物动机变了，前三章的对话和行为都要重写。
> 又改了一周，发现整个故事的结构有问题，中点转折不够有力，需要调整结构。
> 结果前面改的所有文字都白改了——因为结构变了，很多场景要删掉或重写。
> 一个月后，小明还在改，越改越乱，最后放弃了。
>
> （问题：没有冷却，没有先诊断，从文字开始改（从小到大），结果大改后小改白做了，浪费时间和精力。）

✅ **好的修订方式**：
> 小明写完初稿，把文件放了七天，完全不看。
>
> 第七天，他通读一遍，只做标记，不修改。他发现：整体结构没问题，但中段疲软，主角动机在第三章后不清晰，对话有些干。
>
> 他列出问题清单，按严重程度排序：
> 1. 主角动机不清晰（结构/人物问题，必须改）
> 2. 中段疲软（节奏问题，必须改）
> 3. 对话干（文字问题，可以改）
> 4. 有些用词可以优化（小问题，可选）
>
> 他先改结构和人物：明确主角动机，增加中段的反转和冲突。这一步花了三天，改了大纲，重写了几个关键场景。
>
> 结构确定后，他再改场景和节奏：确保每个场景有目标/冲突/转折，调整场景顺序，控制节奏。这一步花了两天。
>
> 然后改文字：把说明改成展示，优化对话，增强感官细节。这一步花了两天。
>
> 最后校对：错别字、标点、格式。花了半天。
>
> 全部改完后，他完整通读最后一遍，确认没有问题，定稿。
>
> 总共花了十天，比"差的方式"还快，而且质量高得多。
>
> （好的原因：先冷却，先诊断，从大到小改（结构→场景→文字→校对），大改确定后再小改，不浪费时间，效率高，质量好。）

### 示例：反馈处理的好与坏

❌ **差的反馈处理**：
> 小明把稿子发给三个朋友看。
>
> 朋友A说："开头太慢了，我看到第三章才进入状态。"
> 小明立刻把前三章删掉了一半，开头变得很快。
>
> 朋友B说："主角太弱了，我不喜欢。"
> 小明立刻把主角改得很强，加了很多金手指。
>
> 朋友C说："结局太悲伤了，我喜欢大团圆。"
> 小明立刻把结局改成了大团圆。
>
> 改完后，小明发现：故事变得不伦不类——开头太快没铺垫，主角太强没成长，结局和前面的基调不符。
>
> 他很困惑："我都按反馈改了，为什么反而更差了？"
>
> （问题：没有冷却，没有分类，没有验证，盲目听从所有反馈，不同反馈者的偏好不同，全部听从会导致故事失去统一性。）

✅ **好的反馈处理**：
> 小明把稿子发给三个朋友看。
>
> 收到反馈后，他没有立刻改，放了24小时。
>
> 然后他把反馈分类：
> - 朋友A："开头太慢" → 节奏问题
> - 朋友B："主角太弱" → 人物问题（但可能是个人偏好——朋友B喜欢爽文）
> - 朋友C："结局太悲伤" → 个人偏好（朋友C喜欢大团圆，但这个故事的主题就是悲剧）
>
> 他验证每条反馈：
> - "开头太慢"——三个朋友中有两个提到，而且他自己重读也觉得前三章铺垫太长。这是普遍问题，必须改。
> - "主角太弱"——只有朋友B提到，其他两个朋友觉得主角的成长弧线很好。这可能是个人偏好，不需要大改，但可以在前期增加主角的闪光点。
> - "结局太悲伤"——只有朋友C提到，而且这个故事的主题就是"失去与接受"，悲剧结局是主题需要。这是个人偏好，不改。
>
> 他按优先级修改：
> 1. 先改开头（节奏问题，普遍问题，必须改）——压缩前三章，把背景信息分散到后面
> 2. 再微调主角（人物问题，部分反馈，可选改）——在前期增加一个主角展现能力的场景
> 3. 结局不改（个人偏好，和主题冲突）
>
> 改完后，他感谢了三个朋友的反馈，即使他没有全部采纳。
>
> （好的原因：先冷却，分类，验证，区分普遍问题和个人偏好，按优先级修改，保持自己的判断和故事的统一性，不盲目听从所有反馈。）

## 常见问题及解法

| 问题 | 表现 | 解法 |
|------|------|------|
| **改不下去** | 初稿写完后不想看，一提修订就烦 | 先冷却（至少3天），让自己从创作者心态切换到读者心态；从最容易改的部分开始（如校对），慢慢进入状态；记住：修订是把故事写好的必经之路 |
| **越改越差** | 改了很多遍，反而不如初稿 | 停下来，回到初稿，重新诊断问题；不要为了改而改，每个修改都要有明确的理由；保留初稿，改坏了可以回退；记住：不是所有问题都需要改，"足够好"比"完美"更重要 |
| **不知道改什么** | 通读后觉得"还行"，找不到具体问题 | 用修订Checklist逐项检查；用角色切换法（读者/编辑/目标读者）；用朗读法（读出来会发现很多问题）；找别人给反馈（旁观者清） |
| **舍不得删** | 知道某段/某场景不好，但舍不得删（写的时候花了很多心血） | 记住："杀死你的宝贝"——好的作者会删掉写得好但对故事没用的部分；把删掉的内容存到"废弃素材"文件里，以后可能用得上；问自己："如果删掉这段，故事会受影响吗？"如果不会，就删 |
| **大修后要重写很多** | 结构改了，很多场景要重写，觉得前面白写了 | 这是正常的——初稿是探索，修订是定型；大修后重写是必要的，不要觉得浪费；记住：初稿的价值不在于文字，而在于帮你找到了故事的核心 |
| **修订时间比写作还长** | 写初稿用了一个月，修订用了三个月 | 这是正常的——好作品都是改出来的；但要设定修订时间限制，不要无限修订；区分"必须改"和"可选改"，先改必须改的；记住：没有完美的作品，只有"足够好可以发表"的作品 |
| **反馈让我很受伤** | 收到负面反馈，情绪低落，不想改了 | 先冷却（至少24小时），不要立刻反应；记住：反馈是对作品的评价，不是对你个人的攻击；把反馈当成"免费的编辑意见"，从中提取有价值的部分；感谢反馈者——愿意花时间给你反馈的人是在帮你 |
| **不同反馈矛盾** | A说开头太慢，B说开头太快，不知道听谁的 | 看哪个是普遍问题（多个反馈者提到）；看哪个更符合你的目标读者；看哪个更符合故事的主题和基调；最终决定权在你——你是作者，不需要让所有人满意 |
| **改完后不自信** | 改了很多遍，还是不确定好不好 | 用修订Checklist逐项检查，确认没有大问题；找1-2个信任的人做最终审读；记住：没有作者对自己的作品100%满意，"足够好"就可以发表；发表后根据读者反馈再改进 |
| **长篇修订无从下手** | 几十万字的长篇，不知道从哪开始改 | 先改整体结构（卷/部/章），再改场景，再改文字；按卷修订，一卷改完再改下一卷；建立修订清单，逐项完成；记住：长篇修订是大工程，要有计划，不要急 |

## 修订与审校质量自检清单

完成修订后，用以下清单确认修订质量：

### 修订流程
- [ ] 初稿完成后冷却了至少3天吗？
- [ ] 通读时只做标记不修改吗？
- [ ] 按从大到小的顺序修订吗？（结构→场景→文字→校对）
- [ ] 大修后重新通读了吗？
- [ ] 全部改完后最终通读了吗？

### 结构修订
- [ ] 三幕结构完整吗？
- [ ] 激励事件足够打破日常吗？
- [ ] 中点改变了故事方向吗？
- [ ] 最低点足够"低"吗？
- [ ] 高潮是主角主动选择吗？（不是巧合/外力解决）
- [ ] 结局回应了开篇和主题吗？
- [ ] 副线和主线交汇了吗？

### 人物修订
- [ ] 主角的目标和动机清晰吗？
- [ ] 主角有内在冲突和完整弧线吗？
- [ ] 人物行为前后一致吗？（变化有铺垫和过程）
- [ ] 每个主要人物都有独特的说话方式吗？
- [ ] 人物关系有变化和发展吗？
- [ ] 反派有说服力的动机吗？
- [ ] 没有工具人吗？（每个配角都有自己的目标）

### 场景修订
- [ ] 每个场景都有明确的目标吗？
- [ ] 每个场景都有冲突吗？
- [ ] 每个场景结束时情况都有变化吗？
- [ ] 每个场景都推进了情节/人物/关系吗？
- [ ] 场景开头3行内进入冲突了吗？
- [ ] 场景结尾有钩子或余韵吗？
- [ ] 没有可以删掉或合并的场景吗？

### 节奏修订
- [ ] 紧张场景和舒缓场景交替吗？
- [ ] 没有连续3个以上的快/慢场景吗？
- [ ] 信息释放节奏合适吗？（不是一次倒完）
- [ ] 悬念维持到最后了吗？
- [ ] 高潮前有"暴风雨前的宁静"吗？
- [ ] 整体节奏符合三幕结构吗？

### 文字修订
- [ ] 没有大段说明（Tell）吗？都改成展示（Show）了吗？
- [ ] 没有副词滥用吗？（用强动词代替）
- [ ] 没有陈词滥调吗？
- [ ] 没有重复用词吗？
- [ ] 句式有变化吗？（长短句交替）
- [ ] 感官细节够吗？（至少2-3种感官）
- [ ] 对话自然吗？有潜台词吗？
- [ ] 没有多余的形容词/修饰语吗？

### 校对
- [ ] 没有错别字吗？
- [ ] 标点正确吗？
- [ ] 语法正确吗？
- [ ] 格式统一吗？（人名/地名/时间格式）
- [ ] 前后一致吗？（人名/地名/设定没有矛盾）

### 反馈处理
- [ ] 收到反馈后冷却了至少24小时吗？
- [ ] 反馈分类了吗？（结构/人物/节奏/文字/个人偏好）
- [ ] 每条反馈验证了吗？（普遍问题还是个人偏好？有具体例子吗？）
- [ ] 按优先级修改了吗？（先改普遍的、严重的问题）
- [ ] 没有盲目听从所有反馈吗？（保持自己的判断）
- [ ] 感谢了反馈者吗？

### 整体质量
- [ ] 故事讲清楚了吗？
- [ ] 人物立住了吗？
- [ ] 节奏合适吗？（不会太慢也不会太快）
- [ ] 情感有冲击力吗？（读者会有感受）
- [ ] 主题表达了吗？（不是说教，是通过故事展示）
- [ ] 你自己满意吗？（不是完美，是"足够好"）

**任何一项不通过，回到对应部分修改，修改后重新自检。全部通过后，可以定稿。**

---

> **修订与审校的终极目标**：把"写出来的故事"变成"写好的故事"。初稿是孩子，修订是教育——你要耐心地、一步步地把它打磨成最好的样子。记住：好作品不是写出来的，是改出来的。当你改完最后一遍，通读全文，觉得"这个故事，是我想讲的那个"——你的修订就成功了。
