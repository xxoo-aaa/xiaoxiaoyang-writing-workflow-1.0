# 11-视角与叙事者 · 技能

> 控制叙事的质感：视角选择、叙事声音、不可靠叙事者、多视角切换、视角越界检测。

## 何时调用
- 用户需要选择/调整故事的叙事视角
- 用户需要设计叙事者的声音和风格
- 用户使用多视角，需要处理切换
- 用户想尝试不可靠叙事者
- 用户说"用第几人称写/视角怎么选"

## 输入要求
- 故事类型和核心概念
- 主要人物
- 可选：已有的视角选择、参考作品

## 输出格式
- 视角选择建议（各视角的优缺点对比，推荐最适合的）
- 叙事声音设计（语气、态度、风格）
- 如果多视角：视角人物选择、切换规则、信息差设计
- 如果不可靠叙事者：不可靠的类型、揭示时机、读者察觉路径
- 视角越界检测（有限视角下是否写了角色不可能知道的事）
- 视角与主题/悬念的关联分析

## 核心方法论

### 视角类型对比

**第一人称（"我"）**
- 优点：代入感极强，读者直接进入角色内心；叙事声音可以非常有个性；适合不可靠叙事者
- 缺点：只能写叙事者知道/经历的事；其他角色的内心只能通过行为推测；叙事者不在场的事件无法直接写
- 适合：悬疑、个人成长、心理故事、回忆性叙事
- 注意："我"的性格和声音要鲜明，不能像第三人称一样客观

**第二人称（"你"）**
- 优点：独特的代入感，让读者直接成为主角；有实验性和前卫感
- 缺点：容易让人出戏；难以维持长篇；读者可能抗拒被强加身份
- 适合：短篇、实验性作品、互动叙事、特定氛围的故事
- 注意：要有明确的理由使用第二人称，不能只是炫技

**第三人称有限（"他/她"，但只跟一个角色的内心）**
- 优点：比第一人称灵活，可以描写外部环境；比全知更有代入感和悬念；是当代小说最常用的视角
- 缺点：仍然受限于视角人物的认知；切换视角时需要处理好
- 适合：几乎所有类型，尤其是长篇、类型小说
- 注意：要明确当前跟的是谁，不要在同一场景里跳视角

**第三人称全知（"他/她"，可以进入所有角色内心）**
- 优点：最灵活，可以展示所有角色的想法和所有事件；适合宏大叙事和群像
- 缺点：代入感较弱；容易变成"上帝视角"的说教；悬念较少（因为读者知道所有人的想法）
- 适合：史诗、群像、社会全景、19世纪风格的小说
- 注意：即使全知，也要有视角焦点，不要在段落间随意跳

**多视角（多个第三人称有限/第一人称交替）**
- 优点：可以展示不同角色的视角和信息差；适合群像和复杂故事；可以制造悬念（A知道的B不知道）
- 缺点：处理不好会混乱；读者可能不喜欢某些视角人物；切换时需要清晰的标识
- 适合：群像、多线叙事、悬疑（信息差）、史诗
- 注意：每个视角人物都要有存在的理由，不要为了多视角而多视角

### 视角选择指南

**选择视角时问自己**：
1. 这个故事的核心情感体验是什么？（需要强代入→第一/有限；需要全景→全知/多视角）
2. 悬念的来源是什么？（来自信息差→有限/多视角；来自命运感→全知）
3. 主角的内心活动重要吗？（重要→第一/有限；不重要→全知/多视角）
4. 故事的规模多大？（个人故事→第一/有限；宏大群像→全知/多视角）
5. 叙事者的"声音"是故事的重要部分吗？（是→第一人称）

**常见搭配**：
- 悬疑/推理：第一人称或第三人称有限（跟侦探），制造信息差
- 言情：第三人称有限（交替跟男女主），展示双方的内心
- 史诗/奇幻：多视角或全知，展示宏大世界
- 心理/成长：第一人称，深入内心
- 恐怖：第一人称或有限，增强代入感和未知感

### 叙事声音设计

**叙事声音的要素**：
1. **语气**：严肃/幽默/讽刺/温柔/冷酷/焦虑/平静...
2. **态度**：叙事者对故事中人物/事件的看法（同情/批判/中立/调侃...）
3. **用词**：正式/口语/文学化/简洁/繁复/方言/行业术语...
4. **句式**：长句/短句/碎片化/流畅/跳跃...
5. **节奏**：叙述的快慢、信息密度、情绪强度
6. **距离**：叙事者和故事的距离（紧贴角色内心/拉开距离评论）

**叙事声音和人物的关系**：
- 第一人称：叙事声音=人物的声音，必须符合人物的性格、教育、背景
- 第三人称有限：叙事声音可以贴近人物（自由间接引语），也可以保持一定距离
- 全知：叙事声音可以是独立的"作者声音"，有自己的风格和态度

**叙事声音一致性检查**：
- [ ] 叙事声音是否符合叙事者的身份和性格？
- [ ] 语气和用词是否前后一致？（除非有明确的变化理由）
- [ ] 多视角时，每个视角人物的声音是否有区别？
- [ ] 叙事声音是否服务于故事的氛围和主题？

### 不可靠叙事者

**什么是不可靠叙事者**：叙事者说的话和事实有差距，读者需要自己辨别真相。

**不可靠的类型**：
1. **无知型**：叙事者自己不知道真相（如儿童视角、失忆者）
2. **偏见型**：叙事者有强烈的偏见，扭曲了事实（如自恋者、偏执狂）
3. **说谎型**：叙事者故意撒谎，隐瞒真相（如罪犯、有秘密的人）
4. **心理型**：叙事者心理不稳定，感知扭曲（如精神疾病、创伤后应激）
5. **天真型**：叙事者天真幼稚，误解了自己看到的事（如孩子、单纯的人）

**不可靠叙事者的设计**：
1. **明确不可靠的原因**：叙事者为什么不可靠？（有说服力的心理/经历原因）
2. **埋下线索**：在前文埋下矛盾和疑点，让读者逐渐察觉
3. **揭示时机**：什么时候让读者确定叙事者不可靠？（通常在中后段）
4. **真相的层次**：第一层不可靠被揭开后，可能还有更深的真相
5. **主题关联**：不可靠叙事应该和主题有关（如"我们如何欺骗自己"）

**读者察觉路径设计**：
- 早期：小的矛盾和不合理（读者可能忽略）
- 中期：越来越多的疑点，读者开始怀疑
- 后期：关键事件揭示叙事者的不可靠
- 高潮：完全揭开真相，重新解读之前的所有事件
- 结局：读者带着新的理解重新审视整个故事

### 多视角切换

**视角人物选择**：
- 每个视角人物都应该有独特的信息和视角，能展示其他视角看不到的东西
- 视角人物的数量要控制（长篇通常3-5个，太多会分散）
- 每个视角人物都应该有自己的故事线和弧线
- 不要让视角人物只是"摄像机"，他要有自己的欲望和冲突

**切换规则**：
1. **场景级切换**：最安全，一个场景只跟一个视角，场景切换时再换视角
2. **章节级切换**：每章一个视角，用章节标题或空行标识
3. **避免段落内切换**：不要在同一段落里跳视角，会让读者混乱
4. **切换时有明确标识**：让读者立刻知道现在在跟谁（通过人物名字、地点、独特的声音）

**信息差设计**：
- 多视角的最大优势是信息差：A知道的事B不知道，读者知道的事角色不知道
- 利用信息差制造悬念、戏剧性反讽、误解
- 设计视角切换的时机：在关键信息即将揭示时切换到另一个视角，增加期待
- 确保读者最终能拼出完整的真相

**多视角检查清单**：
- [ ] 每个视角人物都有存在的理由吗？（删掉他会损失什么？）
- [ ] 每个视角人物的声音有区别吗？
- [ ] 视角切换是否清晰？读者知道当前在跟谁吗？
- [ ] 有没有在同一场景/段落内跳视角？
- [ ] 信息差是否被有效利用？
- [ ] 视角人物的戏份是否平衡？（重要角色有足够的视角时间）

### 视角越界检测

**什么是视角越界**：在有限视角（第一人称或第三人称有限）中，写了视角人物不可能知道的事。

**常见越界**：
- 写了其他角色的内心想法（"他心里想..."，但视角人物不可能知道）
- 写了视角人物不在场的事件
- 写了视角人物不可能感知的细节（如他背后的表情）
- 全知式的评论和总结（"这是他一生中最错误的决定"，但当时他不可能知道）

**检测方法**：
- 逐段检查：这段的信息，视角人物能知道吗？
- 替换测试：把"他想"改成"他看起来想"，是否更合理？
- 信息来源：每个信息都应该有明确的来源（看到/听到/推测/被告知）

**修正方法**：
- 把直接写内心改成通过行为/表情/语言推测
- 把视角人物不在场的事件改成通过他人转述/证据/后果展示
- 把全知评论改成视角人物的主观感受（"我有种感觉，这会是个错误"）
- 如果确实需要写其他视角，考虑切换视角或使用多视角

## 调用示例
**用户**：我在写一个悬疑长篇，有侦探和凶手两条线，用什么视角好？
**技能输出**：
推荐方案：多视角（第三人称有限），交替跟侦探和凶手，但比例不同（侦探70%，凶手30%）。
理由：
1. 侦探视角：代入解谜过程，制造悬念（读者和侦探一起推理）
2. 凶手视角：展示凶手的内心和行动，制造戏剧性反讽（读者知道凶手是谁，但侦探不知道）
3. 信息差：凶手视角揭示的信息让读者比侦探知道得多，增加紧张感
4. 两条视角在高潮处汇聚：侦探和凶手的最终对决

视角切换规则：
- 章节级切换，每章标题或开头明确视角人物
- 侦探章节：聚焦调查和推理，节奏偏慢但信息密集
- 凶手章节：聚焦行动和心理，节奏偏快，有压迫感
- 关键节点切换：在侦探即将发现关键线索时切到凶手视角，增加期待

叙事声音设计：
- 侦探：冷静、理性、观察细致，用词精准，句式偏长
- 凶手：表面平静但内心焦虑，有碎片化的思维，偶尔出现暴力冲动的语言
- 两种声音有明显区别，读者不用看标题也能分辨

不可靠元素：
- 凶手视角可以有一定的不可靠（他对自己的行为有合理化和自我欺骗）
- 读者逐渐发现凶手说的和事实有差距
- 这增加了心理深度和主题（人如何为自己的恶行辩护）

视角越界提醒：
- 侦探章节不要写凶手的内心（只能通过行为推测）
- 凶手章节不要写侦探的推理过程（只能通过他观察到的侦探行为）
...（完整方案）
