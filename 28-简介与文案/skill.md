# 28-简介与文案

> 读者决定要不要看你的故事，只需要3秒——3秒内，他会看你的标题、简介、标签。如果这3秒没有抓住他，他就走了。简介不是"故事梗概"，是"鱼饵"——你要用最少的字，让读者产生"我想看"的冲动。

---

## 一、一句话故事（Logline）

### 什么是Logline

Logline是用**一句话**（通常25-50字）说清楚你的故事核心。它不是梗概，是"钩子"——让人听完就想知道更多。

### Logline公式

**标准公式**：
> 一个【什么样的主角】，在【什么情况下】，必须【做什么事】，否则【会有什么可怕的后果】，但【有什么阻碍/意外】。

**拆解**：
1. **主角**：什么样的人？（身份+性格+困境）
2. **处境**：故事开始时的状态/触发事件
3. **目标**：主角必须做什么？
4. **赌注**：如果失败会怎样？（ stakes——越高越好）
5. **阻碍/意外**：什么在阻止他？（反派/冲突/反转）

### Logline示例

| 作品 | Logline |
|------|---------|
| 《肖申克的救赎》 | 一个被冤枉杀妻的银行家，在终身监禁的监狱里，用二十年时间挖了一条隧道，完成了不可能的越狱。 |
| 《泰坦尼克号》 | 一个即将嫁给贵族的贫穷画家，在沉船上爱上了一个富家女，他们的爱情在灾难中经受考验。 |
| 《哈利·波特》 | 一个住在楼梯下的孤儿男孩，发现自己是个巫师，进入魔法学校后，必须面对杀死他父母的黑魔王。 |
| 《流浪地球》 | 太阳即将毁灭，人类带着地球逃离太阳系，一个父亲和儿子在地球发动机危机中拯救了人类。 |
| 《白夜行》 | 一个男孩为了保护一个女孩，杀了自己的父亲；从此他们在黑暗中相互守护，却永远无法在阳光下牵手。 |

### Logline自检清单

- [ ] 一句话能说清吗？（超过50字就太长了）
- [ ] 主角是谁？他有什么特别之处？
- [ ] 他必须做什么？（目标明确）
- [ ] 如果失败会怎样？（赌注够高吗？）
- [ ] 有什么阻碍/意外？（冲突明确）
- [ ] 听完后想知道更多吗？（有钩子）
- [ ] 没有剧透结局吗？（Logline只说开头和核心冲突，不说结局）

### 常见错误及修改

| 错误 | 示例 | 修改 |
|------|------|------|
| **太笼统** | "一个男人的成长故事。" | "一个被公司裁员的中年男人，为了给女儿治病，开始用自己的会计知识帮黑帮洗钱，却越陷越深。" |
| **没有赌注** | "一个侦探调查一桩谋杀案。" | "一个侦探调查一桩谋杀案，发现凶手是自己的亲生儿子——他必须在正义和亲情之间做出选择。" |
| **没有冲突** | "一个女孩去魔法学校上学。" | "一个女孩去魔法学校上学，发现自己是预言中会毁灭魔法世界的人——她必须在被学校驱逐之前，证明自己不是怪物。" |
| **剧透结局** | "一个男人复仇，最后发现仇人是自己的父亲，他原谅了父亲。" | "一个男人花了十年时间追踪杀妻仇人，最后发现所有线索都指向一个不可能的人——他自己的父亲。" |
| **太长** | 超过100字，把整个故事都说了 | 压缩到50字以内，只保留核心：主角+处境+目标+赌注+阻碍 |

## 二、作品简介三段式

作品简介（通常200-500字）是读者在书籍详情页/小说目录页看到的内容。它比Logline长，但比故事梗概短——它的目的是"让读者点进去看第一章"。

### 三段式结构

#### 第一段：建立世界+主角+困境（钩子）

**内容**：
- 故事发生在什么世界/时代？
- 主角是谁？他的处境如何？
- 什么打破了他的正常生活？（触发事件）

**目标**：让读者代入主角，产生"他好惨/他好厉害/他好有趣"的感觉。

**示例**：
> 林晚三十岁那年，失去了一切。
>
> 丈夫出轨，离婚时她净身出户；公司裁员，她是第一批被裁的；父亲突发脑溢血，躺在医院里，每天的医药费像一座山。
>
> 她带着五岁的女儿，搬进了城中村一个十平米的出租屋。
>
> 所有人都觉得她完了。

#### 第二段：核心冲突+目标+阻碍（张力）

**内容**：
- 主角决定做什么？（目标）
- 什么在阻止他？（阻碍/反派/冲突）
- 他面临什么选择/困境？（两难）

**目标**：让读者产生"他能成功吗？""接下来会怎样？"的好奇。

**示例**：
> 但林晚不这么觉得。
>
> 她用仅剩的三千块钱，在夜市摆了个小摊，卖自己做的卤味。
>
> 从被城管追得到处跑，到有了第一个固定摊位；从一天卖不出五十块，到有人专门开车来买她的卤味——她用了一年时间。
>
> 但就在她的小店即将开张的时候，前夫找到了她，说要夺回女儿的抚养权。
>
> "你一个摆地摊的，能给女儿什么？"他说。
>
> 林晚看着他，笑了："至少，我能给她一个不认输的妈妈。"

#### 第三段：升华+悬念+钩子（让人点进去）

**内容**：
- 故事的主题/情感核心是什么？
- 留下一个悬念/问题/钩子
- 不要剧透结局

**目标**：让读者产生"我要看这个故事"的冲动，立刻点进去。

**示例**：
> 这是一个女人的故事。
>
> 她没有金手指，没有霸道总裁，没有天降好运。
>
> 她只有一双手，和一个不肯认输的灵魂。
>
> 她会成功吗？
>
> 我不知道。
>
> 但我知道，从她决定不认输的那一刻起，她就已经赢了。

### 简介写作的核心原则

1. **聚焦主角，不要群像**：简介里只说主角的故事，不要说太多配角
2. **有情感，不要干巴巴**：简介要让读者有情绪波动——同情、好奇、愤怒、期待
3. **有冲突，不要平铺直叙**：简介里要有明确的冲突和阻碍
4. **有悬念，不要剧透**：不要把结局说出来，留下问题让读者想知道答案
5. **语言简洁，不要啰嗦**：200-500字，每一句话都要有价值
6. **符合类型，不要跑偏**：言情简介要有情感张力，悬疑简介要有悬念，玄幻简介要有世界观和升级感

### 不同类型的简介侧重点

| 类型 | 侧重点 | 关键元素 |
|------|--------|---------|
| **言情** | 男女主关系+情感张力 | 相遇方式、核心矛盾、情感拉扯、虐点/甜点 |
| **悬疑/推理** | 案件+悬念 | 案件是什么、诡异之处、主角的困境、真相的诱惑 |
| **玄幻/升级流** | 世界观+升级感+爽点 | 主角的初始困境、金手指、升级路径、打脸预期 |
| **都市/现实** | 主角困境+逆袭 | 主角的惨状、触发事件、逆袭路径、情感共鸣 |
| **历史/穿越** | 时代背景+主角优势 | 时代背景、主角的现代知识/信息差、改变历史的预期 |
| **科幻** | 核心设定+危机 | 科幻设定是什么、带来了什么危机、主角怎么应对 |
| **恐怖/灵异** | 诡异事件+恐惧感 | 诡异事件是什么、主角的困境、恐怖氛围 |

## 三、推荐语/卖点文案

推荐语是放在书籍封面、宣传页、社交媒体上的简短文案（通常1-3句话），目的是"一句话让人想买/想看"。

### 推荐语的五种类型

#### 类型一：情感共鸣型

**方法**：击中读者的情感痛点，让他觉得"这说的就是我"。

**示例**：
- "三十岁，失去一切，她决定从头再来。"
- "我们都曾在深夜里崩溃，然后在第二天早上假装没事。"
- "这世上最遥远的距离，不是生与死，是我站在你面前，你却不知道我爱你。"

#### 类型二：悬念钩子型

**方法**：提出一个让人好奇的问题/设定，让读者想知道答案。

**示例**：
- "如果有一天，你发现自己的人生是别人写好的小说，你会怎么办？"
- "她死了三次，每次都在同一个男人怀里醒来。"
- "全城的人都在找一个不存在的人——除了我，因为我就是那个人。"

#### 类型三：反差冲突型

**方法**：把两个看似矛盾的元素放在一起，制造冲突感和好奇心。

**示例**：
- "她是个法医，他是个连环杀手——她爱上了自己正在追捕的人。"
- "他是个瞎子，却是全城最好的侦探。"
- "她白天是温柔的幼儿园老师，晚上是地下拳场的不败女王。"

#### 类型四：金句哲理型

**方法**：用一句有深度、有哲理的话，概括故事的主题，让人回味。

**示例**：
- "我们终其一生，都在和自己的平凡和解。"
- "这世上没有真正的感同身受，只有冷暖自知。"
- "你以为的岁月静好，不过是有人在替你负重前行。"

#### 类型五：身份标签型

**方法**：用主角的身份/标签，快速吸引目标读者。

**示例**：
- "一个单亲妈妈的创业史。"
- "一个自闭症少年的数学天才之路。"
- "一个退休老警察的最后一案。"

### 推荐语自检清单

- [ ] 一句话能说清吗？（超过3句话就太长了）
- [ ] 有情感冲击力吗？（读完心里动了一下吗？）
- [ ] 有悬念/好奇心吗？（想知道更多吗？）
- [ ] 符合故事的类型和主题吗？
- [ ] 没有剧透吗？
- [ ] 语言简洁有力吗？（没有废话）

## 四、章节标题设计

章节标题是读者在目录页看到的内容——好的章节标题能让读者想立刻点进去看，差的章节标题让人毫无感觉。

### 章节标题的五种类型

#### 类型一：悬念型

**方法**：标题本身就是一个悬念/问题，让人想知道答案。

**示例**：
- "第三章 她死了"
- "第五章 不该出现的人"
- "第七章 我是谁？"
- "第十章 真相只有一个"

#### 类型二：场景/事件型

**方法**：标题点明这一章的核心场景/事件，简洁明了。

**示例**：
- "第三章 雨夜"
- "第五章 婚礼"
- "第七章 审讯室"
- "第十章 决战"

#### 类型三：金句型

**方法**：用这一章中最有冲击力的一句话作为标题，有文学性和情感冲击力。

**示例**：
- "第三章 我们回不去了"
- "第五章 原来你从来没有爱过我"
- "第七章 这一次，我不会再放手"
- "第十章 愿你被这个世界温柔以待"

#### 类型四：反差型

**方法**：标题和内容形成反差，或者标题本身有反差，制造意外感。

**示例**：
- "第三章 生日快乐"（内容是主角生日当天被甩了）
- "第五章 团圆饭"（内容是一家人在饭桌上撕破脸）
- "第七章 晴天"（内容是主角的世界崩塌了）
- "第十章 再见"（内容是主角再也见不到那个人了）

#### 类型五：数字/时间型

**方法**：用数字/时间作为标题，有节奏感和紧迫感。

**示例**：
- "第三章 第三天"
- "第五章 七秒钟"
- "第七章 一百零八个台阶"
- "第十章 最后三分钟"

### 章节标题设计原则

1. **简洁**：通常2-10个字，不要太长
2. **有吸引力**：让人想点进去看，不要干巴巴的"第三章 事情的发展"
3. **不剧透**：不要把这一章的关键情节/结局说出来
4. **有风格**：和故事的整体风格一致——悬疑故事用悬念型，言情用金句型，玄幻用场景/事件型
5. **有节奏**：相邻章节的标题不要都是同一种类型，交替使用，有节奏感

### 常见错误

| 错误 | 示例 | 修改 |
|------|------|------|
| **太干巴** | "第三章 主角去了公司" | "第三章 第一天上班" |
| **剧透** | "第三章 主角发现妻子出轨了" | "第三章 不该看到的消息" |
| **太长** | "第三章 主角在一个下雨的晚上回到家发现妻子不在家然后他接到了一个陌生电话" | "第三章 雨夜来电" |
| **没有吸引力** | "第三章 过渡" | "第三章 山雨欲来" |

## 五、标签选择策略

标签是读者发现你的故事的重要途径——在小说平台/书籍分类中，标签决定了你的故事会被推荐给什么样的读者。选对标签，事半功倍；选错标签，无人问津。

### 标签的三个层次

#### 第一层：类型标签（必选）

**说明**：故事的核心类型，决定了大的分类。

**常见类型标签**：
- 女频：现言、古言、幻言、快穿、重生、年代、无限流、悬疑推理、现实
- 男频：玄幻、奇幻、都市、科幻、历史、游戏、体育、悬疑、军事
- 通用：短篇、长篇、完结、连载

**选择原则**：
- 选1-2个最核心的类型，不要选太多
- 选读者量最大的那个类型（如果故事有多个类型元素）
- 不要为了蹭流量选不符合的类型（会被读者骂"挂羊头卖狗肉"）

#### 第二层：元素标签（必选）

**说明**：故事中的核心元素/设定，吸引喜欢这些元素的读者。

**常见元素标签**：
- 言情类：甜宠、虐恋、强强、豪门、校园、职场、娱乐圈、穿越、重生、系统、快穿、女配、逆袭、追妻火葬场、先婚后爱、破镜重圆
- 玄幻类：升级流、系统流、无敌流、种田流、签到流、废柴逆袭、宗门、修仙、异界、穿越
- 悬疑类：推理、刑侦、灵异、恐怖、犯罪、心理、反转、密室
- 现实类：创业、职场、家庭、婚姻、成长、治愈、励志

**选择原则**：
- 选3-5个最核心的元素，不要选太多（选太多等于没有重点）
- 选故事中真正有的元素，不要为了蹭流量选没有的元素
- 优先选搜索量大、读者喜欢的元素标签

#### 第三层：情感/风格标签（可选）

**说明**：故事的情感基调/风格，吸引有特定偏好的读者。

**常见情感/风格标签**：
- 情感：治愈、致郁、爆笑、轻松、沉重、温暖、心酸、爽
- 风格：正剧、轻松、搞笑、文艺、暗黑、烧脑、慢热、快节奏
- 读者群体：女性向、男性向、无CP、双男主、双女主

**选择原则**：
- 选1-2个最符合的，可选
- 情感标签要诚实——如果是虐文就不要标"甜宠"，否则读者会骂

### 标签选择的黄金法则

1. **精准**：标签要准确反映故事内容，不要误导读者
2. **聚焦**：不要选太多标签，3-8个最合适，选最核心的
3. **蹭热点但不硬蹭**：可以选热门标签，但必须是故事中真正有的元素
4. **测试**：发布后观察数据，如果某个标签带来的读者不喜欢，可以调整
5. **看竞品**：看看同类型、同水平的作品用了什么标签，参考但不照搬

### 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| **标签太多** | 没有重点，推荐算法不知道推给谁，读者也不知道这是什么 | 选3-8个最核心的标签 |
| **标签不准** | 点进来的读者不是目标读者，差评多，推荐量下降 | 诚实标注，是什么就是什么 |
| **蹭无关标签** | 读者觉得被骗，差评，甚至被平台处罚 | 只选故事中真正有的元素 |
| **不选标签** | 没有推荐，无人问津 | 至少选类型标签和核心元素标签 |
| **标签太冷门** | 搜索量小，没有流量 | 优先选热门标签，冷门标签作为补充 |

## 六、国内/海外简介差异

### 国内平台简介特点

- **节奏快**：前三句就要抓住读者，否则读者就划走了
- **情绪强**：强调情感冲击——虐、爽、甜、燃，让读者有情绪波动
- **冲突明确**：主角的困境和目标要清晰，冲突要激烈
- **金句多**：喜欢用有冲击力的金句，容易传播
- **标签化**：简介中可以直接点明热门标签（"甜宠""重生""逆袭"），吸引目标读者
- **长度适中**：通常200-500字，手机一屏能看完

### 海外平台简介特点

- **更注重世界观和设定**：科幻/奇幻类作品，简介会花更多篇幅介绍世界观
- **更注重人物**：简介会更深入地介绍主角的性格和内心，而不只是情节
- **节奏稍慢**：可以有更多铺垫，不需要前三句就爆冲突
- **文学性更强**：语言更优美、更有文学性，不只是"爽"
- **引用推荐**：常引用媒体/名人的推荐语，增加可信度
- **长度稍长**：通常300-800字，可以有更多细节

### 跨文化简介写作建议

1. **核心冲突要普适**：爱情、复仇、成长、生存——这些是全人类共通的，跨文化都能理解
2. **文化特定元素要解释**：如果故事中有中国特色的元素（修仙、武侠、宫斗），海外简介中需要简单解释
3. **调整节奏**：国内版节奏快、情绪强；海外版可以稍慢、更注重人物和世界观
4. **语言风格调整**：国内版可以用网络用语、金句；海外版要更正式、更文学性
5. **标签系统不同**：国内平台的标签和海外平台（Amazon/Goodreads/Wattpad）的分类不同，要按目标平台的分类调整

### 示例：同一个故事的国内版和海外版简介

**故事**：一个现代女医生穿越到古代，成为了一个被废的皇后，用现代医学知识在古代生存，并和皇帝从敌对到相爱。

**国内版简介**：
> 苏晚醒过来的时候，发现自己穿越了。
>
> 成了大周朝的废后，被打入冷宫，还被灌了毒酒。
>
> 所有人都以为她死定了。
>
> 但他们不知道，苏晚是二十一世纪的外科医生——做手术她可能不行，救人她可是专业的。
>
> 从冷宫出来，她靠一手医术，治好了太后的顽疾，打了贵妃的脸，让皇帝对她刮目相看。
>
> 皇帝："你到底是谁？"
>
> 苏晚笑了："我是你废了的皇后啊，陛下。"
>
> 这是一个女医生在古代的逆袭故事——没有金手指，只有一双手和一个不肯认输的灵魂。

**海外版简介**：
> Dr. Su Wan had it all: a successful career as a surgeon, a loving family, and a bright future.
>
> Until the day she woke up in another world.
>
> She is now Su Wan, the deposed empress of the Great Zhou Dynasty — poisoned, abandoned, and left to die in the Cold Palace.
>
> But Su Wan is not the weak woman they think she is. She is a surgeon from the 21st century, and she knows how to save lives.
>
> Using her medical knowledge, she cures the Empress Dowager's mysterious illness, outwits the scheming concubines, and catches the attention of the Emperor himself — a man who once ordered her death.
>
> As Su Wan navigates the dangerous court politics, she finds herself drawn to the Emperor, a man as complex as the empire he rules. But in a world where one wrong move means death, can she trust the man who holds her life in his hands?
>
> *The Empress Who Refused to Die* is a story of survival, love, and the power of knowledge — set in a world where modern medicine meets ancient intrigue.

（国内版节奏快、情绪强、有爽感和金句；海外版更注重人物和世界观，语言更文学性，结尾有主题升华。）

## 七、模板

### 模板一：Logline模板

```
一个【主角身份+性格特征】，在【触发事件/处境】后，必须【目标】，否则【可怕后果】，但【阻碍/反派/意外】。
```

**填空示例**：
> 一个【被裁员的中年会计】，在【女儿查出白血病】后，必须【在三个月内凑够五十万手术费】，否则【女儿会死】，但【他唯一能快速赚钱的方法，是帮一个黑帮做假账，而那会让他失去一切】。

### 模板二：作品简介三段式模板

```
【第一段：钩子】
（主角是谁？他的处境如何？什么打破了他的正常生活？）

【第二段：张力】
（主角决定做什么？什么在阻止他？他面临什么困境/选择？）

【第三段：升华+钩子】
（故事的主题/情感核心是什么？留下一个悬念/问题，让人想点进去。）
```

### 模板三：推荐语模板

```
【情感共鸣型】：我们都曾【情感痛点】，直到【故事中的转折】。
【悬念钩子型】：如果有一天，【不可能的设定】，你会【选择/行动】？
【反差冲突型】：她是【身份A】，他是【身份B】——【他们之间的冲突/关系】。
【金句哲理型】：【一句有哲理的话，概括故事主题】。
```

### 模板四：标签选择模板

```
类型标签：【1-2个核心类型】
元素标签：【3-5个核心元素】
情感/风格标签：【1-2个，可选】

示例：
类型标签：现言、重生
元素标签：甜宠、豪门、逆袭、追妻火葬场
情感/风格标签：轻松、爽
```

## 九、简介与文案质量自检清单

完成简介/文案后，用以下清单自检：

### Logline
- [ ] 一句话能说清吗？（25-50字）
- [ ] 主角是谁？他有什么特别之处？
- [ ] 他必须做什么？（目标明确）
- [ ] 如果失败会怎样？（赌注够高吗？）
- [ ] 有什么阻碍/意外？（冲突明确）
- [ ] 听完后想知道更多吗？
- [ ] 没有剧透结局吗？

### 作品简介
- [ ] 三段式结构清晰吗？（钩子→张力→升华）
- [ ] 前三句能抓住读者吗？
- [ ] 主角的困境和目标明确吗？
- [ ] 有明确的冲突和阻碍吗？
- [ ] 有情感冲击力吗？（读者心里动了一下吗？）
- [ ] 留下了悬念/钩子吗？（想点进去看吗？）
- [ ] 没有剧透结局吗？
- [ ] 长度合适吗？（200-500字，手机一屏能看完）
- [ ] 符合类型风格吗？

### 推荐语
- [ ] 1-3句话，简洁有力吗？
- [ ] 有情感冲击力或悬念吗？
- [ ] 符合故事主题吗？
- [ ] 没有剧透吗？

### 章节标题
- [ ] 简洁吗？（2-10个字）
- [ ] 有吸引力吗？（想点进去看吗？）
- [ ] 不剧透吗？
- [ ] 和故事风格一致吗？
- [ ] 相邻章节标题有变化吗？（不是同一种类型重复）

### 标签
- [ ] 类型标签准确吗？（1-2个）
- [ ] 元素标签准确吗？（3-5个，都是故事中真正有的）
- [ ] 情感/风格标签准确吗？
- [ ] 标签总数合适吗？（3-8个，不要太多）
- [ ] 没有为了蹭流量选无关标签吗？

### 整体
- [ ] 读完简介后，想立刻看第一章吗？
- [ ] 简介准确反映了故事内容吗？（没有误导读者）
- [ ] 语言简洁有力吗？（没有废话）
- [ ] 目标读者会喜欢吗？

**任何一项不通过，回到对应部分修改，修改后重新自检。**

---

> **简介与文案的终极目标**：让读者在3秒内决定"我要看这个故事"。你不需要在简介里把整个故事都说完——你只需要说够，让读者想知道更多。好的简介像一扇半开的门——读者看到了里面的光，就会忍不住推开门走进去。
