# 17-剧本专项 · 技能

> 电影/剧集剧本的专门方法：标准格式、场景写作、视觉叙事、分镜、台词、行业规范。

## 何时调用
- 用户需要写电影剧本/电视剧本
- 用户需要把故事改成剧本格式
- 用户需要剧本写作的技巧和规范
- 用户说"写剧本/剧本格式/分镜怎么写"

## 输入要求
- 故事大纲/核心概念
- 目标格式（电影/剧集/短剧）
- 可选：已有的故事/小说文本

## 输出格式
- 剧本格式规范说明
- 场景大纲（场景列表，每场的目标/冲突/结果）
- 标准格式的剧本场景示例
- 视觉叙事建议（怎么用画面讲故事）
- 台词写作建议
- 剧本Checklist

## 核心方法论

### 标准剧本格式

**场景标题（Slugline）**：
```
INT. 咖啡馆 - 日
```
- INT./EXT.：室内/室外
- 地点：具体的地点名称
- 时间：日/夜/晨/昏（具体时间按需）
- 全大写，左对齐

**动作描写（Action）**：
- 描写画面中能看到的一切（人物动作、环境、表情）
- 现在时，简洁有力
- 只写能被拍出来的（不要写角色的内心想法，除非用画外音）
- 第一次出现的人物名全大写，之后正常
- 重要的道具/声音可以全大写

**人物名（Character）**：
- 说话人的名字，居中，全大写
- 可以加括号说明状态（V.O.画外音/O.S.画外/续）

**台词（Dialogue）**：
- 人物名下方，居中偏左
- 简洁，口语化，有潜台词
- 不要大段独白（除非有特殊理由）

**括号说明（Parenthetical）**：
- 人物名和台词之间，用括号说明说话方式/动作
- 简洁，不要滥用（大部分时候不需要）

**格式示例**：
```
INT. 咖啡馆 - 日

雨声敲打着窗户。林深坐在角落的位置，面前的咖啡已经凉了。她不停地看手表。

门铃响了。一个男人走进来，环顾四周。

林深
（站起来）
你来了。

男人
（走过来，坐下）
说吧，什么事这么急？

林深
我怀孕了。

男人愣住了。窗外的雷声滚过。

男人
（低声）
...你确定是我的？
```

### 剧本和小说的区别

| 维度 | 小说 | 剧本 |
|---|---|---|
| 叙事方式 | 文字叙述，可以进入内心 | 只能用画面和声音 |
| 信息传递 | 可以直接说明/解释 | 必须通过行动和对话展示 |
| 内心活动 | 可以直接写 | 只能通过表情/动作/画外音 |
| 时间/空间 | 自由切换 | 受场景限制，每场是连续的时空 |
| 节奏 | 由文字控制 | 由场景长度和剪辑控制 |
| 读者/观众 | 读者自己想象画面 | 观众直接看到画面 |

**核心原则**：剧本是"用画面讲故事"，不是"用文字讲故事"。

### 视觉叙事

**什么是视觉叙事**：不依赖对话和旁白，通过画面、动作、构图、色彩、剪辑来传递信息和情感

**视觉叙事技巧**：

1. **用动作展示人物**
   - ❌ 台词说"我很紧张"
   - ✅ 画面：角色不停地搓手，目光闪躲，说话时咽口水

2. **用环境展示状态**
   - ❌ 台词说"我很穷"
   - ✅ 画面：狭小的公寓，墙皮剥落，桌上只有泡面，角色在数硬币

3. **用道具传递信息**
   - 一个反复出现的道具可以承载情感和主题（婚戒、照片、手表、信）
   - 道具的状态变化反映人物/关系的变化（婚戒从戴着→摘下→重新戴上）

4. **用构图表达关系**
   - 两个人在画面中的位置/距离反映他们的关系
   - 权力大的人在画面上方/中心，权力小的人在下方/边缘
   - 关系亲密的人在同一画面，关系疏远的人被门框/柱子隔开

5. **用色彩传递情感**
   - 暖色调（红/橙/黄）：温暖、激情、危险
   - 冷色调（蓝/绿/灰）：冷静、孤独、压抑
   - 色彩的变化反映情感/故事的变化

6. **用声音制造氛围**
   - 环境音（雨声、车流、钟声）
   - 沉默（在紧张时刻突然安静）
   - 音乐的情绪（但剧本中一般不写具体音乐，只写氛围）

7. **用对比制造张力**
   - 画面内的对比（富人和穷人、热闹和孤独）
   - 场景间的对比（上一场热闹聚会，下一场冷清葬礼）

### 场景写作

**剧本场景的结构**（和小说场景类似，但更强调视觉）：
1. **场景目标**：这个场景中角色想要什么？
2. **场景冲突**：什么阻止了他？
3. **场景转折**：场景结束时情况有什么变化？
4. **视觉元素**：这个场景用什么画面/动作/道具来传递信息？

**剧本场景的原则**：
- **每场只有一个核心冲突**（不要一场戏里塞太多东西）
- **每场都必须推进故事**（情节/人物/关系至少推进一个）
- **进场晚，退场早**（从冲突的中间开始，在转折后立刻结束，不要写进出场景的过渡）
- **用动作代替对话**（能做的就不要说）
- **每场的结尾有钩子或转折**（让观众想看下一场）

**场景长度**：
- 电影剧本：通常1-3页（1页≈1分钟），关键场景可以更长
- 电视剧本：每集20-40场，平均每场1-2页
- 短剧：每场更短，30秒-2分钟，冲突更密集

### 台词写作

**剧本台词的原则**（和小说对话类似，但更精简）：
1. **口语化**：像真人说的话，不是书面语
2. **有潜台词**：角色说的和想的不一样
3. **有辨识度**：每个角色说话方式不同
4. **推进情节**：台词不只是聊天，要推进故事或展示人物
5. **简洁**：能一句话说清的不要说三句
6. **避免说明式台词**：不要让角色说他们已经知道的事

**剧本台词和小说对话的区别**：
- 剧本台词更精简（因为有画面配合，不需要说那么多）
- 剧本台词更依赖潜台词（因为不能写内心，只能靠台词和表情）
- 剧本台词要考虑演员的表演（留出表演空间，不要把所有情绪都写在台词里）

**括号说明的使用**：
- 只在必要时使用（说话方式/重要动作）
- 不要每句台词都加括号（那会限制演员的表演）
- 简洁：（笑）（停顿）（低声），不要写一大段

### 分镜/镜头设计

**什么是分镜**：把剧本场景拆成具体的镜头，每个镜头拍什么、怎么拍

**分镜的基本元素**：
- **景别**：远景/全景/中景/近景/特写
- **角度**：平视/仰视/俯视/倾斜
- **运动**：固定/推/拉/摇/移/跟/升降
- **构图**：画面中人物/物体的位置和关系
- **时长**：每个镜头持续多久

**常见镜头语言**：
- **特写**：强调情绪/细节（眼睛、手、道具）
- **近景**：展示人物表情和上半身动作
- **中景**：展示人物动作和互动（最常用）
- **全景**：展示环境和人物在环境中的位置
- **远景**：展示宏大场景/人物的渺小
- **过肩镜头**：两个人对话时常用，展示关系
- **正反打**：对话时交替拍两个人
- **手持镜头**：紧张/真实/混乱感
- **慢镜头**：强调/抒情/关键瞬间

**分镜设计原则**：
- 为情绪和故事服务，不是为了炫技
- 对话场景：正反打+过肩，在情绪变化时切特写
- 动作场景：多机位、快剪辑、手持，增加紧张感
- 情感场景：长镜头、慢运动、特写，让观众感受
- 注意轴线规则（对话时不要越轴，除非有特殊理由）

### 剧本Checklist

**格式**：
- [ ] 场景标题格式正确（INT./EXT. 地点 - 时间）
- [ ] 人物名居中全大写，台词格式正确
- [ ] 动作描写是现在时，只写能拍出来的
- [ ] 第一次出现的人物名全大写
- [ ] 没有写角色的内心想法（除非用V.O.）

**内容**：
- [ ] 每场都有明确的目标和冲突
- [ ] 每场都推进了情节/人物/关系
- [ ] 进场晚，退场早（没有多余的过渡）
- [ ] 用动作和画面展示，不是用对话说明
- [ ] 台词有潜台词，不是直白地说
- [ ] 每个角色的说话方式有辨识度
- [ ] 视觉元素丰富（环境、道具、构图、色彩）
- [ ] 场景结尾有转折或钩子

**节奏**：
- [ ] 场景长度合适（大部分1-3页）
- [ ] 紧张场景和舒缓场景交替
- [ ] 没有连续多个对话场景（需要插入动作场景）
- [ ] 整体节奏符合三幕结构

**行业规范**：
- [ ] 页数符合要求（电影90-120页，每集约45-60页）
- [ ] 没有导演提示（剧本不写具体镜头，那是导演的工作）
- [ ] 没有音乐提示（除非是剧情需要的具体歌曲）
- [ ] 人物数量可控（不要太多次要人物）
- [ ] 场景数量可控（不要太多不同地点，增加拍摄成本）

## 调用示例
**用户**：帮我把这段小说改成剧本格式——"林深坐在咖啡馆里，心里很紧张。她在等陈默，要告诉他自己怀孕了。陈默来了，他看起来很疲惫。林深深吸一口气，说'我怀孕了'。陈默愣住了。"
**技能输出**：
剧本格式改写：

```
INT. 咖啡馆 - 日

雨声敲打着窗户。咖啡馆里人不多，轻音乐在空气中飘着。

林深坐在角落的位置，手指无意识地摩挲着咖啡杯的杯沿。杯里的咖啡已经凉了，她一口没喝。

她看了一眼手表。又看了一眼门口。

门铃响了。

陈默走进来，头发有些乱，眼下有淡淡的青黑。他环顾一圈，看到林深，走过来。

陈默
（坐下，把外套搭在椅背上）
等很久了？

林深
（声音有点紧）
没有。

陈默拿起菜单，但林深没有动。

林深
陈默。

陈默抬头。

林深
（停顿）
我怀孕了。

陈默的手停在菜单上。

很长的沉默。窗外的雷声滚过。

陈默
（低声，几乎是自言自语）
...什么时候的事？
```

改写要点：
1. 用动作展示紧张（摩挲杯沿、看手表、声音紧），不是直接说"心里很紧张"
2. 用环境和声音营造氛围（雨声、轻音乐、雷声）
3. 进场晚：陈默进来就直接进入对话，没有写他怎么赶路
4. 退场早：在陈默问"什么时候的事"就结束，留下悬念
5. 台词有潜台词：林深说"没有"（其实等了很久），陈默问"什么时候的事"（不是"你确定是我的？"但暗示了他的怀疑）
6. 用停顿和沉默增加张力（"很长的沉默"）
7. 视觉元素：凉了的咖啡（暗示她坐了很久）、陈默的疲惫（头发乱、眼下青黑，暗示他有别的事）

进一步建议：
- 这个场景可以增加一个视觉细节：林深的手放在肚子上（但很隐蔽，陈默没注意到），在说"我怀孕了"之前
- 陈默的反应可以更具体：他的手怎么停的、表情怎么变化、眼神往哪看
- 场景结尾的钩子可以更强：陈默说完"什么时候的事"后，他的手机响了，他看了一眼屏幕，表情变了，然后按掉了电话——观众会好奇是谁打来的
...（完整的剧本改写建议）
