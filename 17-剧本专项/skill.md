# 17-剧本专项

> 剧本不是"用对话写的小说"，是"用画面讲故事的蓝图"。写剧本时，你不是在"写"，是在"导"——你写的每一个字，最终都会变成画面、声音、演员的表演。好的剧本，读者读完脑海里已经有了一部电影。

---

## 一、剧本的本质

### 剧本 vs 小说

| 维度 | 小说 | 剧本 |
|------|------|------|
| **核心媒介** | 文字 | 画面+声音 |
| **信息传递** | 可以直接写心理活动、背景介绍 | 只能通过画面、对话、动作展示 |
| **节奏控制** | 作者控制读者的阅读速度 | 导演控制观众的观看速度（约1页=1分钟） |
| **内心描写** | 可以直接写"他很伤心" | 必须通过动作、表情、对话展示"他很伤心" |
| **篇幅** | 灵活，几万到几百万字 | 电影约90-120页（1页≈1分钟），剧集每集约45-60页 |
| **读者** | 普通读者 | 导演、演员、制片人、投资人 |

### 剧本的黄金法则

1. **Show, don't tell**（展示，不要告诉）——不要写"他很生气"，写"他把杯子摔在墙上，碎片溅了一地"
2. **1页≈1分钟**——剧本的页数大致等于成片的分钟数
3. **只写能拍出来的东西**——不要写"他想起了十年前的夏天"（除非用闪回），只写观众能看到和听到的
4. **对话是动作**——每句对话都应该推动情节或展示人物，不能是废话
5. **场景是最小单位**——每个场景有明确的时间、地点、人物、冲突

## 二、标准剧本格式

### 场景标题（Slugline / Scene Heading）

**格式**：`INT./EXT. 地点 - 时间`

- **INT.** = Interior（室内）
- **EXT.** = Exterior（室外）
- **INT./EXT.** = 室内外交替（如车内）
- 地点：具体的地点名称
- 时间：DAY（白天）/ NIGHT（夜晚）/ DAWN（黎明）/ DUSK（黄昏）/ CONTINUOUS（连续）/ LATER（稍后）

**示例**：
```
INT. 小明的公寓 - 夜晚
EXT. 上海外滩 - 白天
INT. 医院走廊 - 连续
EXT. 高速公路 - 黄昏
```

### 动作描写（Action Lines）

**格式**：场景标题下方，描写画面中发生的事。

**规则**：
- 用现在时
- 只写观众能看到和听到的
- 简洁，不要冗长
- 人物第一次出现时名字全大写（如"小明"第一次出现写"小明"，之后正常写）
- 重要道具第一次出现时可以大写（如"一把旧伞"）

**示例**：
```
INT. 小明的公寓 - 夜晚

狭小的单间，墙上贴着几张旧海报。桌上堆满了外卖盒。

小明（30岁，眼神疲惫）坐在电脑前，屏幕的光照在他脸上。他揉了揉眼睛，看了一眼手机——晚上11点47分。

他叹了口气，关上电脑，起身走向卫生间。
```

### 人物名（Character Name）

**格式**：居中（或缩进），全大写。

**规则**：
- 人物说话前先写人物名
- 第一次出现的人物可以在名字后加括号注明年龄和简短描述
- 画外音用（O.S.）= Off Screen，旁白用（V.O.）= Voice Over

**示例**：
```
小明
（疲惫地）
我回来了。

小红
（画外音）
饭在桌上，自己热一下。
```

### 对话（Dialogue）

**格式**：人物名下方，正常格式。

**规则**：
- 简洁，口语化
- 每句对话要有目的（推动情节/展示人物/制造冲突）
- 不要写"小说式"的长段对话
- 括号里可以写简短的情绪/动作提示，但不要太多

**示例**：
```
小明
你今天怎么回来这么早？

小红
（不看他）
今天不忙。

小明
（察觉到不对）
你怎么了？

小红
没怎么。
```

### 括号提示（Parenthetical）

**格式**：人物名下方、对话上方，括号内。

**规则**：
- 简短，只写必要的情绪/动作提示
- 不要写长段的舞台指示
- 能用对话表达的就不要用括号

**示例**：
```
小明
（轻声）
对不起。

小红
（眼泪掉下来）
你每次都这么说。
```

### 转场（Transition）

**格式**：右对齐，全大写。

**常见转场**：
- `CUT TO:` —— 硬切（最常用，通常可以省略）
- `DISSOLVE TO:` —— 溶解（时间流逝）
- `SMASH CUT TO:` —— 猛切（强烈对比）
- `MATCH CUT TO:` —— 匹配剪辑（画面相似性转场）
- `FADE IN:` / `FADE OUT.` —— 淡入/淡出（开头/结尾）

**示例**：
```
FADE IN:

INT. 小明的公寓 - 夜晚

...

SMASH CUT TO:

INT. 警察局 - 白天

...

FADE OUT.
```

### 完整格式示例

```
FADE IN:

INT. 小明的公寓 - 夜晚

狭小的单间，墙上贴着几张旧海报。桌上堆满了外卖盒。

小明（30岁，眼神疲惫）坐在电脑前，屏幕的光照在他脸上。他揉了揉眼睛，看了一眼手机——晚上11点47分。

手机突然响了。来电显示："妈妈"。

小明犹豫了一下，接起电话。

小明
（尽量让声音听起来轻松）
妈，怎么了？

妈妈（V.O.）
（声音沙哑）
小明……你爸他……住院了。

小明的手僵住了。

小明
（声音发抖）
怎么回事？严重吗？

妈妈（V.O.）
医生说……可能要做手术。你……能回来吗？

小明闭上眼睛。窗外，城市的灯火闪烁。

小明
（轻声）
我明天就回去。

他挂了电话，坐在原地，一动不动。

CUT TO:

EXT. 火车站 - 白天

人潮涌动。小明背着一个旧背包，快步走向检票口。

他看了一眼手机——一条未读消息，来自小红："听说叔叔住院了，需要钱的话跟我说。"

小明的手指悬在屏幕上，最终没有回复。

他把手机塞进口袋，走进检票口。

FADE OUT.
```

## 三、电影剧本三幕结构 + 15节拍

### 三幕结构总览

| 幕 | 大致页数 | 占比 | 核心功能 |
|----|---------|------|---------|
| **第一幕（建置）** | 1-30页 | 25% | 建立人物、世界、日常；激励事件打破日常；第一幕转折让主角主动进入故事 |
| **第二幕（对抗）** | 30-90页 | 50% | 主角面对越来越大的挑战；中点改变性质；第二幕转折让主角陷入最低谷 |
| **第三幕（解决）** | 90-120页 | 25% | 主角集结力量，最终对决，解决冲突，展示新世界 |

### 15节拍表（Blake Snyder's Save the Cat Beat Sheet）

| 节拍 | 大致页数 | 说明 |
|------|---------|------|
| **1. 开场画面** | 第1页 | 展示主角的"之前"状态，定调，和结尾形成对比 |
| **2. 主题陈述** | 第5页 | 有人（通常不是主角）说出故事的主题，主角当时不理解 |
| **3. 建置** | 1-10页 | 建立主角的日常、缺陷、欲望，展示他的世界 |
| **4. 催化剂** | 第12页 | 激励事件，打破日常，故事真正开始 |
| **5. 辩论** | 12-25页 | 主角犹豫、害怕、拒绝冒险，思考要不要行动 |
| **6. 进入第二幕** | 第25页 | 主角做出决定，主动进入新世界（第一幕转折） |
| **7. B故事** | 第30页 | 副线开始，通常是爱情/友情，承载主题 |
| **8. 游戏与娱乐** | 30-55页 | 主角在新世界探索，体验"承诺的前提"，有爽点/趣味 |
| **9. 中点** | 第55页 | 重大转折，要么是"假胜利"要么是"假失败"，故事性质改变，赌注提高 |
| **10. 坏人逼近** | 55-75页 | 反派/困难开始反扑，主角的团队出现裂痕，情况越来越糟 |
| **11. 一切尽失** | 第75页 | 最低谷，主角失去重要的东西，有人可能死亡，暗示"死亡气息" |
| **12. 灵魂黑夜** | 75-85页 | 主角陷入绝望，反思自己的缺陷，终于理解主题 |
| **13. 进入第三幕** | 第85页 | 主角找到解决方案，带着新的领悟行动（第二幕转折） |
| **14. 结局** | 85-110页 | 最终对决，主角用学到的东西解决冲突，A故事和B故事交汇 |
| **15. 终场画面** | 最后一页 | 展示主角的"之后"状态，和开场画面对比，展示成长 |

### 节拍使用说明

1. **页数是参考，不是铁律**——可以根据故事调整，但大致比例要对
2. **每个节拍都要有功能**——不能跳过，也不能只是"凑数"
3. **节拍之间要有因果关系**——前一个节拍导致后一个节拍
4. **中点和"一切尽失"是关键**——这两个节拍是故事的脊柱，必须有力

## 四、剧集结构

### 单集结构（45-60分钟剧集）

类似电影三幕，但更紧凑，且每集结尾必须有钩子让观众想看下一集。

| 部分 | 大致页数 | 说明 |
|------|---------|------|
| **冷开场（Cold Open）** | 3-5页 | 开头直接进入冲突/悬念，不显示片头，抓住观众 |
| **第一幕** | 5-15页 | 建立本集核心冲突，引入本集故事 |
| **第二幕上** | 15-30页 | 冲突发展，出现转折 |
| **中点** | 30页左右 | 本集重大转折 |
| **第二幕下** | 30-45页 | 冲突升级，主角陷入困境 |
| **第三幕** | 45-55页 | 解决本集冲突 |
| **钩子（Tag）** | 最后2-3页 | 留下悬念，引导下一集 |

### 季结构（Season Arc）

| 部分 | 集数 | 说明 |
|------|------|------|
| **建置** | 第1-3集 | 建立世界、人物、核心冲突，第1集结尾必须有大钩子 |
| **发展** | 第4-8集 | 多线发展，人物关系变化，冲突升级 |
| **中点转折** | 第8-10集 | 重大反转，改变整个季的性质 |
| **升级** | 第10-12集 | 冲突白热化，主角陷入低谷 |
| **高潮** | 第13集（季终） | 最终对决，解决本季核心冲突，留下下一季钩子 |

### 系列结构（Series Arc）

- 每一季有独立的季弧线，同时有贯穿全系列的总弧线
- 人物在全系列中持续成长
- 每一季结尾解决当季冲突，但留下更大的悬念
- 常见模式：每一季一个大案件/大冒险/大反派

## 五、影视化思维

### 什么是"影视化思维"

写剧本时，时刻想着"观众在屏幕上看到什么、听到什么"。你写的每一句话，最终都要能变成画面和声音。

### 影视化思维的五个原则

#### 原则一：用画面展示，不用文字说明

❌ 错误（小说式）：
> 小明很伤心，他想起了去世的父亲，觉得自己的人生没有意义。

✅ 正确（影视化）：
> 小明坐在父亲的旧沙发上，手指抚过沙发扶手上的一道裂痕——那是父亲当年修椅子时留下的。
>
> 茶几上放着两个茶杯，一个是他的，一个是父亲的。父亲的那个，已经积了一层灰。
>
> 小明拿起父亲的茶杯，手指在杯口摩挲了很久，然后轻轻放下。
>
> 他没有哭。但他的肩膀在抖。

#### 原则二：用动作展示性格，不用形容词说明

❌ 错误：
> 小红是个坚强的女人。

✅ 正确：
> 小红被推倒在地，膝盖磕在台阶上，渗出血来。
>
> 她咬着牙，一声不吭，撑着地站起来，拍了拍裤子上的灰。
>
> 对面的男人愣住了。
>
> 小红
> （平静地）
> 还有什么招，都使出来。

#### 原则三：用对话推进，不用对话解释

❌ 错误（解释性对话）：
> 小明
> 小红，我们结婚五年了，你是我最爱的人，但我最近工作压力很大，所以我忽略了你的感受，我知道这是我的错。

✅ 正确（对话有潜台词）：
> 小红看着桌上的离婚协议书，没有抬头。
>
> 小红
> 你签了吗？
>
> 小明站在门口，手里攥着公文包。
>
> 小明
> 小红，我们能不能……
>
> 小红
> （打断他）
> 你已经三个月没在家吃过晚饭了。
>
> 沉默。
>
> 小明慢慢走过去，在她对面坐下。
>
> 小明
> （轻声）
> 我签。

#### 原则四：每个场景都有冲突和转折

❌ 错误（无冲突场景）：
> 小明走进餐厅，点了一份炒饭，吃完，付钱，离开。

✅ 正确（有冲突和转折）：
> 小明走进餐厅，找了个角落坐下。
>
> 服务员走过来。
>
> 服务员
> 先生，几位？
>
> 小明
> 一位。
>
> 服务员
> （看了一眼他的衣服）
> 我们这里最低消费两百。
>
> 小明的脸红了。他摸了摸口袋——里面只有八十块。
>
> 小明
> 那……我换一家。
>
> 他起身要走，撞到了一个人——是他的前女友小红，和一个男人手牵手走进来。
>
> 三个人都愣住了。

#### 原则五：控制信息，用视觉悬念

❌ 错误（信息全给）：
> 小明走进房间，看到桌子上有一把带血的刀，他知道这是凶器，凶手就是小刚。

✅ 正确（控制信息，视觉悬念）：
> 小明推开门。
>
> 房间里一片漆黑。
>
> 他摸索着打开灯。
>
> 灯亮的瞬间——
>
> 桌子上，一把刀，刀刃上有暗红色的痕迹。
>
> 小明的瞳孔收缩。
>
> 他慢慢走近，蹲下来，仔细看那把刀。
>
> 刀柄上，刻着一个字母："G"。
>
> 小明的脸色变了。
>
> （观众不知道"G"是谁，小明知道——悬念产生了）

## 六、对话写作

### 好对话的四个标准

1. **每句对话都有目的**——推动情节、展示人物、制造冲突、揭示信息，四者至少占其一
2. **有潜台词**——人物说的和想的不一样，"话里有话"
3. **符合人物身份**——不同的人说话方式不同（教育背景、职业、性格、地域）
4. **简洁**——不要啰嗦，不要解释，不要说"小说式"的长句

### 潜台词写作

潜台词是"人物说的话"和"人物真正想的"之间的差距。好的对话，表面在说A，实际在说B。

**示例**：
- 表面："你最近工作很忙啊。"
- 实际："你忽略我很久了，我很生气。"

- 表面："这件衣服挺好看的。"
- 实际："这件衣服太贵了，我不想买。"

- 表面："我没事。"
- 实际："我很有事，但我不想说。"

**写作技巧**：
- 让人物回避问题，而不是直接回答
- 让人物用反问代替回答
- 让人物说和情绪相反的话（生气时说"我没事"，伤心时说"我不在乎"）
- 用沉默代替对话（有时候不说话比说话更有力量）

### 对话节奏

- **短句**：紧张、冲突、愤怒时用短句
- **长句**：思考、回忆、抒情时用长句
- **打断**：人物被打断，展示权力关系或情绪激动
- **沉默**：关键时候用沉默，比对话更有力量
- **重叠**：两个人同时说话，展示混乱或争吵

### 对话禁忌

- ❌ 不要让人物说他们不会说的话（小孩说大人话、古人说网络用语）
- ❌ 不要用对话解释背景（"你还记得吗，我们十年前在巴黎……"）
- ❌ 不要让所有人物说话方式都一样
- ❌ 不要写"完美"的对话（现实中人们会结巴、会重复、会说废话）
- ❌ 不要用对话直接说主题（"我明白了，家庭比事业更重要"）

## 七、国内/海外剧本格式差异

### 国内剧本格式特点

- **场景标题**：通常用"第一场 小明家 夜 内"的格式，和好莱坞格式略有不同
- **字数/页数**：国内电影剧本通常3-5万字，比好莱坞剧本字数多（因为中文信息密度高）
- **人物小传**：国内剧本通常在开头有人物小传，详细介绍主要人物
- **分集大纲**：剧集通常先写分集大纲，再写剧本
- **审查意识**：国内剧本需要考虑审查，涉及政治、暴力、色情、迷信等内容要谨慎

### 海外（好莱坞）剧本格式特点

- **严格的格式**：场景标题、动作、人物名、对话都有严格的缩进和格式（用Final Draft等专业软件）
- **1页≈1分钟**：严格的页数控制，电影90-120页
- **简洁的动作描写**：动作描写非常简洁，只写最必要的
- **更少的人物小传**：人物介绍通常在第一次出场时用一两句话，不单独写小传
- **三幕+15节拍**：好莱坞剧本非常看重结构，节拍表是标配

### 跨文化剧本写作建议

1. **格式按目标市场**：给国内看用国内格式，给海外看用好莱坞格式
2. **主题要普适**：爱情、家庭、正义、成长——这些是跨文化的
3. **文化特定元素要解释**：如果有中国特色的元素（武侠、修仙、中医），海外观众可能需要更多视觉解释
4. **对话要翻译友好**：避免太多谐音梗、文化梗（翻译后会失去效果）
5. **人物动机要普适**：无论什么文化，人物的核心动机（爱、恐惧、欲望、复仇）都是共通的

---

## 八、常见问题及解法

| 问题 | 表现 | 解法 |
|------|------|------|
| **剧本像小说** | 大段心理描写、背景介绍、形容词堆砌 | 用"影视化思维"检查——每句话都能拍出来吗？不能拍的删掉或改成画面 |
| **对话太多** | 人物一直在说话，没有动作和画面 | 增加动作描写，用画面展示信息；把部分对话改成动作或沉默 |
| **对话太少** | 全是动作，没有对话，人物像哑巴 | 关键信息和情感通过对话传递；人物之间要有交流 |
| **场景没有冲突** | 场景只是"发生了什么"，没有张力 | 每个场景都要有冲突（人物vs人物/人物vs环境/人物vs自己）和转折 |
| **节奏太慢** | 前30页还没进入正题，观众/读者失去耐心 | 用15节拍表检查——催化剂在第12页左右，进入第二幕在第25页左右 |
| **节奏太快** | 情节跳跃，人物没有情感反应，观众跟不上 | 在关键转折后给人物反应时间；增加情感场景；让情节有因果关系 |
| **人物扁平** | 所有人物说话方式一样，没有个性 | 给每个人物设计独特的说话方式（用词、句式、口头禅）；让人物的对话符合身份和性格 |
| **潜台词不足** | 人物直接说出心里想的，没有张力 | 让人物回避问题、说反话、用行动代替语言；好的对话是"话里有话" |
| **格式不规范** | 场景标题、人物名、对话格式混乱 | 用专业剧本软件（Final Draft/WriterDuet/国内的"剧享"等）；学习标准格式 |
| **不能拍** | 写了大量心理活动、回忆、抽象概念，无法直接拍摄 | 改成闪回、梦境、画面隐喻；或者删掉，用对话和动作展示 |
| **主题太直白** | 人物直接说出主题，像在说教 | 用故事和人物展示主题，不要让人物"演讲"；好的主题是观众自己感受到的 |
| **结尾无力** | 高潮不够震撼，结尾平淡 | 用15节拍表检查——结局应该是A故事和B故事交汇，主角用学到的东西解决冲突 |

## 九、完整剧本示例（短片）

```
FADE IN:

INT. 公交车 - 夜晚

拥挤的公交车，灯光昏黄。窗外的城市灯火飞速后退。

林晚（28岁，穿着职业装，眼神疲惫）抓着扶手，随着车身摇晃。她的手里攥着一个文件袋，袋角已经被捏皱了。

手机震动。她看了一眼——"老板"。

她深吸一口气，接起电话。

林晚
（尽量让声音听起来精神）
王总，您好。

王总（V.O.）
（声音不耐烦）
方案改好了吗？明天早上九点要给客户。

林晚
改好了，我今晚再检查一遍，明天一早就发您。

王总（V.O.）
今晚就发我。我要先看。

林晚
（看了一眼窗外）
可是我现在在公交车上，到家还要半小时……

王总（V.O.）
（打断她）
那就到家马上发。我不管你用什么方法，今晚我必须看到。

电话挂了。

林晚握着手机，手指微微发白。

旁边的一个老太太（70岁，慈祥）看了她一眼，往里面挪了挪，腾出一个座位。

老太太
姑娘，坐这儿吧。看你累的。

林晚愣了一下，然后勉强笑了笑。

林晚
谢谢您，不用了，我下一站就到。

老太太
（坚持）
坐吧，站着多累。你们年轻人啊，就是太拼了。

林晚犹豫了一下，坐了下来。

老太太
（看着她手里的文件袋）
工作的事？

林晚
（点点头）
嗯。

老太太
我年轻的时候也这样，天天加班，觉得工作最重要。后来身体垮了，才知道——

她拍了拍林晚的手。

老太太
工作是做不完的，身体是自己的。

林晚的眼眶红了。她低下头，不让老太太看到。

公交车报站："下一站，人民广场。"

林晚站起来。

林晚
阿姨，我到了。谢谢您。

老太太
（笑着摆摆手）
早点休息。

林晚点点头，走向车门。

车停了。她下车，冷风扑面而来。

她裹紧外套，走向地铁站。

走了几步，她停下来，回头看了一眼公交车——车已经开走了。

她低头看了看手里的文件袋，然后拿出手机，给老板发了一条消息：

"王总，方案我明天早上到公司发给您。我今晚需要休息。"

发完，她把手机调成静音，塞进口袋。

她深吸一口气，抬起头，大步走向地铁站。

她的背影比刚才挺直了一些。

FADE OUT.
```

## 十一、剧本质量自检清单

完成剧本初稿后，用以下清单自检：

### 格式
- [ ] 场景标题格式正确吗？（INT./EXT. 地点 - 时间）
- [ ] 人物名居中/缩进、全大写吗？
- [ ] 对话格式正确吗？
- [ ] 动作描写用现在时吗？
- [ ] 转场格式正确吗？
- [ ] 页数大致符合时长吗？（1页≈1分钟）

### 结构
- [ ] 开场画面有吸引力吗？（前10页能抓住读者吗？）
- [ ] 催化剂（激励事件）在合适的位置吗？（约第12页）
- [ ] 进入第二幕（第一幕转折）在合适的位置吗？（约第25页）
- [ ] 中点有重大转折吗？（约第55页）
- [ ] "一切尽失"（最低谷）有力量吗？（约第75页）
- [ ] 进入第三幕（第二幕转折）合理吗？（约第85页）
- [ ] 结局解决了核心冲突吗？
- [ ] 终场画面和开场画面对比，展示了人物成长吗？

### 影视化
- [ ] 每句话都能拍出来吗？（没有心理描写、抽象概念）
- [ ] 用画面展示，不用文字说明吗？
- [ ] 用动作展示性格，不用形容词说明吗？
- [ ] 每个场景都有冲突和转折吗？
- [ ] 信息通过画面和对话传递，不用大段解释吗？

### 对话
- [ ] 每句对话都有目的吗？（推动情节/展示人物/制造冲突/揭示信息）
- [ ] 有潜台词吗？（人物说的和想的不一样）
- [ ] 每个人物说话方式不同吗？（符合身份、性格、教育背景）
- [ ] 对话简洁吗？（没有啰嗦、解释、说教）
- [ ] 对话节奏合适吗？（紧张时短句，抒情时长句）
- [ ] 没有"小说式"的长段对话吗？

### 人物
- [ ] 主角有明确的目标和缺陷吗？
- [ ] 主角在故事中有成长/变化吗？
- [ ] 反派有说服力吗？（有自己的动机和逻辑）
- [ ] 配角有个性吗？（不是工具人）
- [ ] 人物关系有变化吗？

### 节奏
- [ ] 前10页抓住读者了吗？
- [ ] 每10页有一个转折或新信息吗？
- [ ] 紧张场景和放松场景交替吗？
- [ ] 没有冗长的场景吗？
- [ ] 高潮有足够的铺垫和冲击力吗？

### 整体
- [ ] 主题通过故事展示，不是通过对话说教吗？
- [ ] 读者读完脑海里有画面感吗？
- [ ] 有让人记住的场景或台词吗？
- [ ] 符合目标市场的格式和审查要求吗？

**任何一项不通过，回到对应部分修改，修改后重新自检。**

---

> **剧本专项的终极目标**：让读者读完剧本后，脑海里已经有了一部完整的电影——他们看到了画面、听到了对话、感受到了情绪。好的剧本不是"写得好"，是"拍得出来"。当一个导演拿到你的剧本，说"这个我能拍"，当一个演员读到你的角色，说"这个我想演"——你的剧本就成功了。
