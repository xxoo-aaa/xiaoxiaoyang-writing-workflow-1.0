# 00-快速启动 · 技能

> 各文体从0到1的完整路线图。不知道第一步该干什么时，从这里开始。

## 何时调用
- 用户说"我想写一篇XX，但不知道怎么开始"
- 用户说"启动一个XX项目"
- 用户需要某文体的完整创作流程指引

## 输入要求
- 文体类型（短篇小说/长篇小说/电影剧本/剧集/短剧/自媒体文章）
- 可选：题材方向、大致想法、目标字数/时长

## 输出格式
- 该文体的完整步骤路线图（每步做什么、产出什么、调用哪个技能）
- 第一步的具体行动建议
- 项目档案初始化模板

## 各文体路线图

### 短篇小说（3000-30000字）
1. **创意** → 调用 02-创意引擎，生成3个高概念方向
2. **选题** → 调用 03-灵感与选题，选定一个方向，明确核心冲突
3. **人物** → 调用 06-人物塑造，设计主角（短篇只需1-2个核心人物）
4. **大纲** → 调用 08-结构与大纲，用三幕结构写场景级大纲
5. **开篇** → 调用 16-吸引力工程，设计开篇钩子
6. **写作** → 按大纲写初稿，过程中调用 12-场景与写作技法、13-对话与台词
7. **修订** → 调用 22-修订与审校，完成至少2轮修订
8. **质检** → 调用 23-质量保障，检查一致性和逻辑

**关键原则**：短篇只讲一个核心冲突，人物少而精，结尾要有余韵或反转。

### 长篇小说（5万字以上）
1. **创意** → 调用 02-创意引擎 + 04-类型工坊，确定核心概念和类型
2. **世界观** → 调用 05-世界观与设定，构建有深度的世界
3. **人物** → 调用 06-人物塑造（主角）+ 07-配角与反派（人物生态）
4. **结构** → 调用 08-结构与大纲，设计卷/部/章三级结构
5. **冲突** → 调用 09-冲突系统，设计四层冲突和升级曲线
6. **主题** → 调用 10-主题与象征，明确核心主题和象征系统
7. **项目 setup** → 调用 19-长篇管理，建立长篇项目管理体系
8. **写作** → 按卷推进，每卷开始前细化该卷大纲，过程中循环调用场景/对话/吸引力技能
9. **修订** → 调用 22-修订与审校，先大修（结构/人物），再小修（文字/节奏）
10. **质检** → 调用 23-质量保障，全面检查

**关键原则**：长篇先建世界和人物，再写大纲；写作中保持项目档案更新；中期注意节奏不崩盘。

### 电影剧本（90-120分钟）
1. **创意** → 调用 02-创意引擎，生成高概念（电影概念必须一句话能说清）
2. **类型** → 调用 04-类型工坊，明确类型和类型惯例
3. **人物** → 调用 06-人物塑造，设计主角和核心对手
4. **结构** → 调用 08-结构与大纲，用三幕/救猫咪结构设计场景大纲（约40-60场）
5. **剧本格式** → 调用 17-剧本专项，学习标准剧本格式
6. **写初稿** → 按场景大纲写，每场调用 12-场景与写作技法、13-对话与台词
7. **修订** → 调用 22-修订与审校，重点检查节奏和场景效率
8. **质检** → 调用 23-质量保障

**关键原则**：电影剧本每场都必须推进故事，没有废场；对话要精简，多用视觉叙事。

### 短剧改编（竖屏微短剧，80-100集）
1. **原著分析** → 分析原著的核心冲突、人物关系、名场面
2. **改编策略** → 调用 18-短剧改编专项，确定改编方向（保留什么/改动什么/强化什么）
3. **人物简化** → 调用 07-配角与反派，把人物标签化、功能化
4. **分集大纲** → 调用 08-结构与大纲 + 18-短剧改编专项，设计80-100集的分集大纲
5. **钩子设计** → 调用 16-吸引力工程，为每集设计集尾钩子和付费卡点
6. **剧本写作** → 调用 17-剧本专项 + 13-对话与台词，按短剧格式写
7. **审核** → 调用 24-内容审核，确保合规

**关键原则**：短剧前3秒必须抓人，每集结尾必须有钩子，冲突密度极高，爽点密集。

## 调用示例
**用户**：我想写一个科幻短篇，帮我启动
**技能输出**：
1. 路线图：创意引擎生成概念 → 选题判断 → 人物设计 → 三幕大纲 → 开篇钩子 → 写作 → 修订
2. 第一步：调用 02-创意引擎，输入"科幻+短篇"，生成3个高概念方向
3. 项目档案已初始化，等待你选择概念方向
