# 29-标题与命名

> 名字是读者对一个人物/地点/作品的第一印象。一个好名字能让读者立刻记住、产生联想、感受到人物的性格和故事的氛围；一个差名字会让读者出戏、记不住、甚至觉得尴尬。命名不是"随便起一个"，是"用最少的字传递最多的信息"。

---

## 一、命名四维度：音、形、义、联想

好的名字在四个维度上都经过设计。

### 维度一：音（听起来怎么样）

**要点**：
- **节奏感**：名字的音节数、重音位置、平仄搭配，读起来要顺口
- **辨识度**：发音要清晰，不要和常见名字太像，也不要太拗口
- **情感暗示**：发音可以暗示性格——尖锐的发音（z/c/s/q）暗示锐利、冷漠；柔和的发音（a/o/m/n/l）暗示温暖、亲切；厚重的发音（zh/ch/sh/g/k）暗示沉稳、有力

**示例**：
- 柔和温暖：林晚、苏暖、江月、白浅
- 锐利冷漠：冷锋、萧寒、沈墨、顾衍
- 沉稳有力：王铁柱、赵大山、周鼎、方刚
- 活泼灵动：小燕子、跳跳、叮当、喵喵

### 维度二：形（写出来怎么样）

**要点**：
- **视觉平衡**：字的笔画数、结构（左右/上下/独体）搭配要协调，不要一个字太复杂一个字太简单
- **辨识度**：字不要太生僻（读者不认识会出戏），也不要太常见（没有辨识度）
- **整体感**：姓和名搭配起来要协调，不要姓很复杂名很简单，或者反过来

**示例**：
- ❌ 不好：爨癵驫（太生僻，读者不认识）、王大（太简单，没有辨识度）、欧阳铁柱（姓很文雅名很土，不协调）
- ✅ 好：顾衍（笔画适中，左右结构+左右结构，协调）、林晚（简单但有辨识度，左右结构+左右结构）、沈墨（有质感，左右结构+上下结构，协调）

### 维度三：义（字的含义是什么）

**要点**：
- **含义暗示性格/命运**：名字的含义可以暗示人物的性格、命运、故事主题
- **不要太直白**：含义要含蓄，不要"张强"就一定很强、"李美"就一定很美——太直白会显得刻意
- **可以有反讽**：名字的含义和人物的实际情况形成反差，有戏剧效果

**示例**：
- 含义暗示性格：萧寒（冷漠疏离）、林暖（温暖亲切）、沈静（安静内敛）、顾勇（勇敢果断）
- 反讽：《活着》里的"福贵"（一生都不富贵）、《白夜行》里的"雪穗"（像雪一样洁白，但实际上在黑暗中行走）
- 含蓄：《红楼梦》里的"甄士隐"（真事隐）、"贾雨村"（假语存）——名字本身就是谐音梗，暗示了故事的性质

### 维度四：联想（让人想到什么）

**要点**：
- **文化联想**：名字会让人联想到历史人物、文学形象、文化符号
- **氛围联想**：名字会让人联想到某种氛围——古风、现代、科幻、恐怖
- **时代联想**：名字会让人联想到某个时代——建国、援朝、文革、改革开放、00后

**示例**：
- 文化联想：李白（诗人）、关羽（武将）、黛玉（《红楼梦》）、悟空（《西游记》）
- 氛围联想：古风（子轩、浩然、诗涵）、现代（子涵、一诺、沐辰）、科幻（星野、银河、零、AI-7）、恐怖（幽冥、血衣、无面）
- 时代联想：50后（建国、援朝、卫国）、70后（志强、建华、红梅）、90后（子涵、浩然、诗涵）、00后（沐辰、一诺、梓萱）

## 二、人物命名方法

### 方法一：性格反推法

**操作**：根据人物的性格、命运、故事主题，反推出名字的音、形、义、联想。

**步骤**：
1. 确定人物的核心性格（3个关键词）
2. 确定人物的命运/故事主题
3. 根据性格和主题，确定名字的"感觉"（柔和/锐利/沉稳/活泼/冷漠/温暖）
4. 根据"感觉"，选择发音和字的含义
5. 检查形和联想，确保协调

**示例**：
- 人物：女主角，外表冷漠内心柔软，是个法医，童年有创伤，故事主题是"在黑暗中寻找光明"
- 核心性格：冷漠、坚韧、温柔（隐藏的）
- 名字感觉：冷、硬、但有一丝温暖
- 发音：冷硬的姓+柔和的名
- 字的含义：姓暗示冷/硬，名暗示光/暖/希望
- 候选：沈晚（沈=沉，晚=黑暗中的夜晚，但"晚"也有"晚霞"的温暖）、萧寒（太冷了，没有温暖）、林墨（林=柔，墨=黑，有质感但不够冷）
- 最终：沈晚——姓冷，名有夜晚的黑暗，但也有"晚霞"的温暖和"晚来的希望"的暗示，符合人物性格和故事主题

### 方法二：时代/背景匹配法

**操作**：根据故事的时代背景、人物的出身、家庭背景，选择符合那个时代/背景的名字。

**要点**：
- 古代人物：用古风名字，参考历史人物的命名方式
- 现代人物：用符合人物出生年代的名字
- 未来/科幻人物：用有未来感的名字（编号、字母+数字、新造词）
- 农村人物：用朴实、接地气的名字
- 城市精英人物：用文雅、有质感的名字
- 富豪家族：用字雅、有传承感的名字，甚至可以用辈分字

**示例**：
- 古代：子轩、浩然、诗涵、婉儿、相如、仲卿
- 50年代：建国、援朝、卫国、红梅、秀英
- 70年代：志强、建华、建军、红梅、小芳
- 90年代：子涵、浩然、诗涵、雨萱、俊杰
- 00年代：沐辰、一诺、梓萱、子墨、思琪
- 农村：铁柱、狗蛋、翠花、春妮、大山
- 城市精英：子轩、一诺、沐辰、思远、若曦
- 富豪家族：顾衍、沈墨、萧寒、林晚、江月（姓少见，名有质感）
- 科幻：星野、银河、零、AI-7、K-2049、新造词

### 方法三：谐音/双关法

**操作**：用谐音或双关，让名字有隐含意义，增加深度和趣味性。

**要点**：
- 谐音：名字的发音和某个词/短语相同或相近，暗示隐含意义
- 双关：名字的字有多重含义，不同的理解有不同的意义
- 不要太刻意：谐音/双关要自然，不要为了谐音而硬凑

**示例**：
- 《红楼梦》：甄士隐（真事隐）、贾雨村（假语存）、元春/迎春/探春/惜春（原应叹息）
- 《白夜行》：桐原亮司（亮司=亮死，暗示他的命运）、唐泽雪穗（雪穗=雪碎，暗示她的脆弱和破碎）
- 《活着》：福贵（一生都不富贵，反讽）
- 原创示例：沈默（沉默，暗示他不爱说话）、林知夏（知夏=知晓夏天，暗示她的出生季节或性格像夏天）、顾望舒（望舒=古代神话中为月亮驾车的神，暗示她的清冷和神秘）

### 方法四：意象联想法

**操作**：选择一个有象征意义的意象（自然景物、动物、物品），作为名字的灵感来源。

**常见意象及暗示**：
- **自然景物**：月（清冷、温柔、神秘）、星（希望、遥远、闪耀）、风（自由、不羁、变化）、雨（悲伤、洗礼、清新）、雪（纯洁、冷漠、短暂）、山（沉稳、可靠、高大）、水（柔软、流动、包容）
- **植物**：竹（气节、坚韧、挺拔）、梅（傲骨、坚强、早春）、兰（高雅、幽静、君子）、菊（隐逸、高洁、晚秋）、莲（纯洁、出淤泥而不染）、桃（浪漫、春天、短命）
- **动物**：龙（尊贵、力量、神秘）、凤（美丽、高贵、重生）、狼（孤独、凶猛、团队）、鹰（锐利、高远、自由）、鱼（自由、灵动、潜意识）
- **物品**：剑（锐利、决断、武力）、琴（优雅、艺术、情感）、书（知识、文雅、安静）、玉（珍贵、纯洁、温润）、墨（文采、深沉、黑色）

**示例**：
- 月：林月、江月、白月、月如
- 星：星河、星野、星辰、南星
- 风：林风、风眠、晨风、随风
- 竹：竹君、竹轩、翠竹、竹影
- 梅：梅君、傲雪、红梅、梅影
- 剑：剑心、剑魂、御剑、剑秋
- 玉：玉瑶、玉暖、明玉、玉书
- 墨：墨白、墨尘、沈墨、墨秋

### 方法五：随机组合法

**操作**：准备一些姓和名的字，随机组合，然后从中挑选有感觉的。

**步骤**：
1. 准备10-20个符合故事风格的姓
2. 准备20-30个符合故事风格的名单字
3. 随机组合，写出50-100个候选名字
4. 从中挑选10个有感觉的
5. 对这10个进行音、形、义、联想的检查，最终确定

**适用场景**：没有灵感的时候，用随机组合打破思维定式，可能会有意外惊喜。

### 海外命名注意事项

1. **文化适配**：名字要符合人物的文化背景——法国人物用法语名字，日本人物用日语名字
2. **时代适配**：名字要符合人物的出生年代——不同年代流行的名字不同
3. **避免刻板印象**：不要用太刻板的名字（比如所有反派都叫Vladimir），给人物起名字时要有多样性
4. **发音简单**：如果目标读者是中文读者，海外名字不要太拗口，尽量选择发音简单、容易记住的
5. **含义美好**：很多海外名字有特定含义（比如Emma=全知的、普遍的；Liam=坚定的守护者），可以根据人物性格选择有对应含义的名字

## 五、地名/世界观命名方法

### 方法一：自然特征法

**操作**：根据地点的自然特征（地形、气候、植被、动物）命名。

**示例**：
- 地形：双峰山、断崖城、幽谷、平原郡、海岛市、沙漠堡
- 气候：永冬城、迷雾谷、风暴角、阳光城、雨都、霜原
- 植被：竹林、桃花岛、松山城、枫林渡、草原郡、椰林湾
- 动物：狼牙谷、鹰巢城、虎啸山、龙城、凤凰台、白鹿原

### 方法二：人文特征法

**操作**：根据地点的人文特征（历史、文化、产业、建筑、传说）命名。

**示例**：
- 历史：古都、旧城、新城、遗民城、废墟、战场原
- 文化：圣城、学府城、工匠城、商人港、诗人谷、舞者街
- 产业：铁矿镇、盐场、渔村、酒乡、茶岭、丝绸城
- 建筑：白塔城、黑塔堡、石桥渡、城墙郡、钟楼市、拱门街
- 传说：龙脊山、凤凰台、仙人渡、鬼门关、神泣谷、魔渊

### 方法三：人名/种族名法

**操作**：用建立这个地点的人物/种族的名字命名。

**示例**：
- 人名：亚历山大城、君士坦丁堡、华盛顿、列宁格勒、斯大林格勒、彼得堡
- 种族名：精灵森林、矮人矿山、兽人平原、人类王国、龙族巢穴、地精洞穴
- 家族名：顾家庄、沈家堡、林家镇、江氏城、萧家谷、苏家坞

### 方法四：方向/位置法

**操作**：用地点的方向/位置命名。

**示例**：
- 方向：东城、西城、南城、北城、东郊、西郊、南境、北境、东陆、西陆
- 位置：中原、边境、边疆、内陆、沿海、河口、山顶、山腰、谷底、湖畔
- 相对位置：上郡、下郡、左城、右城、前村、后村、内城、外城

### 方法五：组合法

**操作**：把两个或多个元素组合在一起，创造有层次感的地名。

**示例**：
- 自然+人文：迷雾圣城、铁矿镇、桃花渡口、竹林书院、风暴港
- 人名+自然：亚历山大港、李白村、苏轼堤、岳飞庙、孔子故里
- 方向+自然：东迷雾谷、西风暴角、南阳光城、北永冬城、中原平原
- 种族+自然：精灵迷雾森林、矮人铁矿山脉、兽人风暴平原、人类阳光海岸

### 地名命名原则

1. **好记**：不要太长、太复杂，2-5个字最合适
2. **有画面感**：听到名字就能想象出这个地方的样子
3. **符合世界观**：名字要符合故事的时代、文化、种族背景
4. **有辨识度**：不同地点的名字要有明显区别，不要混淆
5. **有层次感**：大城市/王国的名字要大气，小镇/村庄的名字要朴实

## 六、作品名（书名/片名）选择决策树

作品名是读者看到的第一个东西——好的作品名能让人立刻产生兴趣，差的作品名会让人直接划走。

### 决策树

```
第一步：你的作品是什么类型？
├─ 言情/情感类 → 用情感/意象/金句型名字
├─ 悬疑/推理类 → 用悬念/案件/问题型名字
├─ 玄幻/奇幻类 → 用世界观/核心设定/主角型名字
├─ 都市/现实类 → 用主角/职业/事件型名字
├─ 历史/穿越类 → 用时代/事件/主角型名字
├─ 科幻类 → 用核心设定/危机/意象型名字
└─ 恐怖/灵异类 → 用诡异/恐惧/意象型名字

第二步：你的作品核心卖点是什么？
├─ 主角魅力 → 用主角名字/身份/特征
├─ 世界观独特 → 用世界观核心设定/地点
├─ 情感冲击 → 用情感/意象/金句
├─ 悬念/反转 → 用问题/案件/悬念
├─ 爽感/逆袭 → 用主角身份/逆袭关键词
└─ 主题深度 → 用意象/象征/哲理

第三步：名字长度
├─ 2-4字：简洁有力，适合大多数类型
├─ 5-8字：有描述性，适合需要更多信息的类型
└─ 8字以上：太长，不推荐（除非是特别有感觉的长句）
```

### 作品名的五种类型

#### 类型一：主角/身份型

**方法**：用主角的名字、身份、特征作为作品名。

**示例**：
- 《哈利·波特》（主角名字）
- 《福尔摩斯探案集》（主角+类型）
- 《霸道总裁爱上我》（主角身份+核心情节）
- 《废柴逆袭记》（主角特征+核心情节）
- 《法医秦明》（职业+主角名字）

**适用**：主角魅力是核心卖点的作品，尤其是升级流、逆袭流、职业文。

#### 类型二：核心设定/世界观型

**方法**：用故事的核心设定、世界观、地点作为作品名。

**示例**：
- 《冰与火之歌》（世界观核心意象）
- 《魔戒》（核心道具）
- 《三体》（核心设定）
- 《流浪地球》（核心事件+世界观）
- 《哈利·波特与魔法石》（主角+核心道具）

**适用**：世界观独特、核心设定有吸引力的作品，尤其是科幻、奇幻、玄幻。

#### 类型三：情感/意象/金句型

**方法**：用有情感冲击力、有画面感、有哲理的短语作为作品名。

**示例**：
- 《活着》（极简，有力量）
- 《百年孤独》（时间+情感）
- 《追风筝的人》（意象+人物）
- 《不能承受的生命之轻》（哲理+情感）
- 《微微一笑很倾城》（情感+氛围）

**适用**：言情、文学、情感类作品，主题有深度的作品。

#### 类型四：悬念/问题/案件型

**方法**：用一个悬念、问题、案件作为作品名，让人想知道答案。

**示例**：
- 《谁杀了她》（问题）
- 《无人生还》（悬念）
- 《消失的爱人》（人物+悬念）
- 《达芬奇密码》（地点+悬念）
- 《十宗罪》（数字+类型）

**适用**：悬疑、推理、犯罪、恐怖类作品。

#### 类型五：事件/时代型

**方法**：用故事的核心事件、时代背景作为作品名。

**示例**：
- 《三国演义》（时代+类型）
- 《水浒传》（地点+类型）
- 《红楼梦》（意象+类型）
- 《万历十五年》（时间）
- 《甲午战争》（事件）

**适用**：历史、战争、大时代背景的作品。

### 作品名自检清单

- [ ] 好记吗？（读者看完一遍能记住吗？）
- [ ] 好读吗？（发音顺口吗？没有生僻字吗？）
- [ ] 符合类型吗？（读者看到名字能猜到是什么类型吗？）
- [ ] 有吸引力吗？（让人想点进去看吗？）
- [ ] 没有剧透吗？（没有把关键情节/结局说出来）
- [ ] 长度合适吗？（2-8字，不要太长）
- [ ] 有辨识度吗？（和其他作品名不混淆吗？）
- [ ] 符合平台风格吗？（网络平台可以直白一点，出版平台可以文学性一点）

### 常见错误

| 错误 | 示例 | 修改 |
|------|------|------|
| **太直白** | 《一个男人和一个女人的爱情故事》 | 《爱在黎明破晓前》 |
| **太文艺** | 《那一抹淡淡的忧伤如同秋日的落叶般飘零》 | 《晚秋》 |
| **太长** | 《关于我转生变成史莱姆这档事》（虽然长但有记忆点，是例外） | 通常控制在8字以内 |
| **太普通** | 《爱情故事》 | 《傲慢与偏见》 |
| **和类型不符** | 悬疑文叫《甜甜的恋爱》 | 悬疑文叫《无声的证词》 |
| **生僻字** | 《饕餮鬻龘》 | 《寻龙诀》 |

## 七、命名禁忌

### 禁忌一：生僻字

**问题**：读者不认识，读不出来，记不住，甚至会因为不认识而放弃。

**示例**：爨、癵、驫、麤、龘、靐、齉、籲、灪、爩

**正确做法**：用常见但有质感的字，不要为了"显得有文化"用生僻字。

### 禁忌二：和知名角色重名

**问题**：读者会联想到知名角色，产生先入为主的印象，甚至觉得你在抄袭/蹭热度。

**示例**：
- 男主角叫"哈利·波特"（和《哈利·波特》重名）
- 女主角叫"林黛玉"（和《红楼梦》重名）
- 反派叫"伏地魔"（和《哈利·波特》重名）

**正确做法**：避免和知名角色重名，尤其是同类型的知名角色。如果不小心重名了，改一个字或者换一个名字。

### 禁忌三：谐音不好

**问题**：名字的谐音有不好的含义，会让读者出戏、觉得尴尬、甚至嘲笑。

**示例**：
- 杜子腾（肚子疼）
- 史珍香（屎真香）
- 范建（犯贱）
- 朱逸群（猪一群）
- 秦寿生（禽兽生）

**正确做法**：起好名字后，多读几遍，看看有没有不好的谐音。如果有，改一个字或者换一个名字。

### 禁忌四：和人物性格/身份不符

**问题**：名字的感觉和人物的性格/身份/背景不符，会让读者出戏。

**示例**：
- 一个冷酷的杀手叫"李小暖"
- 一个农村大妈叫"上官婉儿"
- 一个古代将军叫"Jason"
- 一个未来科幻世界的人叫"王建国"

**正确做法**：名字要符合人物的性格、身份、时代、背景。用"性格反推法"和"时代/背景匹配法"确保名字和人物匹配。

### 禁忌五：角色名字太像

**问题**：多个角色的名字太像，读者会混淆，记不住谁是谁。

**示例**：
- 林晚、林婉、林宛、林琬（四个角色名字太像）
- 小明、小红、小方、小莉（都用"小+字"，太像）
- 张磊、李磊、王磊、赵磊（都用"磊"，太像）

**正确做法**：主要角色的名字要有明显区别——发音、字形、感觉都要不同。配角的名字可以简单一些，但也要和主要角色有区别。

### 禁忌六：名字太多太杂

**问题**：出场人物太多，名字太杂，读者记不住谁是谁，会混乱。

**正确做法**：
- 控制主要角色数量（通常3-8个）
- 次要角色可以用身份代替名字（"店长""司机""老妇人"）
- 重要角色出场时，用特征帮助读者记住（外貌、性格、口头禅）
- 不要在短时间内让太多新角色出场

## 八、正反示例对比

### 示例一：人物命名

❌ **差的命名**：
> 男主角叫张强，女主角叫李美，男二号叫王帅，女二号叫刘艳。
>
> 反派叫赵坏。

（问题：名字太普通、太直白，没有辨识度，没有性格暗示，读者记不住。）

✅ **好的命名**：
> 男主角叫沈墨——沈=沉，墨=黑/文采，暗示他沉默寡言、有深度、有黑暗的过去。
>
> 女主角叫林晚——林=柔，晚=夜晚/晚霞，暗示她外表柔和但有夜晚的坚韧，还有"晚来的希望"的暗示。
>
> 男二号叫顾衍——顾=看/照顾，衍=延伸/繁衍，暗示他眼光长远、有掌控力、是个复杂的人。
>
> 女二号叫苏暖——苏=苏醒/苏州，暖=温暖，暗示她温暖、有治愈力、是林晚的对比。
>
> 反派叫萧寒——萧=萧瑟/萧条，寒=寒冷/冷漠，暗示他冷酷、孤独、有悲剧性。

（问题：每个名字都有性格暗示，有辨识度，发音和字形协调，读者容易记住。）

### 示例二：地名命名

❌ **差的命名**：
> 故事发生在A城，旁边有B山，山上有C庙，庙旁边有D河。

（问题：用字母代替，没有画面感，没有辨识度，读者记不住。）

✅ **好的命名**：
> 故事发生在临江城——临江，暗示城市在江边，有水运和商业。
>
> 城旁边有双峰山——两座山峰并立，是城市的标志，也是故事的重要场景。
>
> 山上有白云寺——建在山顶，常有云雾缭绕，是个有历史的古寺。
>
> 寺旁边有落雁河——每年秋天有大雁落在这里休息，因此得名。

（问题：每个地名都有画面感，有由来，符合世界观，读者容易记住。）

### 示例三：作品名命名

❌ **差的命名**：
> 作品名叫《一个女人的故事》。

（问题：太普通、太笼统，没有吸引力，读者不知道这是什么类型、什么故事。）

✅ **好的命名**：
> 作品名叫《三十岁，从头再来》。
>
> 或者叫《卤味皇后》。
>
> 或者叫《她不认输》。

（问题：有主角特征、有核心冲突、有情感冲击力、符合类型，读者看到名字就想知道更多。）

## 九、与其他模块联动

| 联动模块 | 怎么配合 |
|---------|---------|
| **04-类型工坊** | 不同类型的命名风格不同——古风用古风名字，现代用现代名字，科幻用未来感名字；按类型调整命名风格 |
| **05-世界观与设定** | 地名和种族名要符合世界观——不同种族、不同地区有不同的命名方式；世界观的核心设定可以作为作品名的灵感 |
| **06-人物塑造** | 名字是人物的第一印象——名字要暗示人物的性格、命运、背景；用人物塑造的方法找到人物的核心特质，再反推名字 |
| **07-配角与反派** | 配角和反派的名字也要有辨识度——不要用太普通的名字；反派的名字可以有暗黑感，但不要太刻意 |
| **28-简介与文案** | 作品名和简介是一体的——作品名吸引读者点进来，简介让读者决定要不要看；作品名和简介的风格要一致 |
| **30-翻译与海外本地化** | 海外发行时，名字需要翻译或本地化——中文名字翻译成外文时要考虑发音和含义；外文名字翻译成中文时要符合中文读者的习惯 |
| **27-写作搭档（小小羊）** | 小小羊会帮你起名字——人物名、地名、作品名，还会根据你的故事类型和人物性格推荐合适的名字，帮你检查命名禁忌 |

## 十、命名质量自检清单

完成所有命名后，用以下清单自检：

### 人物命名
- [ ] 主要角色的名字有辨识度吗？（读者能记住吗？）
- [ ] 名字的发音顺口吗？（没有生僻字、没有拗口的发音）
- [ ] 名字的字形协调吗？（姓和名搭配协调，没有太复杂或太简单的字）
- [ ] 名字的含义暗示人物性格/命运吗？
- [ ] 名字符合人物的时代/背景/身份吗？
- [ ] 主要角色的名字有明显区别吗？（不会混淆）
- [ ] 没有不好的谐音吗？
- [ ] 没有和知名角色重名吗？

### 地名命名
- [ ] 地名有画面感吗？（听到名字能想象出地方的样子）
- [ ] 地名好记吗？（2-5个字，不要太长）
- [ ] 地名符合世界观吗？（时代、文化、种族背景）
- [ ] 不同地名有明显区别吗？（不会混淆）
- [ ] 重要地名有由来/传说吗？（增加深度）

### 作品名
- [ ] 好记吗？（读者看完一遍能记住吗？）
- [ ] 好读吗？（发音顺口，没有生僻字）
- [ ] 符合类型吗？（读者看到名字能猜到类型）
- [ ] 有吸引力吗？（让人想点进去看）
- [ ] 没有剧透吗？
- [ ] 长度合适吗？（2-8字）
- [ ] 有辨识度吗？（和其他作品不混淆）

### 整体
- [ ] 所有名字的风格统一吗？（古风故事全用古风名字，现代故事全用现代名字）
- [ ] 名字没有违反命名禁忌吗？（生僻字、重名、谐音不好、性格不符、太像、太多太杂）
- [ ] 读者能记住主要角色和重要地点的名字吗？
- [ ] 名字增加了故事的深度和氛围吗？（不只是"代号"，而是有意义的）

**任何一项不通过，回到对应部分修改，修改后重新自检。**

---

> **命名的终极目标**：让读者听到名字的瞬间，就对这个人物/地点/作品产生感觉——"这个人一定很冷酷""这个地方一定很神秘""这个故事一定很好看"。好的名字不是"随便起的"，是"用最少的字传递最多的信息"。当读者合上书后，他们可能忘了情节，但他们会记住那个名字——因为那个名字已经变成了一个有血有肉的人、一个有画面感的地方、一个有温度的故事。
