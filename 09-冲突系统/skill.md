# 09-冲突系统 · 技能

> 设计故事的引擎：四层冲突、冲突升级曲线、冲突多样性、场景冲突注入。没有冲突就没有故事。

## 何时调用
- 用户觉得故事太平、没有张力
- 用户需要设计故事的核心冲突
- 用户需要检查冲突是否足够强、足够多样化
- 用户说"冲突不够/故事太平"

## 输入要求
- 故事大纲/核心概念
- 主要人物
- 可选：当前觉得平淡的具体场景/段落

## 输出格式
- 核心冲突设计（四层冲突分析）
- 冲突升级曲线（故事各阶段的冲突强度）
- 冲突多样性检查（避免所有冲突都是同一种）
- 具体场景的冲突注入建议
- "没有冲突的场景"识别和改造方案
- 冲突的解决与代价设计

## 核心方法论

### 四层冲突模型

好的故事同时存在四个层面的冲突，它们互相交织：

**第一层：内在冲突（人与自我）**
- 主角内心的矛盾和挣扎
- 来源：核心创伤、核心恐惧、核心渴望之间的矛盾
- 表现：犹豫、自我怀疑、艰难选择、价值观冲突
- 例子：想救人但害怕再次失败 / 渴望爱但不敢信任 / 追求正义但内心有复仇欲

**第二层：人际冲突（人与人）**
- 主角和其他角色之间的冲突
- 来源：目标对立、价值观差异、误解、利益冲突、情感纠葛
- 表现：争吵、对抗、背叛、竞争、误解、关系破裂
- 例子：和反派的对抗 / 和盟友的分歧 / 和爱人的误会 / 和家人的矛盾

**第三层：社会冲突（人与环境/社会）**
- 主角和更大的系统之间的冲突
- 来源：社会制度、文化规范、权力结构、经济压力、偏见歧视
- 表现：被体制压迫、被社会排斥、对抗不公、生存压力
- 例子：对抗腐败的司法系统 / 在歧视性社会中争取平等 / 贫穷带来的生存压力 / 末世中的资源争夺

**第四层：命运冲突（人与超自然/命运）**
- 主角和不可控力量之间的冲突
- 来源：命运、神、超自然力量、自然灾难、时间、死亡
- 表现：对抗命运、与神角力、在灾难中求生、与时间赛跑
- 例子：时间循环中的徒劳 / 预言中的宿命 / 天灾中的生存 / 绝症中的抗争

**四层冲突的关系**：
- 外在冲突（人际/社会/命运）触发和考验内在冲突
- 内在冲突的解决是人物成长的核心
- 最好的故事中，四层冲突在高潮处汇聚
- 主角的最终选择同时解决外在冲突和内在冲突

### 核心冲突设计

**核心冲突公式**：`主角想要[目标]，但[障碍/对手]阻止他，因为[根本原因]`

**好的核心冲突的标准**：
1. **个人化**：冲突和主角的核心创伤/身份/价值观直接相关，不是"随便换个人也一样"
2. **不可调和**：双方的目标本质对立，不能通过谈判解决（至少表面上不能）
3. **有 stakes**：失败的代价足够大，主角输不起
4. **有升级空间**：冲突可以逐步升级，从简单到复杂，从外在到内在
5. **有主题意义**：冲突的本质关乎故事的主题

**核心冲突强化技巧**：
- 让反派和主角有相似的创伤但不同的选择（镜像冲突）
- 让主角的目标和他的内心恐惧矛盾（越接近目标越恐惧）
- 让主角必须在两个都重要的东西之间选择（两难冲突）
- 让冲突的代价逐步升级（从输比赛→输事业→输朋友→输生命）

### 冲突升级曲线

冲突不是一成不变的，它应该随着故事推进逐步升级：

**第一幕**：建立冲突
- 展示主角日常中的小冲突（暗示他的内在矛盾）
- 激励事件引入核心冲突
- 第一幕转折点：主角被卷入冲突，无法回头

**第二幕前半**：冲突升级
- 主角面对越来越大的挑战
- 每解决一个小冲突，引出更大的冲突
- 冲突从外在（解决问题）逐步深入到内在（挑战信念）

**中点**：冲突质变
- 重大胜利或重大失败
- 冲突的性质改变了（从"能不能做到"变成"该不该做"）
-  stakes 显著提高

**第二幕后半**：冲突激化
- 反派/障碍全力反击
- 主角的盟友开始动摇/离开
- 内在冲突加剧，主角开始自我怀疑
- 冲突从多个层面同时施压

**最低点**：冲突顶峰（负面）
- 主角似乎彻底失败
- 外在冲突：失去了最重要的东西
- 内在冲突：信念崩塌，自我怀疑到极点
- 所有层面的冲突同时达到最大压力

**第三幕**：冲突解决
- 主角从最低点站起来，做出最终选择
- 高潮：四层冲突同时爆发和解决
- 主角的最终选择定义了他是谁，也解决了核心冲突
- 结局：展示冲突解决后的新状态

### 冲突多样性

**常见问题**：所有冲突都是同一种（比如都是吵架/都是打斗/都是被追杀），读者会疲劳。

**冲突类型清单**（确保你的故事里有多种）：
- 身体冲突：打斗、追逐、生存挑战
- 言语冲突：争论、谈判、审讯、争吵
- 情感冲突：误解、背叛、信任危机、关系破裂
- 道德冲突：价值观对立、两难选择、良心拷问
- 智力冲突：解谜、策略博弈、心理战
- 社会冲突：制度压迫、偏见、阶级矛盾
- 时间冲突：截止日期、与时间赛跑
- 资源冲突：争夺有限的资源
- 身份冲突：我是谁、我应该成为谁
- 信仰冲突：信念的动摇和重建

**多样性检查**：
- 列出故事中的10个主要冲突场景
- 标注每个冲突的类型
- 如果超过5个是同一种类型，需要调整
- 确保重要场景的冲突类型不同，交替出现

### 场景冲突注入

**"没有冲突的场景"的特征**：
- 角色只是在交流信息，没有分歧
- 场景结束时和开始时状态一样
- 角色顺利得到了他们想要的
- 只是过渡，没有实质内容

**注入冲突的方法**：
1. **给角色不同的目标**：同一场景中，A想要X，B想要Y，X和Y矛盾
2. **引入障碍**：角色想要的东西不容易得到，有具体的障碍
3. **制造误解**：角色之间有信息差，导致误解和冲突
4. **时间压力**：给场景加一个截止时间，增加紧迫感
5. **内在冲突**：即使外在顺利，角色内心也在挣扎
6. **隐藏的对立**：表面和谐，但某个角色有隐藏的目的
7. **提高 stakes**：让这个场景的结果对角色更重要

**场景冲突改造模板**：
```
原场景：两人在咖啡馆聊天，交流信息
改造后：
- A想告诉B一个秘密，但B正在生气不想听
- 或者：A想从B口中套信息，但B察觉了，反过来试探A
- 或者：两人表面友好，但都在隐瞒自己的真实目的
- 或者：时间压力——他们只有5分钟，因为有人正在找他们
```

### 冲突的解决与代价

**冲突不能太容易解决**：
- 主角的胜利必须有代价（失去什么/牺牲什么/改变什么）
- 即使赢了，也不是完美的胜利（有得有失）
- 冲突的解决应该导致主角的永久变化

**冲突解决的类型**：
- 彻底解决：反派被打败，问题完全解决
- 妥协解决：双方各退一步，达成不完美的和平
- 牺牲解决：主角牺牲重要的东西换取胜利
- 转化解决：冲突的性质改变了，原来的矛盾不再是矛盾
- 悬而未决：冲突没有完全解决，留下余味（适合某些类型）

**代价设计**：
- 外在代价：失去了什么（人/物/地位/机会）
- 内在代价：改变了什么（信念/身份/关系）
- 主题代价：胜利的代价是否质疑了主题？（比如"赢了战斗输了灵魂"）

## 调用示例
**用户**：我的故事太平了，帮我看看冲突够不够
**技能输出**：
先分析你当前的冲突：
- 内在冲突：主角想证明自己（有）
- 人际冲突：和反派的对抗（有，但太单一）
- 社会冲突：无
- 命运冲突：无
问题：
1. 只有两层冲突，缺少社会和命运层面
2. 人际冲突都是"和反派打架"，类型单一
3. 冲突没有明显的升级曲线，一直是同一个强度
4. 很多场景没有冲突，只是在过渡
建议：
1. 增加社会冲突：让主角对抗的不只是反派，还有包庇反派的体制
2. 增加命运冲突：主角有一个无法改变的限制（比如时间/疾病/预言）
3. 冲突多样化：加入智力冲突（心理战）、情感冲突（盟友背叛）、道德冲突（要不要用反派的手段）
4. 设计冲突升级曲线：第一幕小冲突→第二幕逐步升级→中点质变→最低点全面崩溃→高潮四层汇聚
...（具体场景的冲突注入建议）
