# 08-结构与大纲 · 技能

> 设计故事的骨架：三幕结构、场景级大纲、节奏控制、三层叙事（明线/暗线/角色线）。

## 何时调用
- 用户需要写故事大纲/结构设计
- 用户觉得故事结构松散/节奏有问题
- 用户需要把想法扩展成完整的故事框架
- 用户说"帮我写大纲/设计故事结构"

## 输入要求
- 核心概念/故事想法
- 主要人物（至少主角）
- 目标文体和字数/时长
- 可选：已有的情节想法、参考作品

## 输出格式
- 故事核心（一句话概念 + 主题 + 核心冲突）
- 三幕结构大纲（每幕的核心事件、转折点、高潮）
- 场景级/章节级大纲（每个场景的目标、冲突、转折、结果）
- 节奏分析（紧张/舒缓的分布）
- 三层叙事设计（明线/暗线/角色线）
- 大纲完整性检查

## 核心方法论

### 三幕结构（通用框架）

**第一幕：建置（约占25%）**
- **开场**：展示主角的日常世界，建立人物和基调
- **激励事件**：打破日常的事件，故事正式开始
- **第一幕转折点**：主角做出决定，进入未知世界（不归点）

**第二幕：对抗（约占50%）**
- **上升动作**：主角面对一系列挑战，逐步成长
- **中点**：故事的中间转折点，通常是重大胜利或重大失败，改变了故事的方向
- **上升动作（后半）**：难度升级，主角面临更大的挑战
- **第二幕转折点（最低点）**：主角似乎失去了一切，所有希望破灭

**第三幕：解决（约占25%）**
- **高潮**：主角和反派的最终对决，做出最终选择
- **结局**：展示新世界的状态，主角的变化，余韵

### 经典结构模型

**救猫咪（Blake Snyder）15个节拍**：
1. 开场画面
2. 主题陈述
3. 建置
4. 催化剂（激励事件）
5. 争论（主角犹豫）
6. 进入第二幕
7. B故事（通常是爱情线/友情线）
8. 游戏与娱乐（类型片的核心乐趣）
9. 中点
10. 坏人逼近
11. 一无所有
12. 灵魂黑夜
13. 进入第三幕
14. 结局
15. 终场画面

**英雄之旅（Joseph Campbell）**：
- 日常世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越门槛 → 考验/盟友/敌人 → 接近最深的洞穴 → 严峻考验 → 奖赏 → 回头路 → 复活 → 带着万灵丹归来

**三幕+七情节点**：
1. 激励事件
2. 第一幕转折点
3. 第一个情节点（上升）
4. 中点
5. 第二个情节点（继续上升/下降）
6. 第二幕转折点（最低点）
7. 高潮

### 场景级大纲设计

每个场景/章节应该包含：
- **场景目标**：这个场景中角色想要什么？
- **场景冲突**：什么阻止了他？
- **场景结果**：他得到了吗？（通常是"没有，而且更糟了"）
- **场景转折**：场景结束时和开始时，情况有什么不同？
- **信息量**：这个场景揭示了什么新信息？
- **功能**：这个场景推进了什么？（情节/人物/主题/氛围）

**场景大纲模板**：
```
场景 #：
地点/时间：
POV人物：
场景目标：
冲突：
关键事件：
转折/结果：
揭示的新信息：
与主线的关系：
字数预估：
```

### 三层叙事结构

好的故事有三条线交织：

**明线（情节线）**：读者直接看到的故事
- 主角的外部目标和行动
- 事件的因果链
- 这是故事的"骨架"

**暗线（真相线）**：隐藏在表面之下的真相
- 真正发生了什么（和表面看到的不同）
- 角色隐藏的秘密和动机
- 世界观的隐藏真相
- 这是故事的"悬念和深度来源"
- 暗线在故事过程中逐步揭示，在高潮处完全揭开

**角色线（情感线）**：人物的内心成长和变化
- 主角的内心旅程和弧线
- 人物关系的发展
- 主题的情感体现
- 这是故事的"心脏"

**三线交织原则**：
- 每个重要场景应该同时推进至少两条线
- 明线的事件应该触发角色线的变化
- 暗线的揭示应该影响明线的走向
- 三条线在高潮处汇聚和解决

### 节奏控制

**节奏的本质**：不是"一直快"，而是"快慢交替，有张有弛"。

**节奏工具**：
1. **场景长度**：紧张场景短而快，舒缓场景长而慢
2. **信息密度**：关键场景信息密集，过渡场景信息稀疏
3. **视角切换**：多视角时在紧张处切换，增加悬念
4. **时间压缩/拉伸**：重要时刻慢写（拉伸时间），过渡快写（压缩时间）
5. **悬念延迟**：在高潮前插入短暂的平静，增加紧张感
6. **副线穿插**：在主线紧张时插入副线，给读者喘息，同时增加期待

**节奏曲线**：
- 第一幕：建立节奏，逐步加速
- 第二幕前半：上升，有小高潮和喘息
- 中点：重大转折，节奏改变
- 第二幕后半：持续加速，压力增大
- 最低点：短暂的停滞/绝望
- 第三幕：全速冲向高潮
- 结局：减速，余韵

### 大纲完整性检查
- [ ] 激励事件是否足够打破主角的日常？
- [ ] 主角的目标是否清晰？
- [ ] 第一幕转折点是否是主角主动做出的选择？
- [ ] 中点是否改变了故事的方向或利害关系？
- [ ] 最低点是否足够"低"？主角失去了什么？
- [ ] 高潮是否是主角主动做出的最终选择？（不是巧合/外力解决）
- [ ] 结局是否回应了开场和主题？
- [ ] 每个场景是否都有目标、冲突、转折？
- [ ] 有没有可以删掉的"过渡场景"？
- [ ] 暗线是否有足够的铺垫？
- [ ] 节奏是否有张有弛，不是一直快或一直慢？

## 调用示例
**用户**：帮我把"记忆删除师发现客户记忆里有自己失踪妻子的线索"扩展成短篇大纲
**技能输出**：
核心：记忆删除师在删除客户痛苦记忆时，发现一段记忆里出现了自己失踪三年的妻子。
主题：记忆定义了我们是谁，删除记忆是否等于删除了自己？
三幕大纲：
第一幕（建置）：
- 开场：展示记忆删除师的工作日常，他冷静、专业，从不窥探客户记忆
- 激励事件：一个特殊客户要求删除一段"不能被任何人看到"的记忆，报酬是平时的十倍
- 第一幕转折：他在删除过程中忍不住看了一眼，发现记忆里有自己失踪的妻子
第二幕（对抗）：
- 上升：他开始秘密调查这个客户，发现客户和妻子的失踪有关
- 中点：他发现妻子可能还活着，但客户的身份比他想象的更危险
- 上升：他深入调查，发现自己的记忆也被篡改过——妻子失踪那天的记忆是假的
- 最低点：客户发现了他的调查，威胁要删除他关于妻子的所有记忆
第三幕（解决）：
- 高潮：他和客户对峙，必须选择——删除客户关于妻子的记忆保护秘密，还是保留记忆找出真相
- 结局：他选择保留记忆，接受了痛苦的真相，妻子已经不在了，但记忆让她仍然活着
...（场景级大纲 + 节奏分析 + 三层叙事设计）

## 结构质量自检（v1.1 新增）

大纲完成后必须检查，不通过的大纲必须调整后才能进入写作阶段。

### 检查项

**1. 冲突检查**
- [ ] 核心冲突足够强吗？（不是鸡毛蒜皮的小事）
- [ ] 双方力量对比合理吗？（不是一边倒，主角有赢的可能但很艰难）
- [ ] 冲突有升级吗？（从简单到复杂，从外部到内部）
- [ ] 主角是主动参与冲突还是被动卷入？（最好是主动做出选择进入冲突）

**2. 转折检查**
- [ ] 每个转折点有伏笔吗？（不是凭空出现的）
- [ ] 每个转折改变了故事走向吗？（不是无关紧要的小翻转）
- [ ] 中点是重大转折吗？（改变了故事的方向或利害关系）
- [ ] 最低点足够"低"吗？（主角失去了什么？所有希望似乎破灭了吗？）
- [ ] 高潮是主角主动做出的最终选择吗？（不是巧合/外力解决）

**3. 节奏检查**
- [ ] 标出每个场景的紧张度（1-10），画出节奏曲线
- [ ] 有没有连续三个紧张场景？（有就加缓冲场景）
- [ ] 有没有连续三个平淡场景？（有就加冲突场景）
- [ ] 紧张场景后有缓冲吗？
- [ ] 高潮前有"暴风雨前的宁静"吗？
- [ ] 场景长度和节奏匹配吗？（紧张场景短快，舒缓场景长慢）

**4. 逻辑检查**
- [ ] 列出因果链：每个事件→原因→结果，都合理吗？
- [ ] 有没有"巧合解决问题"的情况？（巧合只能引发麻烦，不能解决麻烦）
- [ ] 主角靠自己的能力/选择解决问题吗？（不是靠外部救援/突然出现的帮手）
- [ ] 信息差合理吗？（人物知道什么、不知道什么，符合逻辑）
- [ ] 时间线一致吗？（事件顺序、间隔、人物年龄都对得上）

**5. 创新检查**
- [ ] 有没有反套路的结构设计？（不是标准的"英雄之旅"换皮）
- [ ] 有没有"读者想不到但合理"的转折？
- [ ] 结尾是反套路的吗？（如果是，有铺垫吗？）
- [ ] 三层叙事（明线/暗线/角色线）都有创新点吗？
- [ ] 结构本身是这个故事独有的吗？（换一个故事这个结构就不适用了）

**6. 伏笔检查**
- [ ] 列出所有伏笔，每个都有回收计划吗？
- [ ] 伏笔的埋设位置合理吗？（不太早也不太晚）
- [ ] 回收时和前面的伏笔对得上吗？（细节一致）
- [ ] 有没有"突然出现的回收"？（前面没埋，后面突然说"其实之前XX"）
- [ ] 暗线有足够的铺垫吗？（不是高潮时才突然揭开）

**7. 完整性检查**
- [ ] 激励事件足够打破主角的日常吗？
- [ ] 第一幕转折点是主角主动做出的选择吗？
- [ ] 每个场景都有目标、冲突、转折吗？
- [ ] 有没有可以删掉的"过渡场景"？（如果删掉不影响故事，就删掉或合并）
- [ ] 结局回应了开场和主题吗？
- [ ] 所有主要人物的弧线都完成了吗？

### 不通过怎么办

- 冲突不通过 → 加强核心冲突，调整力量对比，加冲突升级
- 转折不通过 → 给转折加伏笔，调整转折使其改变走向，加强最低点
- 节奏不通过 → 调整场景顺序，加缓冲/冲突场景，调整场景长度
- 逻辑不通过 → 把巧合改成有因果的事件，让主角靠自己解决，修复时间线
- 创新不通过 → 用假设颠覆法/反套路法给结构加创新点
- 伏笔不通过 → 给未回收的伏笔安排回收点，删掉不需要的伏笔，给暗线加铺垫
- 完整性不通过 → 补全缺失的结构要素，删掉多余的过渡场景

**只有7项全部通过的大纲，才能进入正文写作阶段。**
